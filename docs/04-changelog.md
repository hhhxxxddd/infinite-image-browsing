## 未发布

### 媒体库与编辑

- 详细信息的描述、参考提示词及生成参数改为跟随编辑点的浮层，避免挤压侧栏；AI 建议先填入草稿，保存后生效。
- 轻量预览统一图片／音视频、工作区产物与各选择入口，固定文件信息／描述／生成信息页签及右下操作；制作方式用黄色标签，来源单独展示。补齐媒体库描述、参考提示词和音频产物信息，读取失败可重试。
- 媒体库与工作区复用图层编辑器：常驻图层区、独立裁剪／缩放、紧凑属性、分组拖放／隐藏／锁定、Delete 删除及内容区／画布保存；改画布不缩放图层。
- 副本和覆盖保存保持编辑器打开，保留元信息并保存可恢复的文档／快照；反复覆盖更新同一记录，副本独立，素材快照去重。
- 项目数据目录可配置、校验迁移并排除媒体扫描；素材选择统一卡片、隐藏路径、共用搜索筛选，图片入口仅搜索图片。
- 横竖图片／视频混排，卡片拖放交换持久顺序；目录别名、子目录改名同步引用；缩略图档位持久保存，侧栏切换避免重复重排。
- 标签分组与自动规则保留，扫描不再默认把生成信息转换为标签；预览取消自动轮播和播放结束自动切换。
- 目录标签页移到侧栏目录下方，记住展开状态，紧凑模式直接展开；修复目录操作菜单残留，索引更新提示使用黄色背景。
- 预览／编辑器共用轻微放大淡入；裁剪、缩放及笔记浮动覆盖画布，统一工具图标、尺寸和分隔线，保留右侧图层／画布设置。

### 工作台与 AI

- 工作区按业务作品组织跨媒体制作文件、产物和成果，首页使用封面卡片并支持上传；工作台／全部作品／具体作品增加轻微切换动效。
- AI 图片在同一制作文件内切换生成／编辑，分别保存输入与配置；纯文字生成不上传素材、不继承编辑来源。AI 音视频仍为明确的未接入入口。
- 音频制作新增全屏多轨时间线：拖动／跨轨移动、裁剪、分割、音量、淡入淡出、静音／独奏／锁定、撤销／重做、分段试听与选区循环，导出 WAV／MP3 产物。自动保存与冲突保护保留未保存副本，修复拖动中间状态被自动写入的问题。
- AI 生成／编辑支持有序多结果映射、单节点批量和图像模型多图片返回；逐张保存来源与快照，共用批次结果区和对比预览。兼容旧配置与任务，部分保存失败保留已有产物。
- 成果同步后显示“已同步”，支持查看副本和覆盖；目录在应用内选择并记忆。修复 Windows 扫描目录大小写校验，产物可再次引用，只有成果可同步。
- 图片制作按单个图层、分组或整张画布建立同一作品内的独立 AI 分支，多个图层通过分组组织；固定输入快照后进入统一编辑器，支持续编或新建、返回来源、派生产物汇总和来源筛选。新 AI 产物按制作文件连续编号，记录提交时的上游来源。
- 制作卡片统一预览和操作，点击产物数量查看历次结果并预览、重命名或删除；产物删除清理成果／AI 输入关联，保留画布图层和媒体库副本。
- 作品、制作文件、图层及 AI 状态迁入 SQLite，保留浏览器迁移备份；事务保存、版本冲突和删除标记阻止部分写入及旧窗口复活数据。应用内媒体改名同步数据库中的图层路径和 AI 键。
- 工作流参数改为列表加属性布局，数据类型为文本／数值／开关／选项，数值支持输入框或滑块；结果映射可命名和排序。批注手动提取并可配置规则，提交前提示保存。
- Comfy Cloud 使用 API v2；加工由后台任务执行，1–15 并发、状态卡片、完成自动保存，失败不重提，重启标记跟踪中断。
- 图片画布与 AI 单图裁剪／缩放共用比例、输出尺寸和比例锁定，AI 保留填充、内容缩放与取景；输入尺寸与模型输出尺寸分开。AI 结果使用提交时源图，缺失快照明确提示。
- 图片卡片导出只复用相同内容、格式和保存范围的图片制作产物，避免误用 AI 加工结果或其他导出范围。
- 素材条和全部素材面板统一类型／来源筛选、勾选标记、虚拟网格及场景右键菜单，修复重复菜单；产物管理跨入口一致。工作区素材改为上图下字，图片／音视频悬浮预览显示标签，制作卡片提供使用素材入口。
- AI 接入支持共用 Comfy Key、可选网络代理、本地内容处理量化及 GGUF 服务；权重独立下载。

### 工程

- 产品统一为 OmniGallery／万象馆；前端迁为 app／features／shared，后端为可安装`omnigallery`包，工具集中到 tools。
- API 使用`/api`，数据实体使用 media，配置`OMNIGALLERY_*`，存储键`omnigallery:*`，桌面标识`app.omnigallery.desktop`；Spike 不兼容旧数据和入口。
- 编辑文档与产物通过宿主接口保存；复用元信息、输入、哈希、Canvas 和错误处理。移除失效编辑器、转发模块及嵌入脚本桥。
- 统一格式、严格类型、模板、依赖边界、测试和构建检查；产物不提交，开发重置默认预览。Windows 原生热部署不再依赖 WSL 同步。
- 文档按使用指南与开发规范归并，清理旧占位、单结果和原地编辑口径，合并重复专题；开发依赖集中到`backend/requirements`，ANN 为可选加速。测试统一 Windows 长短路径比较，补齐预览元信息与目录同步回归。
