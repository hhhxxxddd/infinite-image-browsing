## 未发布

### 品牌与外观

- 设置页改为与主内容区对齐的自适应宽度，限制表单控件长度，并按卡片可用宽度换行；媒体类型和缩略图大小的分段切换使用稳定分隔线。

- 媒体库筛选恢复为区域内浮动面板，取消整页抽屉和遮罩，背景媒体仍可操作；固定标题与底部按钮，筛选草稿应用后生效。修复尺寸区宽高与比例输入框被挤窄、标签竖排的问题，两列输入保持完整宽度。

- 挑一挑复用媒体库混排、封面、悬停放大和信息遮罩，增加同款缩略图大小与“显示信息”开关；保留换批历史、预览、收藏及标签编辑。挑一挑和工作台改为随窗口铺开的布局，标题与正文对齐，工作台卡片自动增减列数，消除宽屏下的大块左侧留白。

- 移除挑一挑顶部重复的“逐项查看”按钮，点击卡片继续进入可切换的预览；图库和挑一挑的收藏心形点亮后统一红色，修复通用封面按钮样式将收藏状态覆盖为白色的问题。

- 挑一挑顶栏改为左侧媒体类型、右侧批次操作，下排分开展示数量和视图设置，移除重复标题和图标。媒体库、挑一挑与预览共用直接展示分组的标签编辑器，保留未分组，支持标签／分组搜索和多选；批量标签选择补充分组，挑一挑快捷打标也复用分组菜单与已选状态。

- React 标签配置改为一排六色预设，喜欢标签默认柔和红色，保留已有颜色直到重新选择；统一标签颜色展示。设置、工作台和挑一挑分离顶部标题与正文滚动区域，修复内容和分类栏上滑越过圆角边界的问题，低窗口高度下分类栏也可滚动。

- 中文名改为“星空馆”，统一网页、侧栏和桌面标题；星轨图标采用石墨底板与银白星光，网页和桌面各尺寸图标从同一 SVG 生成。React 基础表面改为石墨灰，导航选中保留银灰，字标使用较轻的现代黑体；用户标签、时间线分类与告警保留语义颜色。
- 目录页与图库共用顶部搜索和结果工具栏，节点图同步石墨底色与清晰图标；AI 搜索增加银白至浅蓝流光边缘与短距离光晕，移除图库更多菜单中重复的“逐张查看”入口。
- AI 搜索光晕改为独立绘制层，修复左侧裁切并跟随侧栏折叠；添加、新建、生成、导出等主要按钮统一蓝色，浅深色分别配白字和深色字；多选数量徽章修复低对比度，来源标签改为中性灰，收藏统一红色。编辑器共用蓝色片段与选中态、琥珀文字轨和标记，绿／琥珀／红仅承担成功／警告／错误语义。全局提示改为工作区域底部居中，自动避开多选操作条和编辑器底部控制，成功提示缩短、错误提示延长。

### 媒体库与编辑

- 审查并修复 React 与媒体后端：音频时间更新仅在歌词行变化时更新界面，封面与信息栏共用元数据读取，EXIF 按元信息页签加载；标签编辑改为目标集合的事务保存，避免失败重试反向切换，防止旧响应覆盖新会话。修复全屏嵌套编辑弹窗快捷键穿透、挑一挑切换语言后重新加载全部媒体的问题，并限制随机浏览历史的标签／排除路径缓存。
- 元数据及标签同步操作移到后端工作线程，批量生成信息按块查询，图片元数据读写补齐路径权限检查。补充幂等保存、回滚、路径边界、并发响应和歌词定位回归；整理 Vue 对照与 React 现行文档边界。

- 媒体预览改为轻盈的桌面查看器布局，顶部集中常用操作与居中文件名，底部提供规格、位置和缩放滑块，统一细线图标，移除悬浮工具条与重复文件名。保留右侧信息栏，标签仅在描述页签显示；全屏保留完整工具栏及编辑弹窗，修复重新打开或改变窗口后沿用旧画布尺寸的问题，挑一挑去掉预览内重复的收藏按钮。

- 缓存媒体卡片及稳定操作回调，修复每次勾选、追加和取消选择都会重绘全部卡片的卡顿；批量菜单与拖动始终读取最新选择。未打开的弹窗不再重复构建内容，保留关闭动画；工作台素材选择器同步优化单张卡片选择。

- 筛选草稿移入共用表单，修复标签、排除项、开关和尺寸输入连带重渲染整个媒体列表的延迟，工作台素材选择器同步受益；标签搜索延后更新结果并缓存分组，保留输入回显、手动折叠和应用／重置行为。

- 详细信息的描述、参考提示词及生成参数使用独立编辑弹窗，避免挤压侧栏；AI 建议先填入草稿，保存后生效。
- 音频元数据展示歌曲名及封面来源；本地 MP3 可在浮层编辑歌曲名、艺术家、专辑，替换或移除内嵌封面。写入保留声音、歌词和其他标签，带版本冲突保护；修复播放期间 Windows 文件占用导致保存失败的问题，保存后恢复播放位置。
- 轻量预览统一图片／音视频、工作区产物与各选择入口，右侧保留描述／生成信息／元信息页签，常用操作位于顶部，缩放与列表位置位于底部；来源使用中性标签。补齐媒体库描述、参考提示词和音频产物信息。
- 媒体库与工作区复用图层编辑器：常驻图层区、独立裁剪／缩放、紧凑属性、分组拖放／隐藏／锁定、Delete 删除及内容区／画布保存；改画布不缩放图层。
- 副本和覆盖保存保持编辑器打开，保留元信息并保存可恢复的文档／快照；反复覆盖更新同一记录，副本独立，素材快照去重。
- 项目数据目录可配置、校验迁移并排除媒体扫描；素材选择统一卡片、隐藏路径、共用搜索筛选，图片入口仅搜索图片。
- 横竖图片／视频混排，卡片拖放交换持久顺序；目录别名、子目录改名同步引用；缩略图档位持久保存，侧栏切换避免重复重排。
- 标签分组与自动规则保留，扫描不再默认把生成信息转换为标签；预览取消自动轮播和播放结束自动切换。
- 目录标签页移到侧栏目录下方，记住展开状态，紧凑模式直接展开；修复目录操作菜单残留，索引更新提示使用黄色背景。
- 预览／编辑器共用轻微放大淡入；裁剪、缩放及笔记浮动覆盖画布，统一工具图标、尺寸和分隔线，保留右侧图层／画布设置。

### 工作台与 AI

- 图片、音频、视频布局和 AI 各创作入口的标题旁增加圆圈问号，弹层介绍工具并以表格列出当前可用快捷键；未接入的入口明确标记占位能力。

- 工作区按业务作品组织跨媒体制作文件、产物和成果，首页使用封面卡片并支持上传；工作台／全部作品／具体作品增加轻微切换动效。
- AI 图片在同一制作文件内切换生成／编辑，分别保存输入与配置；纯文字生成不上传素材、不继承编辑来源。AI 音视频仍为明确的未接入入口。
- 音频制作新增全屏多轨时间线：拖动／跨轨移动、裁剪、分割、音量、淡入淡出、静音／独奏／锁定、撤销／重做、分段试听与选区循环，导出 WAV／MP3 产物。自动保存与冲突保护保留未保存副本，修复拖动中间状态被自动写入的问题。
- 音频制作可加入视频并编辑其第一条音轨，保留视频来源与使用记录，导出音频产物；无音轨视频明确提示无法添加，波形与试听使用同一音轨。
- 音频制作新增歌词／字幕文字轨，支持时间定位、拖动／裁边、跨轨移动、分割、复制、隐藏／锁定及播放头预览；导入 LRC／SRT／VTT／TXT，按整轨或选区下载 LRC／SRT／VTT，随制作文件保存并兼容旧音频文档。
- 文字片段支持双击／Enter 在片段内编辑，新增短片段自动定位并放大时间线；提交和取消沿用撤销记录，右侧属性滚动条移到内容外侧。
- 声音和文字片段可吸附到其他片段边缘、播放头及标记，Shift 临时跳过；新增可命名、拖动、跳转并随文件保存的标记点。声音片段支持 0.25–4 倍变速和保持音调，裁剪、分割、波形、试听与导出使用相同时间换算。混音音量表显示左右声道、峰值及过载，导出检查编码前混音峰值；录音与自动转写未接入。
- AI 生成／编辑支持有序多结果映射、单节点批量和图像模型多图片返回；逐张保存来源与快照，共用批次结果区和对比预览。兼容旧配置与任务，部分保存失败保留已有产物。
- 成果同步后显示“已同步”，支持查看副本和覆盖；目录在应用内选择并记忆。修复 Windows 扫描目录大小写校验，产物可再次引用，只有成果可同步。
- 图片制作按单个图层、分组或整张画布建立同一作品内的独立 AI 分支，多个图层通过分组组织；固定输入快照后进入统一编辑器，支持续编或新建、返回来源、派生产物汇总和来源筛选。新 AI 产物按制作文件连续编号，记录提交时的上游来源。
- 制作卡片统一预览和操作，点击产物数量查看历次结果并预览、重命名或删除；产物删除清理成果／AI 输入关联，保留画布图层和媒体库副本。
- 作品、制作文件、图层及 AI 状态迁入 SQLite，保留浏览器迁移备份；事务保存、版本冲突和删除标记阻止部分写入及旧窗口复活数据。应用内媒体改名同步数据库中的图层路径和 AI 键。
- 工作流参数改为列表加属性布局，数据类型为文本／数值／开关／选项，数值支持输入框或滑块；结果映射可命名和排序。批注手动提取并可配置规则，提交前提示保存。
- Comfy Cloud 使用 API v2；加工由后台任务执行，1–15 并发、状态卡片、完成自动保存，失败不重提，重启标记跟踪中断。
- 图片画布与 AI 单图裁剪／缩放共用比例、输出尺寸和比例锁定，AI 保留填充、内容缩放与取景；输入尺寸与模型输出尺寸分开。AI 结果使用提交时源图，缺失快照明确提示。
- 图片卡片导出只复用相同内容、格式和保存范围的图片制作产物，避免误用 AI 加工结果或其他导出范围。
- 素材条和全部素材面板统一类型／来源筛选、勾选标记、虚拟网格及场景右键菜单，修复重复菜单；产物管理跨入口一致。工作区素材改为上图下字，图片／音视频悬浮预览显示标签，制作卡片提供使用素材入口。
- AI 接入支持共用 Comfy Key、可选网络代理、本地内容处理量化及 GGUF 服务；权重独立下载。

### 工程

- 产品统一为 OmniGallery／星空馆；前端迁为 app／features／shared，后端为可安装`omnigallery`包，工具集中到 tools。
- API 使用`/api`，数据实体使用 media，配置`OMNIGALLERY_*`，存储键`omnigallery:*`，桌面标识`app.omnigallery.desktop`；Spike 不兼容旧数据和入口。
- 编辑文档与产物通过宿主接口保存；复用元信息、输入、哈希、Canvas 和错误处理。移除失效编辑器、转发模块及嵌入脚本桥。
- 统一格式、严格类型、模板、依赖边界、测试和构建检查；产物不提交，开发重置默认预览。Windows 原生热部署不再依赖 WSL 同步。
- 文档按使用指南与开发规范归并，清理旧占位、单结果和原地编辑口径，合并重复专题；开发依赖集中到`backend/requirements`，ANN 为可选加速。测试统一 Windows 长短路径比较，补齐预览元信息与目录同步回归。
