# 万象馆视觉规则

品牌图标采用蓝色圆角底与方形、圆形、三角、星芒组成的四格展窗，表达多种媒体的收藏与创作。侧栏与浏览器共用 `vue/public/favicon.svg`，桌面图标由该 SVG 通过 `npm exec tauri icon -- public/favicon.svg` 生成；修改图形时需同步再生成桌面资源。品牌副标题为“收藏所爱，创作所想”。

界面的共享变量定义在 `vue/src/ui-system.scss`，由 `main.ts` 在基础样式之后引入。页面优先使用 `--ui-*` 变量；旧组件仍可使用与之映射的 `--zp-*` 变量。深色主题由 `body.dark` 切换。

| 用途 | 变量 | 规则 |
| --- | --- | --- |
| 字体 | `--ui-font` | Segoe UI Variable 优先，中文回退到 Microsoft YaHei UI；正文默认 13px / 1.5 |
| 页面、侧栏、卡片 | `--ui-canvas`、`--ui-sidebar`、`--ui-surface`、`--ui-surface-soft` | 用层次区别区域，避免页面自行指定纯白或纯黑 |
| 外壳与内容区 | `--ui-shell`、`--ui-sidebar-glass`、`--ui-header-glass`、`--ui-stage` | 顶部与侧栏偏冷，展示区偏中性；渐变与柔和阴影代替连续的直线边界 |
| 文本、边框、悬停 | `--ui-text`、`--ui-muted`、`--ui-border`、`--ui-hover` | 明暗主题共用语义，保证静止、悬停与禁用状态可辨 |
| 圆角、间距 | `--ui-radius-sm`、`--ui-radius`、`--ui-radius-lg`、`--ui-space-1` 至 `--ui-space-5` | 小控件 7px、卡片 10px、弹层 14px；间距按 4 / 8 / 12 / 16 / 24px 使用 |
| 动效 | `--ui-motion-fast`、`--ui-motion`、`--ui-ease` | 控件反馈约 120ms，面板/视图约 190ms；优先过渡透明度与位移，不改变内容尺寸 |

新增页面应先使用共享表面和控件状态，再补局部布局。悬浮菜单、弹窗与抽屉由全局规则统一边框、圆角、阴影；页面局部样式只处理其特殊结构。所有动作应保留可见焦点，退出动画不得阻挡下层点击。系统启用“减少动态效果”时，过渡、动画和滚动动效会自动缩减。

侧栏展开、收起时直接切换最终宽度，只保留内部文字等反馈动效。不要对影响媒体内容区的宽度做逐帧动画，否则瀑布流会连续计算卡片尺寸和位置，造成图片抖动。

媒体预览与统一图片编辑器保持纯黑画布、浮动工具条及右侧圆角面板的布局。详情由 `previewPanels.css` 定义，编辑器由 `studioEditorShell.css` 定义：桌面端距边缘 12px、面板圆角 22px，使用留白和细分隔线分组。图片制作不再使用明显的三栏工作台外壳；左侧工具条、右侧图层／属性／裁剪面板围绕画布浮动，面板保留滑入滑出和减少动态效果支持。

左侧分别提供“裁剪”和“缩放”工具：裁剪拖动边角调整选区，缩放拖动边角调整整张图片大小，支持保持比例与输入尺寸。二者再次点击当前工具即取消，“应用调整”提交一次可撤销修改；切换工具从本次调整前的图片重新开始。裁剪与缩放均提供画面比例和输出尺寸；缩放切换比例会调整完整图片的宽高，不裁掉内容。图片填充（填满、完整显示、拉伸）及内容放大放在图层属性，控制图片在图层框内的显示，支持撤销；裁剪面板不展示这些排版设置。画布悬停样式不得覆盖背景模式，棋盘格在鼠标进入、移出及调整时保持显示。

图片右键菜单不重复提供裁剪／重置裁剪；“铺满画布”将图片图层移至原点、调整为画布尺寸并拉伸填满，支持撤销，锁定图层不可操作。编辑器文字和数值输入框显式使用浅色文字光标，避免继承预览容器的透明光标。

画布比例与宽高只调整画布边界，以中心为锚点平移全部图层，不缩放图片、文字或笔画。隐藏和锁定图层也保持与画布中心的相对位置；超出边界的内容仅在预览与导出时裁切，草稿仍保留，扩大画布或撤销后可恢复。读取草稿时不得按当前画布尺寸压缩图层。

保存操作以左上角独立悬浮条呈现，与预览工具条同高，切换或收起右侧工具面板时保持位置。保存副本／覆盖原图直接展示，单一操作不再收进更多菜单；裁剪和缩放时暂时隐藏保存条，取消／应用调整留在右侧工具面板底部。媒体库临时会话显示“未修改／修改未保存”，不称为缓存或已保存；工作区自动保存明确显示“草稿已保存到本机”。

统一编辑器右侧常驻上下分区：上方为图层列表，标题旁提供新增图片、文字和分组，“画布”行用于切换下方画布设置；下方显示选中对象属性、裁剪或缩放工具。两区独立滚动，分隔线支持拖动及上下方向键调整高度。裁剪／缩放期间图层区保持可见但不可操作，取消／应用位于下方工具区底部。左侧只保留选择与移动、裁剪、缩放、撤销、重做、对比（工作区另保留笔记），不再提供新增、图层切换和画布入口。

## 明暗主题与层次

主色使用蓝色：浅色 `#1769aa`，深色 `#8ac5f7`。页面底色分别为冷白 `#f5f8fb` 和深蓝灰 `#121a24`；侧栏、内容表面、浮层逐级区分亮度。Ant Design Vue 的 `colorPrimary` 等主题值与这些变量保持一致。

- 正文、次要文字和主色需在对应表面上保持清晰；小字目标至少 4.5:1，关键控件边界和选中指示至少 3:1。`--ui-control-border` 用于输入框等需要辨认轮廓的控件，`--ui-border` 用于较轻的区域分隔。
- 主表面保持不透明。透明度只用于悬停背景、阴影、焦点环与媒体图片上的遮罩，避免内容透到输入文字背后。
- 外壳、侧栏与顶部栏使用轻微色差和半透明叠层；内容区以圆角、顶部渐变和柔和阴影衔接。毛玻璃只用于导航与搜索等界面框架，媒体卡片和文字所在的表面仍保持清晰。
- 常态卡片用 `--ui-shadow-card`，浮层用 `--ui-shadow`。AI 画面搜索启用时才使用柔和光晕；输入框仍以边框和焦点环表示状态。
- 媒体卡片上的文件名使用深色渐变遮罩。用户设置的标签颜色保持独立，不随品牌主色整体替换。

媒体库素材选择统一使用 `MediaLibraryPicker.vue`：上方搜索与筛选，下方四列缩略图卡片，小屏改为三列。卡片显示文件名，不展示或悬停暴露路径；多选勾选位于左上，独立预览按钮位于右上，媒体类型角标位于左下。网格行按内容高度排列，受限高度只产生滚动，不能压缩网格行导致缩略图重叠。图片添加／替换入口不显示多选勾选和确认页脚，选图直接生效。
