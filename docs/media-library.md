# 万象馆使用说明

## 添加文件夹与扫描

1. 点击顶部或侧栏的“添加文件夹”，选择运行服务机器上的目录。
2. 在侧栏打开该目录。媒体列表上方提供“扫描新增文件”；发现目录变化时，列表上方也会显示扫描提示。
3. 扫描完成后点击“刷新列表”显示最新内容。手动点击“扫描新增文件”会在完成后更新列表。

Windows 桌面版也可在“目录”页或已添加文件夹的浏览页，从资源管理器拖入一个或多个文件夹。确认后将这些目录加入媒体库并扫描；拖入普通文件会被跳过。文件始终留在原位置。

设置 → 扫描与索引中的“自动更新索引”默认开启。媒体库页面可见时每分钟检查一次目录变化，有变化才发起增量扫描；离开媒体库或隐藏页面后不会持续按这个周期扫描。后台扫描与全量重建串行执行，避免同时写索引。自动扫描不强制刷新当前列表。

增量扫描通常会跳过未变化的目录和文件，但大量目录、首次收录或大量新文件仍会产生磁盘读取和元数据解析开销。它不等于零成本，也不会每分钟全量重建。需要重解析历史生成信息或修复索引时，在设置中手动“重建媒体索引”；手动编辑过的生成信息会保留。

设置 → 同步设置可以指定 OneDrive 管理的本地媒体目录。开启“按需文件保护”后，目录会加入媒体库；仅在线文件可作为条目显示，后台扫描、缩略图生成和图片语义索引不会读取其内容，主动打开前会提示下载。下载到本机后，下次扫描会补全媒体信息。关闭保护不会删除已添加的目录，后续扫描会按普通本地文件处理。Windows 桌面版直接读取文件属性；从 WSL 访问 Windows 盘符时，通过 Windows 查询同一属性。OneDrive 负责实际文件传输，万象馆不连接 OneDrive 账号。标签和应用数据库目前仍在本机，不会随媒体目录自动跨设备同步。

## 目录分类与标签页

侧栏“目录”页将已添加的文件夹及其子目录画成自上而下的节点图。点击节点会在侧栏“标签页”中打开该目录，可随时切换或关闭。标签页可以拖动排序；应用关闭后会记住已打开的标签、顺序和当前选中项，关闭的标签不会恢复。目录节点对应本机真实文件夹，适合按自己的分类方式整理媒体；层级较深时可在节点下方继续加载下级。

已添加的根目录标签使用显示别名，并以磁盘图标区别于普通子目录。根目录的“修改显示名称”只改别名；子目录节点的“改名”会修改磁盘上的真实文件夹名，同时更新已打开的标签页和媒体索引路径，保留原有标签、生成信息和手动排序。包含其他已添加根目录的文件夹不能改名。

每个节点可直接新建子文件夹。子目录可以点击“移动”后选择目标节点，也可以拖到目标节点；确认后会连同其中的文件一并移动，并更新媒体索引。已添加的根目录不能移动；包含另一个已添加目录的节点也不能移动。

- **移除管理入口**：从已添加目录中移除入口，不删除原文件。
- **删除子文件夹**：仅允许删除空目录，并要求确认；非空目录会拒绝删除。
- **复制／移动文件**：选中文件后，在操作栏的“移动到”中可选已添加文件夹，或打开“其他路径…”浏览下级目录、输入媒体服务可访问的绝对路径。移动前会检查目标目录和同名文件。也可将卡片拖到侧栏的文件夹或其他文件夹标签页，确认后复制或移动；当前文件夹的面包屑和下级文件夹也可接收拖放。文件夹页的“查看目录”会在目录图中定位当前节点。

## 选择、排序与导出

单击卡片选中，再次单击取消；双击进入预览。列表上方和多选操作栏的“全选已加载”可切换为“取消全选”。多选后操作栏提供标签、复制、移动、导出和删除。

媒体以紧凑的竖向卡片展示，图片铺满卡片并按比例裁切；文件名叠在底部渐变遮罩上。卡片会填满每行的可用宽度；列表上方可选自定义、小、中、大四档宽度，自定义值在设置中调整。空间足够时，卡片最多直接显示一至两个标签，剩余数量用“+N”提示，悬停可查看全部名称。双击预览可查看完整原图。

视频和动图卡片中央显示三角播放入口，音频卡片中央显示耳机入口，单击即可打开预览。索引记录视频流宽高，已有视频在首次搜索时补齐，视频页和混合列表从首次排版起就按真实横竖比例混排；封面加载后仍会校正比例。音频页只显示音频，音频卡片使用方形展示区域；有封面时完整显示，没有时显示纯色占位，卡片尺寸不随封面比例改变。音频仍会出现在“全部媒体”中。较短的卡片在底部名称旁显示彩色标签摘要，避免与播放入口重叠。全部媒体中的顶部栏只保留搜索、筛选、逐张查看、刷新等通用操作；“挑一挑”在侧栏“功能区”中单独打开。选中两张图片时，多选操作栏可进入图片对比；混合选中时操作栏会显示图片、视频、音频数量。

将一张卡片拖到另一张卡片上，会交换两张媒体的排序位置；混排随后按新的顺序重新布局。即使选中了多张卡片，卡片间拖放也只交换实际拖起的那张；拖到文件夹仍可移动所选文件。手动顺序持久保存，在媒体库和文件夹中共用；保存时不重新加载整张列表。需要恢复时，在全部媒体列表上方点击“恢复时间排序”。相似图片搜索使用相似分排序。

Windows 桌面版的卡片右上角有“拖出文件”按钮，按住拖到桌面或资源管理器即可复制原文件；选中多张时可一同拖出。拖动卡片主体仍用于应用内排序和文件夹间操作。网络共享中的文件暂不支持直接拖出，请使用导出或复制。

## 工作台

工作区可引用媒体库的图片、视频和音频，也可保存图片制作与 AI 加工产生的素材。“成果”用于记录已确定的媒体库文件；中间产物仍属于“素材”。工作流在“AI 创作 → 工作流管理”中统一导入和配置。图片制作、工作流映射、工作区产物的保存及删除规则见[工作台说明](workbench.md)。

## 挑一挑

侧栏“挑一挑”从已收录的媒体中随机抽取一批，默认将图片、视频和音频混排；也可以临时切到单一类型。点击卡片直接打开这一批媒体的逐项预览，点击心形标记“喜欢”，右键点击心形可选择其他已有标签。页面还提供“换一批”和“上一批”，方便返回刚才看到的内容；抽取新一批时会尽量避开本轮已展示的媒体，某一类型看完后从头开始。

这个页面用于发现和挑选，不显示排序、批量选择、拖动移动与文件夹管理操作。需要整理文件时回到媒体库或目录页。

以图搜图提供“找重复图”和“AI 找相似”两个分段选项，媒体库和工作区素材选择器使用相同入口。默认的“AI 找相似”使用已建立的 Qwen3-VL 图片向量索引，查找内容相近的图片，并按相似度排序。需要寻找缩放、压缩或轻微修改的同一画面时，切换到“找重复图”，无需 AI 模型。后者首次会读取尚未建立特征的候选图片，之后按文件修改时间和大小复用本地特征缓存。修改最低相似分只筛选已返回的前 100 项；更换参考图或筛选范围才重新比较。

## 搜索

媒体库顶部搜索框查找**文件名、标签和个人描述**，不搜索路径。输入多个词表示同时满足；需要只查某一字段时使用 `name:`、`tag:` 或 `desc:`。双引号包住完整短语，`-` 表示排除，`OR` 表示任选，括号用于分组，`has:desc` 筛选已有描述的媒体。例如：

```text
tag:风景 -tag:模糊
(tag:风景 OR tag:城市) desc:夜景
name:"IMG 001" has:desc
```

搜索框右侧的问号提供可点击的示例。当前搜索框不支持正则表达式。点击搜索框内的机器人图标会切换到蓝色的“画面搜索”模式：在同一个输入框描述画面，按 Enter 搜索；再次点击可切回文字搜索，原文字搜索词会恢复。两种搜索词不会叠加；已应用的标签、尺寸与文件夹范围筛选在两种模式下都会生效。点击图片图标、粘贴图片或拖入图片可进行以图搜图。画面搜索需要先在“设置 → AI 接入”准备本地模型并建立图片向量索引。

## 筛选媒体

顶部工具栏的筛选入口按标签分组展示可选项，并在顶部提供跨分组名称搜索；列表中的颜色与卡片标签一致。每组先显示 40 个标签，可继续加载更多。卡片右键菜单和多选标签菜单也按分组展示并提供名称搜索。同一分组内选中多个标签时，媒体只需匹配其中任意一个；同时选中多个分组时，媒体必须分别满足每个分组。排除标签会去掉带有该标签的媒体；选择“排除所有标签”可只看无标签媒体，不计入尺寸和媒体类型等内部标签。画面比例和精确尺寸也可与标签同时使用。

选择或移除标签只会修改弹窗中的草稿。点击“应用筛选”才更新结果；“重置”恢复本次打开时已应用的条件，“清空全部筛选”清空草稿，仍需点击“应用筛选”生效。关闭弹窗会放弃未应用的修改。缩略图尺寸、排序恢复和扫描入口位于媒体列表上方。

## 导出

“导出”包含两个目的地：

| 目的地 | 保存位置 |
| --- | --- |
| 下载到电脑（ZIP） | 由当前浏览器的下载设置决定 |
| 保存到应用归档目录 | 运行后端的机器，完成后显示完整路径 |

归档目录在设置 → 通用 → 归档目录中修改，也可从导出窗口修改。Windows 桌面版默认位于 `%LOCALAPPDATA%\com.zanllp.iib\zip_temp`；独立后端默认使用其工作目录下的 `zip_temp`。界面会显示实际绝对路径，不会自动写入 Windows“下载”目录。

- Windows 本地后端示例：`D:\图片归档`。
- 修改后点击“保存目录”。更改只影响之后的归档，不移动已有 ZIP；“恢复默认”返回后端默认目录。
- “压缩 ZIP 内容”影响压缩方式，不改变导出目的地。

## 预览与生成信息

双击卡片或点击顶部“逐张查看”，进入同一个预览组件。右侧详情面板可以通过工具条的圆圈感叹号按钮收起或展开；左侧提供上一项／下一项按钮。上下滑动、方向键或 Ctrl / Cmd + 滚轮可切换媒体，普通滚轮缩放图片。预览不会自动切换下一项，右侧的 × 关闭预览。

### 描述与 AI 参考提示词

媒体描述与 AI 参考提示词以可展开的正文显示，标题旁提供复制、编辑和 AI 建议图标；点击正文也可原地编辑。AI 建议打开轻量弹窗，确认提示词与建议长度后进入编辑状态，结果直接填入草稿。保存成功返回正文，失败保留草稿，取消编辑不保存。单次修改提示词不会覆盖“AI 接入”的默认设置。

音频和视频使用相同的描述展示与编辑交互，AI 描述图标为置灰占位，不发起生成请求。“AI 参考提示词”只对图片显示，位于描述页；其内容独立保存，不覆盖媒体描述或原始生成信息。

### 生成信息

生成信息页只展示已有内容：使用资源默认显示前三项，可展开；正向／负向提示词显示可展开正文；参数以标签排列，保留零值，不用当前图片尺寸补充缺失的生成尺寸。点击提示词或参数可原地编辑，缺失字段通过顶部“＋”添加。复制和原文编辑使用图标，提示词不重复显示编辑图标。三个页签的滚动条统一贴近右侧面板边缘。

“使用资源”和正／负提示词保留中文；参数以英文显示，悬停提供中英双语说明。资源支持 Checkpoint、LoRA、VAE、Upscaler、Embedding、ControlNet、LyCORIS、Hypernetwork，可附权重（含 0）和哈希。LoRA 不必写入提示词：手动添加的资源独立写入 `extraJsonMetaInfo.resources`，保留提示词、已有参数和其他补充信息。同类型同名资源合并显示，手动填写的权重和哈希优先。

资源权重与数值参数使用可手动输入、清空的减／加控件，输入框提供文本光标和聚焦边框。Steps、Seed、Clip skip、Hires steps 使用整数步进；权重、CFG scale、Hires upscale 步长为 0.1；Denoising strength 范围 0–1、步长 0.05。Size 分宽高填写正整数，Sampler 和 Schedule type 使用文本输入。

原文编辑器提供映射预览与格式示例，说明提示词、资源、参数的对应关系。面板不单独展示原始文本或“更多信息”；未归类字段保留在原文编辑中。不能安全拆分的 JSON／工作流格式只提供原文编辑，不转换为普通提示词。编辑保存在数据库中，不修改图片文件；工作区素材同步到媒体库时会带上已填写的信息。

检测到媒体元信息中的 ComfyUI 工作流时，在生成信息底部显示 `Comfyui·节点数` 标签和复制图标，不提供编辑入口。优先识别带节点布局的 workflow，只有 API prompt 时按执行节点计数；复制完整 JSON。没有可识别工作流时不显示标签。

### 图片调整与媒体预览

预览顶部工具条保留“全屏、喜欢”“调整图片”“媒体描述、详细信息”“更多、关闭”。下载与删除收进“更多”；音视频播放、进度和音量使用播放器控件。气泡图标控制所有媒体的描述，圆圈感叹号控制详情。动态图禁用静态图片调整入口。

“调整图片”在当前预览中打开与工作区图片制作共用的编辑器，保留顶部预览工具条，暂不可用的按钮置灰。左侧提供选择与移动、裁剪、缩放、撤销／重做和原图对比；右侧上方常驻图层列表，下方显示当前属性或工具设置，添加图片、文字、分组和画布入口集中在图层区。裁剪与缩放是两个独立工具，都提供比例预设、输出宽高和保持比例；进入工具不立即改变图层，应用后才提交，再次点击可取消。画布宽高和比例只改变画布边界，不缩放原图；图片填充方式属于图层属性。详细布局和操作见[图片制作](workbench.md#图片制作)。

添加或替换图片使用与工作区相同的媒体库搜索和筛选能力，卡片只显示缩略图与文件名，不显示路径。这个入口始终只搜索、显示图片，点击卡片直接添加或替换；眼睛按钮仅预览，不选入。工作区的通用素材选择器仍可多选图片、视频和音频。

从媒体库进入时，当前图片按原尺寸成为初始图层，可搜索媒体库并加入其他图片。本次图层状态和撤销记录仅在内存中保留，不写入工作区草稿；有未保存修改时退出会提醒。默认“保存副本”在原目录生成不重名 PNG 图片，保留透明区域；旁边直接提供“覆盖原图”，需确认。导出读取原图而非缩略图，服务端验证合成尺寸并保留原有标签、描述和生成信息；覆盖使用原格式和原子替换，失败保留编辑状态和原文件。保存后保持编辑器和当前选中项，刷新媒体列表，并继续编辑保存后的文件。保存副本或覆盖时还会持久保存完整编辑文档和素材快照；再次调整成品会恢复图层、文字、分组、画布及保存范围。反复覆盖更新同一份记录，不累积历史版本；保存副本建立独立记录，相同素材快照按内容去重共用。图片制作入口使用同一工具布局，但保留工作区素材范围、自动草稿和工作区产物保存；AI 创作仍由工作区入口提供。

音频预览会读取本地文件的标题、艺术家、专辑、时长和内嵌封面；也支持同目录下同名封面图，或 `cover`、`folder`、`front` 图片。歌词优先读取与音频同名的 `.lrc`、`.srt`、`.vtt`、`.txt` 文件，再尝试音频内嵌的歌词。带时间戳的歌词或台词随播放高亮，点击一行可跳到该时间；无时间戳时显示纯文本。没有这些信息时仍可按文件名播放，不联网查找或生成歌词。图像封面只在本地缩放后传给界面，不修改音频原文件。

设置 → 标签配置默认有“未分组”，其中包含内置收藏标签“喜欢”。可以创建分组并直接在每个分组中新增标签；拖动标签卡片或使用“移动到”可调整分组。标签也可改名、选色，颜色选择器提供预设色与自定义色。删除分组会把其中标签移到“未分组”，不会删除标签或图片关联。标签筛选和自动打标规则选择器按分组展示，并可搜索标签名称。标签改名后图片关联和自动打标规则会沿用新名称。内置收藏标签内部标识仍为 `like`，不提供改名，已有收藏与规则保持兼容。

扫描和重建索引不会默认把提示词、模型、采样器、LoRA 或生成来源转成标签。这些信息保留在生成详情里；需要按这些条件打标时，在设置 → 自动打标规则中选择目标标签并配置条件。筛选区只展示自定义标签分组。升级时会清理旧版自动生成的系统标签及关联，保留手动标签、显式规则产生的标签、原始生成信息，以及供媒体类型和尺寸筛选使用的内部索引。

## 快捷键


固定按键和自定义按键在设置 → 快捷键中直接展示。固定项不可编辑，自定义项点击输入框后按键即可设置；重复按键或与固定操作、常见浏览器操作冲突时会提示。

| 按键 | 操作 | 生效范围 |
| --- | --- | --- |
| PageUp / PageDown | 向前／向后翻一屏 | 鼠标位于媒体列表上 |
| Home / End | 已加载列表开头／末尾 | 鼠标位于媒体列表上 |
| Ctrl / Cmd + A | 全选已加载媒体，再按一次取消全选 | 媒体库页面（输入框除外） |
| ↑ / ←，↓ / → | 上一项／下一项 | 普通预览、全屏预览 |
| Esc | 关闭预览 | 普通预览、全屏预览 |
| + / −，滚轮 | 缩放 | 图片预览 |
| Ctrl / Cmd + 滚轮 | 上一项／下一项 | 普通预览、全屏预览 |
| 0 | 恢复大小、位置和旋转 | 图片预览 |
| R | 向右旋转 90° | 图片预览 |

输入文字或编辑生成信息时不触发预览快捷键。视频／音频控件获得焦点时保留其原生键盘操作。旧版“复制到／移动到”快捷键不再提供；文件操作仍可通过列表菜单完成。

## 缩略图设置

“缩略图短边上限”按原图较短的一边计算，并随卡片显示尺寸选取不超过该值的分辨率；网格单元宽度控制卡片显示大小，设置中的下限和列表的“小”档均为 192 px。设置页使用中性抽象图即时展示效果。极长图片的最长边会限制在 4096 px 内，避免缩略图占用过多内存。

## 视频与音频播放

应用识别扩展名以收录媒体文件。播放时，服务端按需传输原文件，桌面版由 WebView2 使用系统和浏览器可用的解码器播放；服务端不会实时转码。视频封面另由 PyAV（FFmpeg）提取，再缓存为 WebP。能生成封面不代表视频本身可在内置播放器中播放。

短视频提取封面时会回退到第一帧。GIF 和多帧 WebP 等动图通过文件头识别，卡片用播放图标提示可播放。视频、音频或图片无法在内置预览解码或读取时，Windows 桌面版可点击“选择本机应用打开”，由系统弹出“打开方式”并使用选定程序打开原文件；浏览器版提供原文件下载入口。打开本机应用由用户点击触发，不会在预览失败时自动弹出其他程序。

大视频按 HTTP Range 分块读取，服务端每次最多读取 1 MiB，不会因为文件是 10 GiB 就一次读入内存。当前项预加载元信息并在播放时继续按需读取；相邻视频只显示封面，相邻音频不挂载媒体地址，不会请求它们的原文件。视频封面按需提取并缓存为最长边不超过 1280 px 的 WebP，同时最多解码两张封面。大文件首次生成封面、跳转到文件尾部、播放高码率或高分辨率视频仍会受磁盘速度、容器索引和设备解码能力影响；文件大小本身不是唯一瓶颈。

兼容性优先建议使用 MP4 容器、H.264 视频和 AAC 音频。HEVC/H.265 是否可用取决于 Windows 的 HEVC 扩展和解码路径（见[微软的 Edge 播放说明](https://learn.microsoft.com/en-us/troubleshoot/microsoft-edge/development/video-playback-issues)）；AVI、MKV、FLV、WMV 等扩展名可收录，但能否播放还取决于容器内的编码和当前设备。遇到不能播放的文件，可在文件菜单选择“使用默认应用打开”。

### 编辑记录与快照

媒体编辑数据存放在项目数据目录的 `iib-edit-history` 子目录，不属于缓存，也不使用浏览器 localStorage。项目数据目录在“设置 → 通用”中配置，与工作区素材共用；打包版默认使用 exe 所在目录下的 `iib-project-data`，开发版默认使用数据库旁的同名目录。已有安装沿用旧位置，主动迁移后才切换。`records` 保存每张成品的一份当前编辑文档，`assets` 使用内容哈希和 `.blob` 扩展名保存素材，`outputs` 关联成品内容与记录。扫描器主动跳过整个目录，快照不重复出现在媒体库。覆盖成功后清理无记录引用的素材快照，保留最初源图和当前图层所需的素材。

成品改名或移动后，文件内容不变即可继续找到记录。备份或迁移应用时应同时保留数据库与项目数据目录；只把成品图片复制到另一台机器，不会携带独立的编辑数据。此前未保存编辑记录的图片仍以单张图层打开。显式保存才写入记录，未保存的媒体库会话仍不自动生成草稿。

项目数据目录迁移会复制并逐项校验，成功后才启用新路径；失败继续使用原路径。迁移时暂停相关文件写入，原目录保留备份，确认新目录正常后可手动清理。新旧托管数据目录均排除媒体扫描。目标包含同名数据区时拒绝覆盖。该目录面向工作区素材、媒体编辑数据和素材快照，预留后续音频、视频编辑使用；目前可恢复编辑的实现用于静态图片。
