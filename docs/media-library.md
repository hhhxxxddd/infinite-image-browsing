# 拾影使用说明

## 添加文件夹与扫描

1. 点击顶部或侧栏的“添加文件夹”，选择运行服务机器上的目录。
2. 在侧栏打开该目录。筛选面板的“显示与索引”区域提供“扫描新增文件”；发现目录变化时，列表上方也会显示扫描入口。
3. 扫描完成后点击“刷新列表”显示最新内容。手动点击“扫描新增文件”会在完成后更新列表。

设置 → 扫描与索引中的“自动更新索引”默认开启。媒体库页面可见时每分钟检查一次目录变化，有变化才发起增量扫描；离开媒体库或隐藏页面后不会持续按这个周期扫描。后台扫描与全量重建串行执行，避免同时写索引。自动扫描不强制刷新当前列表。

增量扫描通常会跳过未变化的目录和文件，但大量目录、首次收录或大量新文件仍会产生磁盘读取和元数据解析开销。它不等于零成本，也不会每分钟全量重建。需要重解析历史生成信息或修复索引时，在设置中手动“重建媒体索引”；手动编辑过的生成信息会保留。

## 文件夹管理

“文件夹”页面按树形展示父子关系，展开目录查看下级。目录内可新建子文件夹，浏览媒体时也可通过路径导航返回上级。

- **移除管理入口**：从已添加目录中移除入口，不删除原文件。
- **删除子文件夹**：仅允许删除空目录，并要求确认；非空目录会拒绝删除。
- **复制／移动文件**：选中文件，通过操作栏选择目标文件夹；也可拖到目录中。

## 选择、排序与导出

单击卡片选中，再次单击取消；双击进入预览。多选后操作栏提供标签、复制、移动、导出和删除。

拖动卡片到另一张卡片前后可改变排序，多选后可整组移动。手动顺序持久保存，在媒体库和文件夹中共用；保存时不重新加载整张列表。需要恢复时，在全部媒体的筛选面板选择“恢复时间排序”。相似图片搜索使用相似分排序。

“导出”包含两个目的地：

| 目的地 | 保存位置 |
| --- | --- |
| 下载到电脑（ZIP） | 由当前浏览器的下载设置决定 |
| 保存到应用归档目录 | 运行后端的机器，完成后显示完整路径 |

归档目录在设置 → 通用 → 导出与归档中修改，也可从导出窗口修改。默认是后端工作目录下的 `zip_temp`，界面会显示实际绝对路径；它不一定是 Windows 的“下载”目录。

- Windows 本地后端示例：`D:\图片归档`。
- WSL 后端访问同一磁盘：`/mnt/d/图片归档`。
- 修改后点击“保存目录”。更改只影响之后的归档，不移动已有 ZIP；“恢复默认”返回后端默认目录。
- “压缩 ZIP 内容”影响压缩方式，不改变导出目的地。

## 预览与生成信息

双击卡片或点击顶部“逐张查看”，进入同一个预览组件。右侧常驻生成信息，左侧提供上一项／下一项按钮；滚轮、上下滑动或方向键也能切换。轮播按钮明确显示是否开启及间隔，右侧的 × 关闭预览。

生成信息包括正向／负向提示词、模型与资源、参数和标签。有元数据时自动填充，没有时允许编辑补全。分项编辑支持模型、采样器、Seed、Steps、CFG、尺寸等；更多参数、补充 JSON 和原文编辑用于保留其他信息。保存写入媒体库数据库，不修改图片本身。

内置收藏标签显示为“喜欢”；内部标识仍为 `like`，已有收藏与规则保持兼容。

## 快捷键

固定按键和自定义按键在设置 → 快捷键中直接展示。固定项不可编辑，自定义项点击输入框后按键即可设置；重复按键或与固定操作、常见浏览器操作冲突时会提示。

| 按键 | 操作 | 生效范围 |
| --- | --- | --- |
| PageUp / PageDown | 向前／向后翻一屏 | 鼠标位于媒体列表上 |
| Home / End | 已加载列表开头／末尾 | 鼠标位于媒体列表上 |
| Ctrl / Cmd + A | 全选已加载媒体 | 鼠标位于媒体列表上 |
| ↑ / ←，↓ / → | 上一项／下一项 | 普通预览、全屏预览 |
| Esc | 关闭预览 | 普通预览、全屏预览 |
| + / −，Ctrl / Cmd + 滚轮 | 缩放 | 图片预览 |
| 0 | 恢复大小、位置和旋转 | 图片预览 |
| R | 向右旋转 90° | 图片预览 |
| 自定义 | 下载、删除、切换标签 | 普通预览、全屏预览 |

输入文字或编辑生成信息时不触发预览快捷键。视频／音频控件获得焦点时保留其原生键盘操作。旧版“复制到／移动到”快捷键不再提供；文件操作仍可通过列表菜单完成。

## 设置中的参数差异

“显示相邻图片的生成参数差异”比较相邻两张图片的提示词、模型、步数等，在卡片上标记变化；没有生成信息时不显示。Seed 是生成时的随机种子，关闭“将 Seed 变化计入差异”后，仅 Seed 不同不会显示参数差异。

缩略图分辨率控制预览图像的清晰度与读取量；网格单元宽度控制卡片显示大小。设置页使用中性抽象图即时展示效果。
