# 01 · 媒体库

[文档首页](../README.md) · [工作台](02-workbench.md) · [AI 接入](03-ai-services.md)

## 1. 收录与扫描

1. 点击“添加文件夹”，选择**运行后端机器**上的目录；文件保留在原处。
2. 打开目录，点击“扫描新增文件”。手动扫描完成后更新列表；后台扫描后可点击“刷新列表”。
3. Windows 桌面版也可从资源管理器拖入一个或多个文件夹，确认后收录并扫描；普通文件会被跳过。

“设置 → 扫描与索引 → 自动更新索引”默认开启：媒体库页面可见时每分钟检查目录变化，再做增量扫描；离开页面或隐藏窗口后不按此周期检查。扫描和重建串行执行，自动扫描不强制刷新当前列表。首次收录、大量新文件仍有磁盘与解析成本。

要重新解析历史元信息或修复索引，手动“重建媒体索引”；用户编辑过的生成信息保留。目录时间检查不能可靠发现所有文件内容修改，重要变更后可手动重建。

“设置 → 同步设置”可指定 OneDrive 本地目录并开启按需文件保护：仅在线文件可以列出，扫描、缩略图和图片语义索引不主动读取内容；打开时提示下载，下载后再次扫描补全信息。关闭保护不移除目录。OneDrive 负责传输，应用不连接 OneDrive 账号；标签和数据库仍在本机，不随媒体目录自动同步。Windows 和访问 Windows 盘符的 WSL 都会查询文件属性。

## 2. 目录与文件操作

侧栏“目录”以从左向右的节点图展示目录，根目录位于左上方，同级目录纵向排列。卡片右侧箭头按需展开或收起下级目录，悬停显示更多操作；“查看目录”弹窗使用相同布局，搜索栏保持常驻。点击节点打开标签页；标签页支持关闭、拖动排序，并记住顺序和当前项。

| 操作 | 行为与限制 |
| --- | --- |
| 根目录“修改显示名称” | 只改别名，不改磁盘名称 |
| 子目录改名 | 修改真实目录名，同步已打开标签页和索引路径，保留标签、生成信息与手动顺序 |
| 新建子目录 | 在当前节点下创建一个真实文件夹 |
| 移动子目录 | 点“移动”再选目标，或拖到目标节点；确认后连同文件移动并更新索引 |
| 移除管理入口 | 取消收录入口，不删除原文件 |
| 删除子目录 | 确认后只删除空目录；拒绝非空目录 |

根目录不能移动；包含其他已添加根目录的节点不能移动或改名。复制／移动文件可从多选操作栏选择已添加目录，或用“其他路径…”浏览、输入后端可访问的绝对路径。目标和同名文件会先检查。卡片也可拖到侧栏目录、目录标签页、面包屑或下级文件夹；确认后执行。文件夹页的“查看目录”会在节点图中定位当前目录。

## 3. 卡片、选择与排序

单击选中，再次单击取消；双击预览。“全选已加载”可切为“取消全选”，多选后可打标签、复制、移动、导出或删除。选择两张图片时可进入图片对比；混合选择会显示各媒体类型数量。

图片和视频按真实横竖比例混排，卡片按比例裁切显示，双击可看完整内容；音频固定方形，有封面时完整显示。文件名在底部，标签空间不足时用“+N”汇总，悬停查看名称。视频／动图的播放入口、音频的耳机入口可单击打开预览。

将卡片拖到另一张卡片上会交换两项顺序，即使多选也只交换实际拖起的一项；拖到文件夹仍可处理所选文件。手动顺序持久保存，媒体库和目录共用；“恢复时间排序”可重置。相似搜索按相似分排序。

Windows 桌面版卡片右上角的“拖出文件”可把原文件复制到桌面或资源管理器，多选时一同拖出；网络共享文件暂不支持此方式，可用复制或导出。

缩略图宽度分自定义／小／中／大，最小卡片宽度为 192 px。设置中的“缩略图短边上限”控制加载分辨率，极长图的最长边最多 4096 px；卡片宽度决定显示大小，两者不同。

侧栏“挑一挑”随机展示图片、视频、音频，可切单一类型、换一批或回到上一批。点击预览，心形标记“喜欢”，右键心形选择其他标签；该页不提供批量整理或拖动管理。

## 4. 搜索、标签与筛选

文字搜索匹配**文件名、标签、个人描述，不匹配路径**。多个词同时满足；支持 `name:`、`tag:`、`desc:`、短语引号、排除 `-`、任选 `OR`、括号和 `has:desc`，不支持正则。问号菜单提供示例：

```text
tag:风景 -tag:模糊
(tag:风景 OR tag:城市) desc:夜景
name:"IMG 001" has:desc
```

机器人图标切换画面搜索，输入描述后按 Enter；再次点击恢复原文字搜索词。两种查询不叠加，已应用筛选继续生效。点击图片图标、粘贴或拖入图片可以图搜图：“AI 找相似”需要 Qwen 图片索引；“找重复图”使用本地感知哈希和颜色，无需 AI。最低相似分只过滤已返回的前 100 项，换参考图或范围才重新比较。模型准备见 [AI 接入](03-ai-services.md)。

筛选按标签分组，可搜索名称，每组先显示 40 项并可继续加载。同组多选是“任一”，跨组是“同时满足”；排除标签去掉相应媒体，“排除所有标签”查无自定义标签的媒体。比例、尺寸也可同时应用。

筛选弹窗有独立草稿：“应用筛选”才更新结果，“重置”恢复打开时条件，“清空全部筛选”清空草稿，关闭放弃未应用修改。卡片右键及多选标签菜单也支持分组与名称搜索。

“设置 → 标签配置”支持新建分组、标签、改名、选色、拖动或“移动到”调整分组。删分组只将标签移入“未分组”，保留媒体关联；标签改名同步自动打标规则。内置“喜欢”不可改名。扫描不自动把提示词、模型、采样器、LoRA 转成标签；有需要时配置显式自动打标规则。

## 5. 预览、描述与生成信息

双击卡片或“逐张查看”打开统一预览。气泡按钮开关描述，圆圈感叹号开关详情，× 关闭；不会自动换下一项。图片滚轮缩放，方向键或 Ctrl / Cmd + 滚轮切换，音视频使用播放器控件。

**描述页：** 正文可展开、复制和原地编辑。标题旁 AI 建议打开轻量弹窗，确认提示词、长度后把结果写入编辑草稿；保存成功回到正文，失败保留草稿，取消不保存。临时指令不覆盖设置中的默认值。音视频描述交互相同，AI 按钮暂为置灰占位；AI 参考提示词只对图片提供，独立保存，不覆盖描述或原始生成信息。

**生成信息页：** 只显示已有资源、正负提示词和参数，不补造缺失值。资源默认前三项，可展开；点击提示词或参数原地编辑，顶部“＋”补字段，编辑图标打开原始文本和映射预览。不能安全拆分的 JSON／工作流只允许原文编辑；未归类字段仍保留。

- 资源支持 Checkpoint、LoRA、VAE、Upscaler、Embedding、ControlNet、LyCORIS、Hypernetwork，可附权重与哈希。LoRA 不必写进提示词；同类型同名资源合并，手动权重和哈希优先，保留权重 0。
- 使用资源与提示词用中文名称；参数用英文，悬停显示中英说明。整数参数按整数步进，权重／CFG／放大倍率按 0.1，重绘幅度范围 0–1、步长 0.05；Size 分宽高填写，Sampler 和 Schedule type 为文本。数值可直接输入或清空。
- 元信息中的 ComfyUI 工作流显示为 `Comfyui·节点数`，只能复制完整 JSON，不编辑。优先 UI workflow，仅有 API prompt 时统计执行节点；识别不到就不显示。

描述、标签与生成信息的手工修改保存在数据库，不改写原媒体文件；工作区素材同步到媒体库时继承这些信息。

## 6. 图片调整、保存与快照

静态图片可从预览进入“调整图片”；动图禁用此入口。编辑器右上常驻图层、右下显示属性，左侧为选择／移动、裁剪、缩放、撤销／重做、原图对比。添加图片、文字、分组及画布入口在图层区。完整工具操作见 [图片制作](02-workbench.md#2-图片制作)。

裁剪和缩放分别调整选区与完整图片尺寸，都有比例预设；进入工具不改图层，应用才提交，取消可还原。改画布比例只改变边界，不缩放图层。选图共用媒体库搜索与筛选，卡片隐藏路径；添加／替换始终只显示图片，点击直接选入，眼睛按钮单独预览。

| 保存方式 | 结果 |
| --- | --- |
| 保存副本 | 原目录生成不重名 PNG，保留透明区域；创建独立编辑记录 |
| 覆盖原图 | 确认后以原格式原子替换；更新同一记录，不累积历史版本 |
| 内容区／整个画布 | 前者取可见图层在画布内的包围范围，去四周画布空白；后者保留排版留白 |

导出读取原图，保留标签、描述和必要生成信息；失败保留原文件和编辑状态。保存后不退出，可继续编辑保存后的文件。再次打开成品恢复图层、文字、分组、画布和保存范围。未保存的媒体库会话仅在内存中，退出会提醒，不写工作区草稿。

编辑数据位于项目数据目录的 `omnigallery-edit-history`：`records` 存当前文档，`assets` 用内容哈希去重保存 `.blob` 素材，`outputs` 关联成品。反复覆盖保留最初源图和当前图层需要的快照，清理无记录引用的素材。扫描跳过整个托管区，快照不会重复出现在媒体库。成品改名／移动但内容不变时仍能找回记录；单独复制成品到另一台机器不会带上独立编辑数据。

“设置 → 通用 → 项目数据目录”统一管理工作区素材、编辑数据与快照；桌面默认 exe 旁 `.local/project-data`，源码默认应用数据根下 `project-data`。迁移先复制校验，成功才切换，原目录留备份；失败继续原路径，拒绝覆盖已有同名数据区，新旧托管区均排除扫描。备份需同时保留数据库、项目数据和原媒体。目前可恢复编辑只用于静态图片。

## 7. 音视频播放

音频读取本地标题、艺术家、专辑、时长及内嵌封面；也识别同名封面或 `cover`、`folder`、`front` 图片。歌词优先同名 `.lrc`、`.srt`、`.vtt`、`.txt`，其次内嵌歌词；时间戳随播放高亮，点击可跳转，无时间戳按正文显示。不联网找歌词，不修改音频文件。

收录按扩展名，播放能力取决于 WebView2／浏览器和系统解码器，后端不实时转码；能显示 PyAV 提取的封面不代表能播放。MP4＋H.264＋AAC 通常兼容较好；HEVC 取决于系统扩展，其他容器还取决于内部编码。无法解码时，桌面版可主动选择本机应用打开，浏览器可下载原文件。

大视频用 HTTP Range 按需读取，每次最多 1 MiB；相邻项不加载原视频／音频。视频封面最长边不超过 1280 px，同时最多解码两张。首次封面、远距离跳转及高码率播放仍受磁盘、容器索引和解码能力影响。

## 8. 导出与快捷键

导出可选浏览器下载 ZIP，或保存到**后端机器**的应用归档目录。归档默认是应用数据根下 `exports`，源码为 `.local/exports`，桌面为用户应用目录；界面显示实际路径。“设置 → 通用 → 归档目录”或导出窗可修改，改目录不移动旧 ZIP。“压缩 ZIP 内容”只改变压缩方式。

| 按键 | 操作／范围 |
| --- | --- |
| PageUp / PageDown；Home / End | 鼠标在媒体列表上：翻屏；到已加载开头／末尾 |
| Ctrl / Cmd + A | 媒体列表全选已加载，再按取消 |
| ↑ / ←；↓ / → | 预览上一项／下一项 |
| Esc | 关闭预览 |
| + / − 或滚轮 | 图片缩放 |
| Ctrl / Cmd + 滚轮 | 切换预览媒体 |
| 0；R | 图片恢复大小、位置、旋转；向右转 90° |
| Delete | 编辑器删除选中图层，输入框除外 |

设置页可录入下载、删除、切换标签等自定义快捷键，固定项不可改；冲突会提示。输入文字或编辑元信息时不触发预览快捷键，播放器聚焦时保留原生按键行为。
