# 01 · 媒体库

[文档首页](../README.md) · [工作台](02-workbench.md) · [AI 接入](03-ai-services.md)

## 1. 收录与扫描

1. 点击“添加文件夹”，选择**运行后端机器**上的目录；文件保留在原处。
2. 打开目录，点击“扫描新增文件”。手动扫描完成后更新列表；后台扫描后可点击“刷新列表”。
3. Windows 桌面版也可从资源管理器拖入一个或多个文件夹，确认后收录并扫描；普通文件会被跳过。

“设置 → 扫描与索引 → 自动更新索引”默认开启：媒体库页面可见时每分钟检查目录变化，再做增量扫描；离开页面或隐藏窗口后不按此周期检查。扫描和重建串行执行，自动扫描不强制刷新当前列表。首次收录、大量新文件仍有磁盘与解析成本。

要重新解析历史元信息或修复索引，手动“重建媒体索引”；用户编辑过的生成信息保留。目录时间检查不能可靠发现所有文件内容修改，重要变更后可手动重建。

“设置 → 同步设置”可指定 OneDrive 本地目录并开启按需文件保护：仅在线文件可以列出，扫描、缩略图和图片语义索引不主动读取内容；打开时提示下载，下载后再次扫描补全信息。关闭保护不移除目录。OneDrive 负责传输，应用不连接 OneDrive 账号；标签和数据库仍在本机，不随媒体目录自动同步。Windows 和访问 Windows 盘符的 WSL 都会查询文件属性。

## 2. 目录与文件操作

当前目录和“查看全部内容”的递归浏览只展示系统扫描支持的图片、视频和音频，尚未建立索引的支持格式也会显示；子目录保留。README、JSON、字幕、歌词等辅助文件不单独显示为卡片，仍可供歌词和生成信息等功能读取。不在扫描格式范围内的文件也不混入媒体列表。

当前目录上方的子文件夹条只显示目录名称，单击进入目录；右键可选择“进入目录”“查看全部内容”“复制路径”或“删除空文件夹”。“进入目录”打开选中的目录，“查看全部内容”会递归读取其子目录；删除仍需确认，且只允许删除空文件夹。这里不提供“刷新下级目录”，该操作保留在目录节点图中，用于更新已展开的分支。

点击侧栏“目录”右侧的箭头进入目录页；点击“目录”本身展开或收起下方已打开的标签页。侧栏收起时，点击带数量的目录图标会直接展开侧栏并显示下方列表。列表展开、收起有高度和淡入淡出的过渡；启用减少动态效果时直接切换。目录页以从左向右的节点图展示目录，根目录位于左上方，同级目录纵向排列。卡片右侧箭头按需展开或收起下级目录，展开／折叠选择及滚动位置会记住，返回目录页、刷新或重开后恢复；折叠父节点不会清空下级选择。悬停显示更多操作；“查看目录”弹窗使用相同布局，搜索栏保持常驻。点击节点打开标签页；已打开的标签页以缩进列表显示在侧栏“目录”下方，支持关闭、拖动排序，并记住顺序和当前项。标签页较多时列表独立滚动。

| 操作                 | 行为与限制                                                               |
| -------------------- | ------------------------------------------------------------------------ |
| 根目录“修改显示名称” | 只改别名，不改磁盘名称                                                   |
| 子目录改名           | 修改真实目录名，同步已打开标签页和索引路径，保留标签、生成信息与手动顺序 |
| 新建子目录           | 在当前节点下创建一个真实文件夹                                           |
| 移动子目录           | 点“移动”再选目标，或拖到目标节点；确认后连同文件移动并更新索引           |
| 移除管理入口         | 取消收录入口，不删除原文件                                               |
| 删除子目录           | 确认后只删除空目录；拒绝非空目录                                         |

根目录不能移动；包含其他已添加根目录的节点不能移动或改名。复制／移动文件可从多选操作栏选择已添加目录，或用“其他路径…”浏览、输入后端可访问的绝对路径。目标和同名文件会先检查。卡片也可拖到侧栏目录、目录标签页、面包屑或下级文件夹；确认后执行。文件夹页的“查看目录”会在节点图中定位当前目录。

## 3. 卡片、选择与排序

单击选中，再次单击取消；双击预览。“全选已加载”可切为“取消全选”，多选后可打标签、复制、移动、导出或删除。选择两张图片时可进入图片对比；混合选择会显示各媒体类型数量。

图片和视频按真实横竖比例混排，卡片按比例裁切显示，双击可看完整内容；音频固定方形，有封面时完整显示。所有媒体卡片在底部统一显示去掉后缀的文件名，音频不以曲目标题替代文件名，也不显示艺术家副标题；这些元数据保留在预览详情。标签空间不足时用“+N”汇总，悬停查看名称。视频／动图的播放入口、音频的耳机入口可单击打开预览。

将卡片拖到另一张卡片上会交换两项顺序，即使多选也只交换实际拖起的一项；拖到文件夹仍可处理所选文件。手动顺序持久保存，媒体库和目录共用；“恢复时间排序”可重置。相似搜索按相似分排序。

缩略图宽度分自定义／小／中／大，最小卡片宽度为 192 px。设置中的“缩略图短边上限”控制加载分辨率，极长图的最长边最多 4096 px；卡片宽度决定显示大小，两者不同。

侧栏“挑一挑”随机展示图片、视频、音频，可切单一类型、换一批或回到上一批。点击预览，心形标记“喜欢”，标签图标选择其他标签；该页不提供批量整理或拖动管理。心形和标签操作在悬停或键盘聚焦时显示，移开鼠标后收起，已喜欢的心形仍为红色；触屏设备保持操作入口可见。媒体库使用相同规则。

## 4. 搜索、标签与筛选

文字搜索匹配**文件名、标签、个人描述，不匹配路径**。多个词同时满足；支持 `name:`、`tag:`、`desc:`、短语引号、排除 `-`、任选 `OR`、括号和 `has:desc`，不支持正则。问号菜单提供示例：

```text
tag:风景 -tag:模糊
(tag:风景 OR tag:城市) desc:夜景
name:"IMG 001" has:desc
```

机器人图标切换画面搜索，输入描述后按 Enter；再次点击恢复原文字搜索词。两种查询不叠加，已应用筛选继续生效。点击图片图标、粘贴或拖入图片可以图搜图：“AI 找相似”需要 Qwen 图片索引；“找重复图”使用本地感知哈希和颜色，无需 AI。最低相似分只过滤已返回的前 100 项，换参考图或范围才重新比较。模型准备见 [AI 接入](03-ai-services.md)。

筛选按标签分组，可搜索标签名称及分组名称。“未分组”在分组筛选、排除标签、快捷菜单和标签编辑中固定排在最前，其余分组按名称排序。内置“喜欢”在所属分组及已选标签中置顶；存储名称统一为“喜欢”，旧版 `like` 自动迁移并保留收藏关联。同组多选是“任一”，跨组是“同时满足”；排除标签去掉相应媒体，“没有自定义标签”查无自定义标签的媒体。比例、尺寸也可同时应用。

筛选面板有独立草稿：“应用筛选”才更新结果，“重置”恢复打开时条件，“清空全部筛选”清空草稿，关闭放弃未应用修改。卡片右键及多选标签菜单也支持分组与名称搜索。

“设置 → 标签配置”支持新建分组、标签、改名、选色、拖动或“移动到”调整分组。删分组只将标签移入“未分组”，保留媒体关联；标签改名同步自动打标规则。内置“喜欢”不可改名。扫描不自动把提示词、模型、采样器、LoRA 转成标签；有需要时配置显式自动打标规则。

## 5. 预览、描述与生成信息

媒体预览使用桌面查看器布局：顶部集中编辑、制作、旋转、收藏、下载和删除，底部显示规格、列表位置及缩放，右侧保留描述／生成信息／元信息页签。标签只在描述页签显示，编辑使用独立弹窗；双击卡片即可预览，不再提供重复的“逐张查看”菜单。筛选为主内容区内的无整页遮罩面板，标签配置提供一排预设颜色，喜欢默认红色。

双击媒体库卡片或点击音视频播放入口打开统一预览。底部信息按钮控制右侧信息栏，× 关闭；不会自动换下一项。图片滚轮缩放，方向键或 Ctrl / Cmd + 滚轮切换，音视频使用播放器控件。系统启用减少动态效果时关闭过渡。

**描述页：** 正文可展开、复制；编辑入口打开独立弹窗，避免挤压详情布局。AI 建议同样在弹窗中确认提示词和长度，生成后填入编辑区，保存描述后生效；失败保留草稿，取消不保存。临时指令不覆盖默认值。音视频描述交互相同，AI 按钮暂置灰；图片的 AI 参考提示词独立保存，不覆盖描述或原始生成信息。

**生成信息页：** 显示已有资源、正负提示词和参数，不补造缺失值。提示词和参数分别在弹窗中修改，“添加参数”补字段。原始文本只从“编辑原文”弹窗查看或修改，不在侧栏重复展开；只读媒体提供“查看原文”。弹窗说明解析规则并提供例子。不能安全拆分的 JSON／工作流保留原文；未归类字段仍保留。

- 资源支持 Checkpoint、LoRA、VAE、Upscaler、Embedding、ControlNet、LyCORIS、Hypernetwork；名称完整显示，可用权重随名称显示，哈希在悬停说明中显示。LoRA 可来自提示词中的 `<lora:名称:权重>`、参数行 `LoRA: 名称:权重`（权重可省略，多个名称用分号分隔），或末尾 `extraJsonMetaInfo` 的 `resources` 数组。同类型同名资源合并，手动权重和哈希优先，保留权重 0。ComfyUI 读取采样器实际使用的模型链路，关闭的 LoRA 不列为使用资源。
- 参数卡片、添加菜单与编辑标题使用英文名称，如 Sampler、Steps、CFG scale、Seed；卡片悬停显示中英说明。Size 使用 `宽度x高度`，如 `1024x1024`。原文格式是正向提示词、`Negative prompt:` 负向提示词、单独一行逗号分隔的英文参数；参数值含逗号时用双引号包裹。最后可附 `extraJsonMetaInfo: JSON 对象`。
- 生成信息和元信息页中的 ComfyUI 工作流显示为 `COMFY: 21 Nodes`（实际节点数），点击复制完整 JSON。优先 UI workflow，仅有 API prompt 时统计执行节点；支持 PNG 元数据及 JPEG/WebP 的 EXIF 工作流，识别不到就不显示。完整图只在点击复制时序列化。

描述、标签与生成信息的手工修改保存在数据库，不改写原媒体文件；工作区产物选为成果并同步到媒体库时继承这些信息。

## 6. 图片调整、保存与快照

静态图片可从预览工具栏的“编辑”进入图片编辑器，可保存副本或覆盖原图；动图禁用此入口。“制作”以当前媒体为素材在工作台创建独立制作文件，两个按钮悬停可查看说明。编辑器右上常驻图层、右下显示属性，左侧为选择／移动、裁剪、缩放、撤销／重做、原图对比。添加图片、文字、分组及画布入口在图层区。完整工具操作见 [图片制作](02-workbench.md#2-图片制作)。

裁剪和缩放分别调整选区与完整图片尺寸，都有比例预设；进入工具不改图层，应用才提交，取消可还原。改画布比例只改变边界，不缩放图层。选图共用媒体库搜索与筛选，卡片隐藏路径；添加／替换始终只显示图片，点击直接选入，眼睛按钮单独预览。

| 保存方式         | 结果                                                               |
| ---------------- | ------------------------------------------------------------------ |
| 保存副本         | 原目录生成不重名 PNG，保留透明区域；创建独立编辑记录               |
| 覆盖原图         | 确认后以原格式原子替换；更新同一记录，不累积历史版本               |
| 内容区／整个画布 | 前者取可见图层在画布内的包围范围，去四周画布空白；后者保留排版留白 |

导出读取原图，保留标签、描述和必要生成信息；失败保留原文件和编辑状态。保存后不退出，可继续编辑保存后的文件。再次打开成品恢复图层、文字、分组、画布和保存范围。未保存的媒体库会话仅在内存中，退出会提醒，不写工作区制作文件。

编辑数据位于项目数据目录的 `omnigallery-edit-history`：`records` 存当前文档，`assets` 用内容哈希去重保存 `.blob` 素材，`outputs` 关联成品。反复覆盖保留最初源图和当前图层需要的快照，清理无记录引用的素材。扫描跳过整个托管区，快照不会重复出现在媒体库。成品改名／移动但内容不变时仍能找回记录；单独复制成品到另一台机器不会带上独立编辑数据。

“设置 → 通用 → 项目数据目录”统一管理工作区素材、编辑数据与快照；桌面默认 exe 旁 `.local/project-data`，源码默认应用数据根下 `project-data`。迁移先复制校验，成功才切换，原目录留备份；失败继续原路径，拒绝覆盖已有同名数据区，新旧托管区均排除扫描。备份需同时保留数据库、项目数据和原媒体。目前可恢复编辑只用于静态图片。

## 7. 音视频播放

音频读取本地标题、艺术家、专辑、时长及内嵌封面；也识别同名封面或 `cover`、`folder`、`front` 图片。“元信息 → 音频元数据”显示标题与封面来源，便于区分文件名和内嵌歌曲名。歌词优先同名 `.lrc`、`.srt`、`.vtt`、`.txt`，其次内嵌歌词；时间戳随播放高亮，点击可跳转，无时间戳按正文显示，不联网找歌词。

本地 MP3、FLAC、OGG、M4A、WAV、WMA 可通过“编辑歌曲信息”浮层修改歌曲名、艺术家、专辑，替换或移除内嵌封面；OGG 支持 Vorbis、Opus、FLAC、Speex 音频。封面支持 JPEG／PNG／WebP，最大 8 MB、2400 万像素。保存写入各格式原生标签，不重新编码声音，保留歌词及其他标签；清空歌曲名后显示文件名，移除内嵌封面后仍可使用同名或目录封面。保存时暂时释放播放器，完成后恢复播放位置与状态。文件已被其他窗口修改时拒绝覆盖，需重新读取；被外部播放器占用时提示停止使用后重试。裸 AAC 保持只读；格式损坏、内容与扩展名不匹配、只读模式及工作区产物不提供写入入口。标签写入能力与浏览器能否播放该编码独立。文字轨的导入和下载见 [音频制作](02-workbench.md#5-音频制作)。

收录按扩展名，播放能力取决于 WebView2／浏览器和系统解码器，后端不实时转码；能显示 PyAV 提取的封面不代表能播放。MP4＋H.264＋AAC 通常兼容较好；HEVC 取决于系统扩展，其他容器还取决于内部编码。无法解码时，桌面版可主动选择本机应用打开，浏览器可下载原文件。

大视频用 HTTP Range 按需读取，每次最多 1 MiB；相邻项不加载原视频／音频。视频封面最长边不超过 1280 px，同时最多解码两张。首次封面、远距离跳转及高码率播放仍受磁盘、容器索引和解码能力影响。

## 8. 导出与快捷键

导出可选浏览器下载 ZIP，或保存到**后端机器**的应用归档目录。归档默认是应用数据根下 `exports`，源码为 `.local/exports`，桌面为用户应用目录；界面显示实际路径。“设置 → 通用 → 归档目录”或导出窗可修改，改目录不移动旧 ZIP。“压缩 ZIP 内容”只改变压缩方式。

| 按键                          | 操作／范围                                 |
| ----------------------------- | ------------------------------------------ |
| PageUp / PageDown；Home / End | 鼠标在媒体列表上：翻屏；到已加载开头／末尾 |
| Ctrl / Cmd + A                | 媒体列表全选已加载，再按取消               |
| ↑ / ←；↓ / →                  | 预览上一项／下一项                         |
| Esc                           | 关闭预览                                   |
| + / − 或滚轮                  | 图片缩放                                   |
| Ctrl / Cmd + 滚轮             | 切换预览媒体                               |
| 0；R                          | 图片恢复大小、位置、旋转；向右转 90°       |
| Delete                        | 编辑器删除选中图层，输入框除外             |

设置页可录入下载、删除、切换标签等自定义快捷键，固定项不可改；冲突会提示。输入文字或编辑元信息时不触发预览快捷键，播放器聚焦时保留原生按键行为。
