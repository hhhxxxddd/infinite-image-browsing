## 收录与目录

添加已有媒体目录后，扫描器建立索引，原文件留在原位置。按扩展名收录图片、视频和音频，写操作受目录权限与只读模式约束。

“目录”展示已添加根目录和节点关系图，可设置别名、预设或上传图标；图标同步用于节点、侧栏和子文件夹。展开状态与浏览位置会保留。

进入文件夹后依次为结果工具栏、目录导航、子文件夹。导航左侧返回上级和显示路径，右侧提供“包含子目录”、新建及更多操作；读取进度紧邻递归开关。子文件夹过多时可横向滚动。

普通媒体库浏览已索引内容，目录浏览直接读取磁盘；“包含子目录”逐级读取，也能显示未扫描的媒体。原文件变化后重新扫描，保留原媒体 ID、收藏、自定义标签、描述、手改生成信息和 AI 注释，刷新尺寸与文件派生索引。

“分享目录链接”复制当前应用中的目录地址，供再次打开或访问同一服务的人使用；它不上传文件，也不授予权限。

## 查找与整理

顶部搜索覆盖文件名、标签、描述与生成信息，支持字段、排除、分组和短语。筛选可组合类型、标签、分组与尺寸；修改先保留为草稿，应用后更新结果。

配置本地图文模型并建立图片索引后，可按画面描述、参考图片或近重复查找。分数表示本次相对排序，不是识别概率；音视频不进入图片向量索引。

列表按原比例混排，支持小／中／大缩略图与信息开关。普通单击累计选择或取消选中项，Shift 连选，双击预览。自定义排序可拖动交换位置，也可按日期排序；分页追加保留当前选择。

收藏或快捷标签直接切换，批量标签提交最终集合，重试不会反向切换。扫描不默认把生成信息转换为自定义标签。

选中项可复制、移动、归档、删除或导出。复制目标必须是已有文件夹，媒体或同名 TXT 侧车已存在时拒绝覆盖；批量继续模式跳过失败项并报告原因。文件重命名同步侧车、工作区素材与图层引用，失败回滚该媒体及侧车。

目录改名、移动更新应用引用；压平先检查子目录之间、目标目录已有文件和侧车的名称冲突，再逐项移动。压平可能部分完成，失败项会报告原因；删除目录要求为空。

“挑一挑”按类型随机提供批次，保留最近批次的前后浏览、收藏、标签与共用预览。

## 预览与制作

顶部集中操作和文件名，底部显示规格、列表位置与缩放，右侧为描述、生成信息、元信息；标签在描述页签。窄窗口信息区移到画面下方。

图片预览支持缩放、平移、旋转、全屏和对比。“编辑图片”进入图层编辑器，可保存副本或覆盖当前原图，重新打开恢复最新编辑文档。变换、裁剪、文字、分组和保存说明集中在[图片制作](02-workbench.md#图片制作)。

“制作”可直接选择已有或新建工作区、已有或新建作品，无需先进入工作台。取消不创建数据，成功保存制作文件后进入编辑器。

生成信息只展示解析到的提示词、资源、工作流和参数，不推断缺失字段。ComfyUI 支持 API 图及工作流；不支持的生成格式仍可查看原始元信息。

音频预览显示歌曲名、封面和可读取的歌词。本地 MP3、FLAC、OGG、M4A、WAV、WMA 可编辑歌曲名、艺术家、专辑及内嵌封面；裸 AAC 只读。保存保留声音和其余标签，检查文件版本，播放期间释放文件后恢复位置。

普通预览不实时转码，播放取决于浏览器／WebView2 及系统解码器。封面可读取不代表文件可播放；可下载原文件，桌面也可选择本机应用打开。大视频用 HTTP Range 按需读取，不预载相邻原媒体。

## 导出与快捷键

ZIP 可浏览器下载，或保存到后端机器的应用数据目录下 `exports`。导出窗口显示实际路径，归档随整个应用数据目录迁移，不再单独设置位置，见[存储与备份](04-storage.md)。

图片缩略图和自动视频封面可在设置中清理，后续浏览时重新生成；手动选择的视频封面属于持久数据，会保留。

| 范围     | 按键                        | 操作                     |
| -------- | --------------------------- | ------------------------ |
| 媒体列表 | PageUp／PageDown、Home／End | 翻屏、到已加载开头／末尾 |
| 媒体列表 | Ctrl/Cmd+A                  | 全选已加载，再按取消     |
| 预览     | 方向键、Esc                 | 切换媒体、关闭           |
| 图片预览 | +／−、滚轮                  | 缩放                     |
| 预览     | Ctrl/Cmd+滚轮               | 切换媒体                 |
| 图片预览 | 0、R                        | 复位、旋转 90°           |

自定义快捷键在设置中管理。文字输入、嵌套编辑弹窗及播放器保留所属控件的按键行为。
