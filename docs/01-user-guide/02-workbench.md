# 工作台

[文档导航](../README.md) · [媒体库](01-media-library.md) · [AI 接入](03-ai-services.md)

## 层级与浏览

| 对象     | 用途                                                     |
| -------- | -------------------------------------------------------- |
| 工作区   | 项目容器，组织作品及共用素材，支持封面、目标、颜色和搁置 |
| 作品     | 要完成的内容，包含制作文件与成果，可跨媒体类型           |
| 制作文件 | 持续编辑的图片画布、音视频时间线或 AI 制作记录           |
| 产物     | 导出文件或 AI 结果，可供其他制作文件引用                 |
| 成果     | 作品选定的交付文件，可保留多版本，只有成果可同步媒体库   |

首页以封面卡展示工作区，工作区内以横向卡展示作品，作品内以文件式卡展示制作文件。工作区与作品均有最近使用、创建日期、更新日期排序，日期可双向排列并分别记忆。作品更新日期包含制作文件修改，打开只更新使用时间。

顶部路径提供层级导航，工作区和作品左上有轻量返回；作品返回所属工作区，刷新保持工作区视图。“工具配置”管理工作流等配置，再次点击返回此前页面。

工作区和作品可修改名称、目标与颜色；自动配色按稳定 ID 分配。首页星空每 30 秒轮换，隐藏或减少动态效果时暂停。

## 素材与制作文件

工作区素材分引用、产物，两组紧凑多列显示，数量较多可继续加载。引用只保存原路径，移出引用不删除原媒体。

作品先展示标题，再展示素材条和“制作／成果”。素材可切换全部／已使用，支持横向滚轮、边缘轻微回弹、悬停预览及右键菜单。展开后使用类型与来源两组标签，组合搜索。

“新建制作文件”选择图片、视频、音频或 AI 图片。点击制作卡名称／预览继续编辑，点击产物数量查看历次结果。媒体库也可直接选择或新建工作区与作品并创建制作。

编辑器提供工具介绍与快捷键。保存失败保留内容，跨窗口冲突拒绝覆盖；可按提示保留未保存副本后重新读取。

## 图片制作

图层支持图片、文字、分组、排序、显隐、锁定、变换、裁剪、笔记和撤销。改画布不自动缩放图层，导出可选择整张画布或内容范围。

整张画布、分组或单层可建立同作品中的独立 AI 编辑分支，输入固定为快照，可继续或新建。来源入口返回原制作文件，切换前等待保存成功。画布导出与 AI 结果分别记录。

## 音频制作

多音轨支持音频和视频第一条声音轨、移动／跨轨移动、裁边、分割、复制、音量、淡入淡出、静音／独奏／锁定及撤销。无音轨视频不能添加，源视频不修改。

提供播放头、选区、循环、缩放、吸附与标记。声音可设 0.25–4 倍速并选择保持音调，后续片段和文字不自动移动。电平表及导出检查提示过载，没有自动限幅或 LUFS 归一化。

文字轨支持歌词／字幕、片段内编辑、拖动与裁边。导入 UTF-8 LRC／SRT／VTT／TXT，下载 LRC／SRT／VTT，可选整轨或选区。文字独立下载，音频产物只含混音。

试听按短窗口渲染，导出 WAV／MP3 工作区产物，需要 FFmpeg 和 ffprobe。当前没有录音、降噪、均衡器或自动转写。

## 视频剪辑

画面、声音、字幕和标记支持移动、裁切、分割、速度与属性调整。视频可同时进入画面／声音轨或只加入一轨，预览原声由声音轨播放。

导出 H.264／AAC MP4；图片只用静态首帧，画面按比例放入黑底画布。当前没有转场、关键帧或动态图播放；最长 60 分钟、3840 × 2160、60 fps，画面与声音各 64 片段、256 字幕，见[实现与限制](../02-development/08-video-editor.md)。

## AI 图片与工作流

同一 AI 制作文件可切换图片生成／编辑。生成用文字和参数，编辑用主图、参考图、可选遮罩、批注和裁剪；输入尺寸与输出尺寸分别设置。AI 音频／视频只有不可提交的入口。

工具配置导入 ComfyUI API JSON，映射输入、提示词、结果与可调参数。自动识别仅提供初始建议；生成工作流不接受图片输入，编辑按实际输入改写提交副本。

后端执行任务，关闭页面不丢失已提交任务的结果。每张结果独立保存，部分失败保留成功结果；编辑结果与提交时源图对比，源图不随后续编辑变化。

Comfy 并发 1–15，默认 2；重启标记跟踪中断，不重放付费请求。验证连接只检查认证，额度、模型、节点和输出继续由实际任务校验。云任务上传实际输入并消耗额度。

## 成果与备份

产物选入成果后可同步到已添加媒体库目录，副本与工作区原产物分别保留，支持查看或覆盖。删除工作区记录不删除已同步媒体。

工作区、作品、制作文件、图层与 AI 状态保存在 SQLite；产物和输入快照使用项目数据目录。浏览器与桌面可共享同一数据库，各自保存界面偏好。备份需同时包含数据库、项目数据和原媒体。
