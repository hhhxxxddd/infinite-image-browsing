# 02 · 工作台

[文档首页](../README.md) · [媒体库](01-media-library.md) · [AI 接入](03-ai-services.md)

## 1. 工作区、作品与制作草稿

工作区是项目容器，保存共享素材、业务作品和成果。工作台一级导航为工作区、图片制作、音视频制作、AI 创作和工具配置。

**作品按想完成的内容命名，不选择媒体类型。** 例如“某某短剧”可以同时使用图片、配乐、旁白和视频。每件作品有自己的目标、制作草稿和成果；一个工作区只放一件作品也可以。

- **工作区素材：** 统一引用图片、视频或音频，各作品和制作入口共用同一素材池。工具保存或 AI 生成的产物进入工作区素材，不自动选为作品成果；“下载图片”仍只下载文件。旧作品关联的文件和旧工作区成果继续保留在共享池中。
- **制作草稿：** 图片画布、视频剪辑、音频制作或 AI 加工的编辑记录。类型属于草稿，不属于作品。一件作品可保存多张画布、多份配音或剪辑安排，以及多份 AI 加工草稿。每份草稿有自己的名称与笔记。
- **成果：** 用户选定用于交付或展示的文件，可来自工作区产物或媒体库已有文件，可放不同版本，也可在其他草稿中再用作素材。当前不自动记录版本关系或修改上游草稿。

工作区首页点击作品进入总览，在制作草稿和成果间切换，不要求按某个固定顺序创作。新建作品只填写名称与目标，进入总览；新建制作草稿选择制作方式后打开。顶部工具切换保持当前作品，分别列出该作品对应的草稿；可从当前作品栏回到总览或切换作品。作品总览的“已使用素材”默认收起，自动汇总图片草稿的图层引用、AI 草稿当前保存的主图及参考图，并显示使用它们的草稿；不把素材池中的未用文件或刚生成的产物算作已使用。音视频轨道尚未接入实际编辑，因此目前不生成轨道素材的使用记录。

图片草稿继续使用真实图层编辑器，其标签页和存储按所属作品隔离，保留原有文档。音视频草稿目前为制作布局预览，可预览源文件和记录草稿笔记；裁剪、混音、时间定位和导出尚未接入。AI 图片编辑的主图、参考图、批注、裁剪、加工入口选择、工作流参数、提示词及使用历史按制作草稿隔离；切换作品、草稿或离开 AI 页之前保存修改，保存失败或裁剪尚未完成时保留当前会话。图片生成、AI 音视频仍为占位入口。后台结果仍保存在原工作区，可在其他草稿中引用，或手动选为作品成果。

业务作品与制作草稿记录保存在本机 localStorage；工作区记录仍使用原有配置存储。窗口间共享文件与草稿更新，当前工作区和作品选择保持独立。旧版按媒体类型创建的作品转换为业务作品，并保留其中的制作草稿、目标和文件关联；旧存储键作为迁移备份保留。未关联的原有图片草稿汇总到“原有图片创作”，不会修改文档内容。

改名、删除画布只影响制作草稿，不改变业务作品名称；即使删完草稿，作品仍保留。删除作品会清理其中本机草稿，原媒体及保存的成果保留。删除工作区会清理其本机记录、草稿和工作区产物，原媒体和已同步到媒体库的副本保留。旧工作区笔记可在“工作区笔记”中查看。

工具配置管理全局工作流，不依赖当前工作区；媒体 AI 描述、参考提示词和已有标签推荐仍在设置中管理。

## 2. 图片制作

图片制作与 AI 创作共用工作台上层的“素材”条，同一横向素材条始终保持产物组在前、引用组在后；使用过的图片只在各自来源组内前置。未使用产物按最新优先排列，空分组不显示。取消主图、参考图或删除图层不会撤销组内前置位置。产物缩略图底部固定显示“产物”色签，具体来源在悬浮预览中显示。支持滚轮横向浏览、图片悬浮预览、素材点击预览和“全部”浏览；可搜索名称、筛选引用／产物，从媒体库加入素材。图片／视频／音频分类始终可见，不适用的类型置灰。缩略条分批加载，展开列表只渲染可见行。图片制作的草稿列表位于素材条下方，展示当前作品中可继续编辑的图层草稿，并提供新建入口。

图片草稿卡片可直接“保存为素材”（新导出默认 PNG、内容区）或选择扫描目录“同步到媒体库”。已保存的同一版本会复用已有素材；编辑器内保存也记录对应草稿版本。卡片显示“已保存／已收录”标记，悬停说明含义；修改草稿后须重新保存当前版本，自动保存时间变化不影响标记。只有同步并成功索引的版本标记为已收录。删除草稿保留已有产物与媒体库副本。

工作台图片编辑器在画布下方显示素材条，媒体库图片编辑不显示。底部素材条与外部共用单行容器、悬浮说明、缩略图、分组和排序：产物组在前、引用组在后，使用过的图片在各自组内前置，删除图层后也不归位，记录按工作区保存在本机；未使用的产物最新优先、引用保持原顺序。两组用分隔线区分，不显示组名和数量。左上角为媒体类型、底部为产物色签，右上角勾选表示“已使用”，悬浮可查看完整说明。支持箭头、滚轮横向浏览和悬浮预览；默认点击添加图层，选中未锁定的图片图层后可切换为替换。右侧网格图标浏览全部工作区图片，“＋”从媒体库补充素材；最右侧上下排列“添加图层／替换图片”模式。编辑器原有的添加／替换图片入口统一打开媒体库选择器，选中的图片先加入工作区，再用于当前画布。

首页展示当前作品的图片草稿卡片、缩略图、尺寸、图层数和保存时间，可新建或继续上次草稿。打开后与媒体库图片调整共用编辑器：左侧工具，右上图层，右下属性；两区独立滚动，分隔条可拖动或用上下方向键调整高度。新增图片、文字、分组和画布入口位于图层区。

- **裁剪／缩放：** 分别调整选区／完整图片，支持边角拖动、比例、输出尺寸与保持比例。进入不改图层，应用提交一次可撤销修改，再点当前工具可取消。文字和分组不支持这两项工具。
- **图层／分组：** 可双向排序、移入或移出分组。拖到目标行整行高亮，顶部／底部“拖动到此”可移出分组并置顶／置底。分组数量跟在名称后，隐藏和锁定可直接点击。Delete 删除所选对象，文本输入时不拦截。
- **画布／填充：** 改画布尺寸以中心为锚点平移图层，不缩放内容；超出部分仍保留，可扩大画布或撤销恢复。图层属性的“填满”按比例覆盖边框、可能裁掉内容，“完整显示”保留全图、可能留白，“拉伸”按边框改变比例；内容放大也在此设置。图片菜单“铺满画布”会拉伸图层到画布大小。棋盘格仅辅助查看透明区域，透明和棋盘格都导出透明像素。
- **保存范围：** 默认内容区取画布内可见图片和文字的旋转包围范围，排除隐藏、全透明和编辑批注；去四周空白，保留图层间距与图片内部留白。“整个画布”保留全部画布边界，不改变草稿坐标。

左上保存条固定显示范围和保存操作；裁剪／缩放的取消、应用留在右下工具区。“保存图片”生成工作区素材，支持 PNG／JPG，可同时选媒体库目录同步；“下载图片”只下载文件。使用原尺寸素材，均不覆盖源文件。

工作区图层草稿自动保存在当前浏览器，返回前立即保存，失败留在编辑器提示。关闭返回图片草稿列表，卡片名称旁可直接重命名或删除草稿；删除须确认，仅清除图层草稿，保留业务作品、源素材和已保存的图片。删除最后一个图片草稿后显示空列表，可重新创建。合成结果与浏览器草稿独立，合成图本身不携带完整草稿。媒体库入口则只在显式保存时持久保留编辑文档与快照，见 [图片调整](01-media-library.md#6-图片调整保存与快照)。

选中图片、分组或整张画布后可“合成 / AI 加工”，先核对预览和实际输入，再选内容边界或完整画布。遮罩白色允许修改、黑色保留；独立遮罩通道需要已配置相应连接的工作流。

## 3. AI 图片编辑

AI 创作的“图片生成／图片编辑／音频创作／视频创作”切换条位于公共素材条下方。图片生成和图片编辑浏览图片，音频创作浏览音频，视频创作的素材条混合展示图片、视频和音频，在“全部”弹层内可按类型筛选，不影响上方素材条。没有素材时保留完整素材条和添加入口。顶部素材条只提供普通素材浏览与添加，不显示主图／参考图用途。在同一 AI 草稿内切换子页会保留图片编辑会话，隐藏时暂停画布渲染。离开 AI 工具或切换作品、草稿前保存当前会话，再进入时恢复；也可手动保存草稿。

进入 AI 创作不会自动打开编辑器，点击对应的打开按钮后进入全屏界面。全屏右上角、关闭按钮左侧提供四类创作切换；图片生成、音频创作和视频创作目前显示占位页，底部按对应媒体类型展示素材。切换功能保留图片编辑会话。

图片编辑在独立全屏界面中进行：中央单图画布、左侧批注／涂抹／遮罩／裁剪工具，右侧可折叠图像设置与 AI 加工，不提供图层面板。顶部可保存草稿或将当前编辑图保存为工作区素材；关闭返回工作台，再次进入保留当前编辑会话。编辑器底部复用素材条，只有这里提供主图／参考图选择与右键操作，“全部素材”向上展开。

素材左上角显示图片／视频／音频类型；编辑器底部素材右上角用“主／参1”等短标记表示用途，悬浮预览显示完整名称。产物色签位于底部，工作区创建内容用淡黄色区分。引用组内保留选用历史，取消用途仍保留位置；产物始终留在产物组，使用过的产物在组内前置，其余按新到旧排列，未完成任务显示在产物组前部。同步媒体库不改变原素材来源。

滚轮横向浏览，不带动页面；两侧箭头可点击滚动，到达边界时置灰。初次显示 16 项，继续浏览追加，悬停约 200 ms 展示大图与名称，滚动或操作即关闭。“全部”提供名称搜索、来源筛选和虚拟网格。已用作主／参考图的卡片点击切换编辑，其他卡片点击预览，右键设置用途。

### 批注与提交

两种加工入口都通过“提取批注”手动生成提示词，提交仅使用文本框内容，不暗中追加说明：

| 批注 | 提取文本 |
| --- | --- |
| 提示框 | `修改方框内的区域: {批注内容}` |
| 箭头 | `修改箭头指向的区域: {批注内容}` |
| 涂抹 | `去掉涂抹标注，并编辑其覆盖的区域: {批注内容}` |

只提取当前加工范围内可见、有文字的批注，每条一行，按编号升序，同号保留图层顺序。再次提取更新未改写段落，保留人工修改，并按需追加新内容。

首次保存前或存在未保存修改时，开始加工会提醒。“保存并开始加工”成功后才提交；返回编辑不提交。保存失败保留草稿，待应用的裁剪须先确认或取消。

### 后台任务与结果

提交后本地服务执行，页面可继续编辑、切换或关闭；结果自动保存到提交时工作区。排队／运行／失败卡片完成后替换为结果，失败可查看原因，不自动重复付费请求。

“设置 → AI 接入 → Comfy 连接”配置全工作区共用的并发，范围 **1–15，默认 2**。未完成队列上限为并发数两倍，至少 4 个；调高会放行等待任务，调低不中断正在运行任务。后台执行依赖本地服务继续运行；重启将未完成任务标为跟踪中断，超时不代表云端停止，应先核对云端再决定重提。

AI 结果可看结果图、滑动对比或并排查看，右侧显示生成信息。源图是**提交时主图快照**，不随后续编辑或改名改变；缺少快照会提示，不能拿当前草稿代替。快照随素材删除，同步媒体库后仍留在工作区。

信息分别保留本系统提交记录、结果文件内嵌生成信息、原始文件元信息；共用媒体库解析器。没有返回或记录的模型参数不推断补全，提交记录未必包括工作流默认值与云端运行时值。

## 4. Comfy 工作流

先在 [AI 接入](03-ai-services.md) 配置共用 Comfy Key。Router 使用已适配图像模型的比例／分辨率选项；Cloud 使用 Comfy API v2 上传素材、提交任务、查询与下载。

“工具配置 → 工作流”导入 **ComfyUI API 格式 JSON**，按用途分类、名称排序。未保存修改离开配置时需确认；保存或删除配置后，已打开的创作页自动刷新工作流列表。图形视图用于核对节点连接，并映射主图、参考图、可选遮罩、正负提示词和结果节点；自动识别只是初始建议，检查后保存。图片结果必须进入 v2 `outputs`，内容处理结果必须保存成文本文件，节点内预览不能替代文件输出。

未用参考图输入会在提交副本中断开，遮罩按本次选择改写，原工作流不变。多余参考图、未连接遮罩或已知节点组合限制会提示本次忽略的输入。

“可调参数”自定义名称、数值／文本／开关／选项及目标字段，一个选项可写多个字段；未覆盖项保留 JSON 默认值，不靠固定节点名推断。节点和模型须在云端可用，导入前移除凭证等敏感内容。“验证连接”只验证认证，不保证积分、订阅、节点权限或任务成功。

## 5. 数据与备份

工作区、工作流、任务和素材信息在数据库；创建文件及源图快照在项目数据目录的 `omnigallery-workspace-artifacts`。目录可在“设置 → 通用”配置迁移，与媒体编辑数据一起备份。

当前工作区、图层草稿及部分输入选择／提示词保存在浏览器 localStorage，**数据库备份不包含这些草稿**，浏览器与桌面 WebView 不共用它们。云端加工上传实际输入并消耗服务额度；未使用云端功能时，本地索引与编辑不上传文件。
