# 工作台

[文档导航](../README.md) · [媒体库](01-media-library.md) · [AI 接入](03-ai-services.md)

## 层级与浏览

| 对象     | 用途                                                     |
| -------- | -------------------------------------------------------- |
| 工作区   | 项目容器，组织作品及共用素材，支持封面、目标、颜色和搁置 |
| 作品     | 要完成的内容，包含制作文件与成果，可跨媒体类型           |
| 制作文件 | 持续编辑的图片画布、音视频时间线或 AI 制作记录           |
| 产物     | 导出文件或 AI 结果，可供其他制作文件引用                 |
| 成果     | 作品选定的交付文件，可保留多版本，只有成果可同步媒体库   |

首页以封面卡展示工作区，工作区内以横向卡展示作品，作品内以文件式卡展示制作文件。工作区与作品均有最近使用、创建日期、更新日期排序，日期可双向排列并分别记忆。作品更新日期包含制作文件修改，打开只更新使用时间。

顶部路径提供层级导航，工作区和作品左上有轻量返回；作品返回所属工作区，刷新保持工作区视图。“工具配置”管理工作流等配置，再次点击返回此前页面。

工作区和作品可修改名称、目标与颜色；自动配色按稳定 ID 分配。首页星空每 30 秒轮换，隐藏或减少动态效果时暂停。

## 素材与制作文件

工作区素材分引用、产物，两组紧凑多列显示，数量较多可继续加载。引用只保存原路径，移出引用不删除原媒体。

作品先展示标题，再展示素材条和“制作／成果”。素材可切换全部／已使用，支持横向滚轮、边缘轻微回弹、悬停预览及右键菜单。展开后使用类型与来源两组标签，组合搜索。

“新建制作文件”选择图片、视频、音频或 AI 图片。点击制作卡名称／预览继续编辑，点击产物数量查看历次结果。媒体库也可直接选择或新建工作区与作品并创建制作。

编辑器提供工具介绍与快捷键。保存失败保留当前内容；另一窗口修改或删除制作文件后，旧会话不能覆盖或复活它，需重新打开。未保存内容只在当前会话中保留。

## 图片制作

工作区制作和媒体库“编辑图片”使用同一图层编辑器，支持图片、文字、分组、显隐、锁定、笔记与撤销。右侧常驻图层及属性面板；点击空白处取消图层或分组选择，列表中的“画布”进入画布设置。图层显隐和锁定使用列表行图标，图片和文字的不透明度统一位于属性底部。参数滑条按“名称、重置、滑条、数值”单行排列，重置恢复默认值；已为默认值时按钮置灰。改画布尺寸不自动缩放图层。

### 变换、裁剪与文字

拖动选框八个调整点缩放，顶部圆点旋转；图片角点默认保持比例，Shift 切换约束，旋转时 Shift 对齐 15°。中键拖动或空格加左键平移视口并保留选择，“适应”居中复位。每次手势记录一次撤销，Esc 取消当前调整。

左侧缩放／裁剪按钮打开尺寸与比例面板，八种比例与图库筛选共用。裁剪选框可移动、八点调整，提供九宫格、尺寸与框外遮罩；输入宽高和拖动实时同步，固定比例时宽高联动。范围限制在图层边界内，支持小至 1 像素的选框；点击“应用裁剪”才修改图层，取消或 Esc 保留原图层。

“添加文字”提供标题、副标题和正文预设，文字模板尚未开放。右侧调整字体、字号、颜色、样式、行距、字距和对齐，也可按画布对齐、旋转及翻转。双击文字进入高对比编辑框，Ctrl/Cmd+Enter 完成，编辑框颜色不改图层颜色；预览、导出和重新打开使用相同排版。

文字效果提供纯色／双色渐变填充、描边、投影、外发光与背景。常用值和颜色直接修改，更多参数在对应行左侧的小浮窗内调整；支持启用、关闭及重置。效果随编辑文档保存，内容区导出包含文字效果超出的范围。

图片和文字共用“尺寸、位置、画布对齐、角度”布局，支持比例锁定、顺时针旋转 90°及水平／垂直翻转。文字对齐控制文字在框内的排版，画布对齐控制整个图层的位置。锁定图层或所属分组后，属性不可修改；在图层列表解锁后继续编辑。

图片的“填充方式”可直接切换三项：“填充”等比铺满并隐藏超出图层的内容，“完整”等比显示整张图片、允许留空，“拉伸”匹配图层宽高、可能变形。图片与图层比例一致时，三种方式效果相同。

文字、图片等图层共用分组入口：属性标题旁的归属标签和图层右键菜单支持移入／移出分组。Ctrl/Cmd 点击多选后可批量操作；图层区“新建分组”将选中成员归入新组，无选择时建立空组。锁定成员和锁定组不能更改归属。

分组和空分组均可拖动排序或上移／下移。选中组后编辑名称、显隐、锁定和位置，或解散并保留图层。整组选框移动全部成员（含隐藏成员），保持相对位置；组或成员锁定时禁止整组移动。点击成员行、双击组内画面或 Alt 点击可单选成员。方向键移动 1 像素，Shift 加速至 10 像素。

右键菜单保留复制、分组、排序和删除，图片单选另有替换入口；分组菜单提供复制、重命名、解散和删除组及内容。复制多选或整组时保留相对位置和文字效果，并生成独立图层。显隐、锁定和文字编辑沿用图层行与画布入口。

### 保存与导出

| 场景           | 行为                                                                                |
| -------------- | ----------------------------------------------------------------------------------- |
| 工作区制作文件 | 自动保存编辑文档，也可手动保存；导出到工作区或下载图片                              |
| 媒体库保存副本 | 默认 `原名_副本.原后缀`，确认名称后保存到原目录；同名报错，不自动编号，继续编辑原图 |
| 媒体库覆盖原图 | 校验打开时的文件版本，成功后更新当前编辑文档；原图已变化时拒绝覆盖                  |

保存范围可选内容区或整个画布。媒体库保存要求原图为单帧 JPG、PNG、WebP、BMP 或 TIFF，JPG 透明区域填白；单边最多 16384 像素、总像素不超过 1 亿。可编辑文档及素材快照需要随项目数据备份，只有导出图片不能恢复图层。

重新打开恢复完整图层与分组。保存遇到冲突先保留需要的内容，再重新读取，失败不会登记半成品。

整张画布、分组或单层可建立同作品中的独立 AI 编辑分支，输入固定为快照，可继续或新建。来源入口返回原制作文件，切换前等待保存成功。画布导出与 AI 结果分别记录。

## 音频制作

多音轨支持音频和视频第一条声音轨、移动／跨轨移动、裁边、分割、复制、音量、淡入淡出、静音／独奏／锁定及撤销。无音轨视频不能添加，源视频不修改。

提供播放头、选区、循环、缩放、吸附与标记。声音可设 0.25–4 倍速并选择保持音调，后续片段和文字不自动移动。电平表及导出检查提示过载，没有自动限幅或 LUFS 归一化。

文字轨支持歌词／字幕、片段内编辑、拖动与裁边。导入 UTF-8 LRC／SRT／VTT／TXT，下载 LRC／SRT／VTT，可选整轨或选区。文字独立下载，音频产物只含混音。

试听按短窗口渲染，导出 WAV／MP3 工作区产物，需要 FFmpeg 和 ffprobe。当前没有录音、降噪、均衡器或自动转写。

## 视频剪辑

画面、声音、字幕和标记支持移动、裁切、分割、速度与属性调整。视频可同时进入画面／声音轨或只加入一轨，预览原声由声音轨播放。

导出 H.264／AAC MP4，画面等比放入黑底，图片和动图只用首帧。当前没有转场、关键帧或动态图播放。

| 项目 | 上限                  |
| ---- | --------------------- |
| 时长 | 60 分钟               |
| 画布 | 3840 × 2160，宽高偶数 |
| 帧率 | 60 fps                |
| 片段 | 画面、声音各 64       |
| 字幕 | 256 条                |

开发契约见[视频编辑实现](../02-development/08-video-editor.md)。

## AI 图片与工作流

同一 AI 制作文件可切换图片生成／编辑。生成用文字和参数，编辑用主图、参考图、可选遮罩、批注和裁剪；输入尺寸与输出尺寸分别设置。AI 音频／视频只有不可提交的入口。

工具配置导入 ComfyUI API JSON，映射输入、提示词、结果与可调参数。自动识别仅提供初始建议；生成工作流不接受图片输入，编辑按实际输入改写提交副本。

后端执行任务，关闭页面不丢失已提交任务的结果。每张结果独立保存，部分失败保留成功结果；编辑结果与提交时源图对比，源图不随后续编辑变化。

服务配置、并发与任务边界见 [AI 接入](03-ai-services.md#在线服务)。

## 成果与备份

产物选入成果后可同步到已添加媒体库目录，副本与工作区原产物分别保留，支持查看或覆盖。删除工作区记录不删除已同步媒体。

工作区、作品、制作文件、图层与 AI 状态保存在应用数据目录的 `db`，产物和输入快照在 `project-data`；二者随应用目录一起迁移。多个窗口应连接同一个服务，各自保存界面偏好。备份和恢复见[存储与备份](04-storage.md)。
