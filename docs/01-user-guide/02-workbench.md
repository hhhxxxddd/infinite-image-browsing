## 层级与浏览

| 对象     | 用途                                                     |
| -------- | -------------------------------------------------------- |
| 工作区   | 项目容器，组织作品及共用素材，支持封面、目标、颜色和搁置 |
| 作品     | 要完成的内容，包含制作文件与成果，可跨媒体类型           |
| 制作文件 | 持续编辑的图片画布、音视频时间线或 AI 制作记录           |
| 产物     | 导出文件或 AI 结果，可供其他制作文件引用                 |
| 成果     | 作品选定的交付文件，可保留多版本，只有成果可同步媒体库   |

首页以封面卡展示工作区，工作区内以横向卡展示作品，作品内以文件式卡展示制作文件。工作区与作品均有最近使用、创建日期、更新日期排序，日期可双向排列并分别记忆。作品更新日期包含制作文件修改，打开只更新使用时间。

顶部路径提供层级导航，工作区和作品左上有轻量返回；作品返回所属工作区，刷新保持工作区视图。“工具配置”分为「内置工具」和「自定义工作流」，媒体库与所有工作区全局共用；再次点击返回此前页面。内置工具无需选择用途，只配置开放的默认参数；自定义工作流保留导入、用途、节点映射和删除。

内置消除、高清化、抠图分别使用 Qwen2.1、SeedVR2、SAM3，默认值全局共享，编辑器可按次修改。内置流程只读，可复制为自定义草稿后保存，不受自定义预设修改或删除影响。专用 SAM3 遮罩流程保留在配置中，不列入普通 AI 图片编辑候选。

工作区和作品可修改名称、目标与颜色；自动配色按稳定 ID 分配。首页星空每 30 秒轮换，隐藏或减少动态效果时暂停。

## 素材与制作文件

工作区素材分引用、产物，两组紧凑多列显示，数量较多可继续加载。引用只保存原路径，移出引用不删除原媒体。

作品先展示标题，再展示素材条和“制作／成果”。素材可切换全部／已使用，支持横向滚轮、边缘轻微回弹、悬停预览及右键菜单。展开后使用类型与来源两组标签，组合搜索。

“新建制作文件”选择图片、视频、音频或 AI 图片。点击制作卡名称／预览继续编辑，点击产物数量查看历次结果。媒体库也可直接选择或新建工作区与作品并创建制作。

编辑器提供工具介绍与快捷键。保存失败保留当前内容；另一窗口修改或删除制作文件后，旧会话不能覆盖或复活它，需重新打开。未保存内容只在当前会话中保留。

## 音视频共用操作

左上集中返回、文件名、保存、导出、撤销／重做、帮助和保存状态圆点，底部素材条默认“查看”。拖动空白框选，Shift／Ctrl 多选；关联片段一起移动和分割，锁定轨道限制相应编辑。删除只修改时间线，不删除源媒体。

右侧的“属性”显示常用时间与基础设置，“混音”集中声音处理，“工程”提供素材检查与制作版本；视频另有“精修”，切换动画、转场、裁切、调色、局部处理和精剪。当前选中内容决定可用控件。所选工具直接展示，次要数值列表、同步起点、预设及恢复副本用明确的“展开／收起”按钮查看。

播放头和入出点接受秒数或 `时:分:秒.毫秒`，Enter 或离开输入框确认，Escape 取消。I／O 设置入出点；未设置选区时显示“未设置”，清空任一端点可清除选区。也可拖出选区、拖动两端微调。左右键移动播放头，Shift 加大步进，选中片段后空格播放／暂停。刻度随缩放调整，轨道内容独立滚动，删除轨道后回收高度。

素材右键“选段添加”可先预览原片、输入源入出点，再加入播放头位置。视频制作可选音画一起、仅画面或仅声音，音频制作只取声音。多声音流素材可按语言、名称、声道和采样率选择，片段属性中也可切换；选择会随制作文件保存，试听、波形和导出使用同一流。声音晚于画面开始时保留前面的静音，不自动改变源入点。浏览器不能播放的编码仍可按源时间选段，播放效果需在主编辑器检查。

源文件移动或不可用时，用“重新指定素材”替换同一源的片段引用；也可在“工程 → 工程素材”查看健康清单，指定目录批量查找。同名冲突需手动选择，缺少所选声音流、时长不足或无法读取的候选不能应用。确认后一次替换引用，保留时间位置、源区间、属性与关联，可以一次撤销；原媒体不被修改。

属性可复制到同类选中对象，也可保存为工作区内共用预设。音频区分片段、音轨和总混音；视频区分画面和字幕，画面属性不会覆盖关联声音。素材路径和时间线位置不随属性预设改变。

“制作版本”可命名保存当前剪辑、预览后恢复。音频版本可试听，视频版本可连续播放音画或定位查看；预览不修改当前制作文件，恢复前自动保存当前内容。每个制作文件保留最近 30 个版本，容量不足时回收最早版本；版本保存剪辑指令，外部源媒体仍需可用。

制作文件损坏时会打开独立恢复页，可下载原始坏副本、浏览正常历史版本并恢复。恢复会先完整保留坏原文，再写入所选版本，成功后重新加载编辑器；没有正常历史时仍可下载原文。只读模式允许浏览和下载，不能恢复写入。

“导出产物”先确认名称和范围：有有效选区时默认选区，否则默认整条时间线，并显示起止位置与时长。确认后保存文档并提交后台任务，右上任务列表显示进度、取消和结果，离开编辑器后继续处理。结果对应提交时的版本，期间可以继续编辑。服务重启将运行中任务标记中断，排队任务可继续；响应不确定时核对原任务，避免重复创建。两类导出均需要本机 FFmpeg 和 ffprobe。

## 音频制作

### 剪辑与文字

声音、歌词与字幕在同一时间线编辑，支持复制粘贴、关联、移动、分割、裁边和波纹删除。波纹删除只闭合没有其他内容占用的空隙，锁定轨道不会被连带移动。文字轨支持片段内编辑，导入 UTF-8 LRC／SRT／VTT／TXT，下载 LRC／SRT／VTT，可选整轨或选区。文字独立下载，音频产物只含混音。可选择视频素材中要使用的声音流，无声音流的视频不能添加。

波形只加载当前可见范围，可分开显示左右声道、调整显示振幅与轨道高度；显示振幅不改音量。文字预览按需展开。开启音量曲线编辑后，可直接添加、拖动和删除片段内的音量点，也可输入时间和值；一笔拖动对应一次撤销，Escape 取消。

### 混音与检查

片段支持 0.25–4 倍速、保持音调、音量、声像、左右声道交换、转单声道、只取左／右声道和反转相位。淡入淡出可用手柄或数值调整，并选择直线、柔和、等功率曲线；相邻片段可交叉淡化。选区与片头／片尾接缝可循环试听。

音轨支持静音／独奏／锁定。将人声轨标为“对白”、音乐轨标为“音乐”并开启压低背景音乐后，混音会随对白降低音乐音量。轨道和总混音提供降噪、音色预设／手动三段均衡、动态压缩、减轻齿音、动态响度统一及限幅，默认关闭；可暂时旁路处理与原声对比。

“检查整段混音”异步测量整体响度（LUFS）、响度变化（LRA）和真峰值，并可定位采样过载区间，分析可取消。制作文件保留最近 8 份报告，重新打开仍可查看；混音、时长或源素材变化时标为过期，无法确认源版本时也禁用旧过载位置。只读可检查和查看，不能保存新报告。

### 试听与导出

试听提前准备后续混音块，用同一音频时钟连续衔接。开启会保留处理历史的声音效果、自动压低音乐，或改变速度并保持音调时，先在后台准备完整混音，再按当前位置读取，避免每段试听重新开始处理；可以查看进度或取消准备。暂停仍可观察准备进度；修改声音或离开后释放当前窗口的准备，其他窗口使用同一声音时计算继续。声音参数或原素材改变后重新准备，只改画面、文字或标记会复用声音。总混音处理关闭时，总音量实时生效。修改循环范围或开关循环时先暂停，重新播放使用新范围。导出为 WAV／MP3，任务完成后可试听产物或选为成果。

完整混音是磁盘缓存，可被容量回收，不会创建产物或成果。当前缓存预算为 20 GiB；长工程需要额外临时空间，空间不足会提示并停止。6 小时双声道混音本身约 8.3 GB，带背景音乐压低时预检会为中间处理按四份混音另留余量。首次准备耗时仍需用实际长工程验收。

| 项目         | 当前约束                                |
| ------------ | --------------------------------------- |
| 时间线       | 最长 24 小时                            |
| 声音轨／片段 | 最多 32 轨，每轨 256 段                 |
| 文字轨／片段 | 最多 8 轨，每轨 4096 段，每段 5000 字符 |
| 音量曲线     | 每片段最多 128 个点                     |
| 导出任务     | 音频单并发，排队与运行合计最多 4 个     |

不包含录音、新增导出规格或智能辅助。实现说明见[音频时间线](../02-development/07-workbench.md#音频时间线)。

## 视频剪辑

### 时间线与画布

多条画面轨、声音轨和字幕统一编辑，轨道支持顺序、显隐、静音／独奏和锁定。视频同时加入画面与声音轨时默认关联，也可解除后重新选择画面与声音关联；已有同步偏移会保留。“同步起点”可指定移动画面或声音，并输入偏移。支持框选、多选、复制粘贴、插入／覆盖、波纹删除和闭合空隙。时间属性按帧对齐，关联轨道锁定时显示原因并禁用受限操作。

时间线按当前刻度和可见范围抽取预览帧；放大、缩小或滚动时重新计算采样点。刻度随缩放切换帧、秒、分钟等间隔，声音轨显示对应范围的波形，不会预先抽完整部长视频。“适应”贴合实际内容，“适应选中”可放大短片段进行裁边；片段显示宽度对应真实时长。拖动吸附按屏幕距离判断，缩放后保持接近的操作手感。选中片段后空格播放／暂停，预览与时间线的分界线可拖动。

暂停时可在画布点选可见对象，拖动位置、边角等比缩放、旋转或裁剪；居中与边缘对齐提供辅助线。字幕也可直接点选和移动。工具只在选中时显示，播放时隐藏；锁定或只读时不能修改。拖动可用 Escape 取消，完整手势对应一次撤销。

精剪提供“滑移源区间”和“滚动交界”：前者保持片段位置与时长，改变所取源内容；后者改变两个紧邻片段的交界，保持两侧外边界。可按帧输入，并预览修改前／后的接缝；音画关联与轨道锁定继续生效。

字幕工作台支持搜索、多选替换、整体时间偏移和批量应用当前样式，导入／下载 SRT／VTT。每条最多 5000 字符，输入、批量替换和导出使用同一限制。字幕可设置字体、颜色、背景、描边、对齐、位置、自动换行和最大宽度；可显示画布内侧 5% 安全区辅助排版。

### 动画、转场与处理

画面支持位置、缩放、旋转、翻转、透明度、填充、源裁剪、定格及短片段倒放。位置、缩放、旋转和透明度可设关键帧；局部动画时间轴支持拖动、多选、数值修改、复制到播放头，以及线性、缓入、缓出、缓入缓出。拆分、裁边和滚动交界保留对应的动画区间。

叠化转场可调整实际重叠范围、时长和缓动曲线，关联声音随入场片段一起移动。它会改变入场片段的时间位置，区别于单个片段的淡入淡出；不支持复杂转场库。

颜色提供亮度／对比度／饱和度、曝光、色温、色调和伽马。局部处理可在小预览中绘制矩形或椭圆区域，进行遮罩、模糊和马赛克，调整反选、柔边及强度；每片段最多 8 个区域。区域随画面变换移动，透明遮罩会露出下层画面，未包含自动跟踪。

### 预览与导出

素材由后端读取尺寸、时长、编码和音轨，时间线只保存引用及剪辑操作。预览可选“自动／流畅／原画”：自动按素材尺寸和编码准备代理，流畅优先使用 720p 代理，原画直接播放原片。代理准备时可继续编辑，任务可取消、缓存可清理；缓存以 20 GiB 为回收目标，清理不影响原片。HDR 与可变帧率素材仍需检查色彩和音画同步。

预览按轨道顺序合成，导出采用相同剪辑数据并始终读取原片，输出为 H.264／AAC MP4。产物可在素材条预览或选为成果。图片与动图使用首帧，暂不支持 HDR 成片输出和专业色彩管理。

视频声音可调整声像、音量曲线、声道、淡化和轨道／总混音处理。需要保留处理历史或变速保持音调时，试听与导出共用完整混音；视频当前不提供对白压低音乐的轨道角色设置或整段响度报告。

| 项目       | 当前约束                                             |
| ---------- | ---------------------------------------------------- |
| 成片时长   | 最长 6 小时                                          |
| 画布       | 最多 3840 × 2160 像素面积；宽高为偶数，单边最多 3840 |
| 帧率       | 1–60 fps                                             |
| 轨道／片段 | 最多 32 轨，画面、声音各最多 256 段                  |
| 字幕／标记 | 最多 4096 条字幕、256 个标记                         |
| 关键帧     | 每片段最多 128 个                                    |
| 局部处理   | 每片段最多 8 个区域                                  |
| 倒放       | 单个片段最多 30 秒，长段需先分割                     |
| 导出任务   | 视频单并发，排队与运行合计最多 4 个                  |

导出按时间窗口逐层处理，避免同时解码全部片段；开始前估算磁盘空间，空间不足时停止并清理半成品。真实 UHD 短片已用于回归，大于 10 GB 的 4K 长视频仍需实机性能验收，尤其是复杂叠层、HEVC、HDR 和可变帧率素材。

开发契约见[视频编辑实现](../02-development/08-video-editor.md)。

## AI 图片与工作流

同一 AI 制作文件可切换图片生成／编辑。生成使用文字和输出参数；编辑使用主图、参考图、可选遮罩与批注。输入尺寸与输出尺寸分别设置。AI 音频／视频已提供基本布局：中央预览占位、右侧规划能力、右上类型切换；配音、音效、视频生成、编辑延长和口型等服务尚未接入，提交按钮不可用。

### 输入画布

主图和所有参考图同屏显示，点击图片后用左侧工具编辑。裁剪、尺寸共用图片编辑的宽高、比例预设、选框和重置操作；尺寸页直接显示填充、内容缩放与位置。主图还可涂抹、画遮罩、提示框和箭头，提示标注设置只在对应工具内显示。每张图独立保存并保留本次会话撤销记录，切换选择不会清空。

通过右侧“添加参考图”或底部素材条追加，图片上方可替换或移除；画布不显示多余的参考图占位。添加和恢复数量不受工作流限制，提交按当前模型／工作流能力取前几张，忽略超额参考图或不支持的遮罩时明确提示，原编辑内容保留。

左上集中返回、保存、导出、撤销／重做、帮助和保存状态圆点；右上图标提供 AI 类型、笔记和任务列表。左侧参数悬浮，不挤压画布。底部素材条默认“查看”，上方缩放栏与其左侧对齐。

滚轮缩放，中键或空格加左键平移；选择工具移动图片的查看位置，可适应全部输入或重新排列。位置只影响查看，主图和按编号排列的参考图仍分别提交，涂抹和提示标注合入图片，遮罩单独提交。图片编辑创建的 AI 分支使用固定主图快照。

### 工作流与结果

“工具配置 → 自定义工作流”导入 ComfyUI API JSON，映射输入、提示词、结果和可调参数。自动识别只是初始建议；生成工作流不接受图片输入，编辑按实际输入改写提交副本。内置图层工具的设置和执行边界见[图片编辑](05-image-editor.md#内置-ai-工具)。

提交后自动打开任务列表浮层，进度和结果不占用右侧参数区。任务区分上传、云端排队、处理和获取结果，可刷新、取消、继续跟踪及预览；结果与提交时主图对比，不随后续编辑变化。每张结果独立保存，部分失败保留成功部分。

图片生成完成后，中央直接展示生成结果，可切换多张图片、缩放、拖动与适应视图；刷新后恢复所选结果，新完成任务会自动展示。只显示当前工作区和制作文件的生图结果，图片编辑结果仍从任务列表查看。

关闭页面不丢失已提交任务。已有云端编号的任务可在后端重启后继续查询，断线多次失败时用“继续跟踪”；取消需云端确认，完成太晚无法取消时仍保存结果。无编号的未知 Cloud 提交不自动补发，具体边界与并发配置见 [AI 设置](03-ai-services.md#在线服务)。

## 成果与备份

产物选入成果后可同步到已添加媒体库目录，副本与工作区原产物分别保留，支持查看或覆盖。删除工作区记录不删除已同步媒体。

工作区、作品、制作文件、图层与 AI 状态保存在应用数据目录的 `db`，产物和输入快照在 `project-data`；二者随应用目录一起迁移。多个窗口应连接同一个服务，各自保存界面偏好。备份和恢复见[存储与备份](04-storage.md)。
