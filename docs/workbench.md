# 工作台：素材、图片制作与 AI 创作

## 工作区与素材

按作品或任务创建工作区，填写名称和可选目标。工作区可搁置、恢复或删除。顶部在“工作区”“图片制作”“AI 创作”“音视频工具”间切换，工具共用当前工作区素材。目前图片编辑已接入 AI 加工；图片生成、音频创作、视频创作和音视频工具仍为功能占位。

| 来源 | 存放方式 | 后续使用 |
| --- | --- | --- |
| 媒体库引用 | 引用已索引的图片、视频或音频，不复制文件 | 保留原文件位置；在应用内改名后更新引用 |
| 工作区创建 | 图片制作保存的图片和 AI 加工结果，独立存储，不参与媒体库扫描 | 可继续加工，也可主动同步到媒体库 |
| 成果 | 从媒体库引用已确定的作品 | 用于记录任务的最终作品，不复制文件 |

选择媒体库素材时可用文字搜索、筛选、画面搜索和以图搜图，缩略图打开浮层预览。名称隐藏末尾的文件后缀；图片／视频／音频以缩略图左上角角标显示，与“挑一挑”一致。工作区创建内容在右下角显示“图片制作”或“AI 加工”来源角标。

两种来源都可填写描述、标签、生成信息及反推提示词。修改保存在数据库中，不改写图片；AI 结果可从工作区素材右键菜单进入“编辑素材信息”。同步到媒体库会复制结果文件，并继承已填写的信息和标签；工作区原素材继续保留。同步副本与原素材此后独立管理，不持续双向同步。

### 引用与删除

在应用内重命名媒体库文件时，工作区素材和成果引用同步更新。进入工作台还会按媒体 ID 校正引用，并迁移本机图片草稿、AI 主图及参考图路径。直接在系统文件管理器中改名不属于这条同步流程。

工作区创建素材可在总览、AI 素材条和“全部”面板右键删除。确认后删除文件、源图快照、素材信息及相关本机 AI 草稿和引用；已同步到媒体库的副本保留。图片制作画布若仍引用该素材，会提示图片不可用。

删除整个工作区会清理其记录、笔记、本机草稿、后台任务记录和创建的素材；媒体库原文件与已同步副本保留。已经提交到云端的任务可能继续运行，但本地完成处理不会向已删除的工作区保存结果。

## 图片制作

图片制作支持多个草稿，画布可添加图片、文字、分组、提示框、涂抹标注和遮罩。属性面板编辑所选对象；画布内滚轮缩放，撤销与重做位于缩放按钮左侧。草稿保存在本机浏览器，可重命名或删除。

“保存为素材”把合成图写入工作区，支持 PNG 或 JPG，也可同时选择一个媒体库扫描目录同步。“下载图片”只下载文件，不会加入工作区。原始媒体文件不因编辑而改变。

选中图层、分组或整张画布后，可打开“合成 / AI 加工”。先核对作品预览和实际输入，再选择内容边界裁切或完整画布。遮罩中白色允许修改、黑色保留；需要独立遮罩通道时，使用已配置相应连接的工作流。

## AI 图片编辑

### 素材条与“全部”

素材条只显示图片，以方形缩略图呈现。主图／参考图用途在左上角，来源或任务状态在右下角。工作区创建素材以淡黄色底色和边框区分，“素材”标题的提示说明来源。同步媒体库后，原素材仍为淡黄色；重新加入的媒体库副本按普通引用显示。

- 设置主图或参考图后，素材进入靠前的选用历史；取消用途仍保留靠前位置，便于反复尝试。未完成任务和未选用的新产物排在选用历史后，其余素材随后。
- 滚轮向上向左、向下向右，不带动页面。边缘只有提示箭头，抵达对应一侧末端后隐藏；箭头不可点击，按系统减少动态效果设置停用动画。
- 初次呈现 16 项，横向浏览时分批追加，缩略图延迟加载。停留约 200ms 显示包含 180px 图片和两行名称的悬浮卡片，不挤动列表；滚动、移出或操作时收起。
- 已设为主图或参考图的卡片点击切换编辑；其余图片点击预览，使用放大镜光标。右键设置用途。
- “全部”保留名称，支持搜索及来源筛选，只显示图片，网格按可视区域渲染。

### 提示词、批注与保存

图片编辑与图片制作的加工入口都通过提示词下方的“提取批注”手动生成文本。提交只使用文本框中的内容，不再隐藏追加批注或统一说明。

| 批注类型 | 提取文本 |
| --- | --- |
| 提示框 | `修改方框内的区域: {批注内容}` |
| 箭头 | `修改箭头指向的区域: {批注内容}` |
| 涂抹 | `去掉涂抹标注，并编辑其覆盖的区域: {批注内容}` |

只提取可见、有文字且在当前加工范围内的批注。每条一行，跨类型按现有编号升序排列，同号保留图层顺序；不指定颜色。再次提取更新未改写的提取段落，保留人工改写的内容，并在需要时追加新的提取内容。可根据所选模型继续修改文字。

AI 图片编辑首次保存前或有未保存修改时，点击“开始 AI 加工”会提醒保存。选择“保存并开始加工”且保存成功后才提交；“返回编辑”不提交。保存失败保留草稿；待应用的裁剪须先确认或取消。

### 后台任务

提交后由本地服务在后台执行，页面可继续编辑、切换或关闭。完成后自动保存到提交时的工作区。素材条和“全部”显示排队中、进行中、失败卡片，完成后替换为结果素材，角标显示“AI 加工”。失败卡片可查看原因，不会自动重新提交付费请求。

任务状态保存在数据库中，刷新页面可恢复查看。在“设置 → AI 接入 → Comfy 连接”通过加减按钮或直接输入配置并发数，范围 **1–15，默认 2**，所有工作区共用。最多接收并发数两倍的未完成任务，至少 4 个；提高并发可放行排队任务，降低并发不会中断正在运行的任务。

后台执行依赖本地服务继续运行，不代表关闭桌面应用后服务仍在运行。服务重启会将未结束任务标记为跟踪中断，避免自动重复扣费；先在云端核对任务，再决定是否重新提交。超时同样不代表云端任务已停止。

### AI 结果预览

素材条、“全部”和工作区列表共用 AI 结果浮层预览。左侧可切换“结果”“滑动对比”“并排查看”，右侧固定展示生成信息。

滑动对比使用可拖动、支持键盘的分界线，两图居中适配。源图为加工时提交的主图快照，包含当时的编辑和标注，不随之后的草稿修改或媒体库改名改变。新结果保存快照；历史结果缺少快照时会明确提示，不用当前草稿代替。快照随素材删除，同步媒体库时仍留在工作区。

生成信息与媒体库共用解析和字段整理逻辑，展示模型与资源、正向／负向提示词、Sampler、Steps、CFG、Seed、Size、Clip skip、更多参数及原始记录。信息来源分为：

1. **本系统提交记录**：提示词、工作流名称或模型、参数覆盖值、参考图数量、遮罩使用情况和成功结果的任务编号。工作流默认值与云端运行时参数不一定包含在内。
2. **图片内嵌生成信息**：从原样保存的结果文件读取；当前内嵌工作流解析主要支持 ComfyUI。它与提交记录分别保留，不互相覆盖。
3. **原始文件元信息**：可展开查看未整理成生成字段的文件信息。

没有记录、平台未返回或图片未写入的字段不推断补全；参数缺失不意味着要在本应用重复配置订阅或余额。

## Comfy 接入与工作流

在“设置 → AI 接入”保存一次 Comfy API Key，供内容处理和工作台共用。图片加工可选 **Comfy Router 图像模型**或 **Comfy Cloud 工作流**：Router 提供已适配模型的比例和分辨率选项；Cloud 按工作流节点和参数运行，使用 API v2 上传素材、提交任务、查询状态和下载结果。

“验证连接”只检查 Key 是否可用于 v2 查询，不保证当前积分、订阅、并发或节点权限足以运行。实际执行权限由平台在提交时决定，平台错误码随提示保留；应用不据此推算订阅状态。

在“工作流管理”导入 ComfyUI **API 格式** JSON。全局工作流按名称排序并标记用途，对应创作页只显示相应用途。图形视图用于核对节点和连接，再明确设置主图、参考图、可选遮罩、正负提示词与结果节点。自动识别只是初始建议，应检查后保存。

图片结果节点必须在 v2 job 的 `outputs` 中产生图片文件；内容处理结果节点必须保存文本文件。只在节点界面显示预览或文本不能替代下载结果。

未使用的参考图输入位会在提交副本中断开；遮罩也按本次选择改写连接与输入。不会修改已保存的原工作流。多余参考图或未连接遮罩通道以黄色提示本次忽略；已知节点对遮罩与多图的组合限制也会缩减本次参考图数量。

尺寸、采样算法和步数不靠固定节点名推断。在“可调参数”中自定义名称、控件和目标字段，支持数值、文本、开关和选项；选项可同时写入多个字段。未覆盖字段保留 JSON 默认值。节点和模型需存在于所用云端环境；导入前应移除 JSON 中的凭证或敏感内容。

## 数据位置

工作区记录、全局工作流、后台任务状态和素材信息保存在本地数据库。创建素材的文件及源图快照位于数据库旁的 `iib-workspace-artifacts` 目录，备份时应与数据库一起保存。

当前工作区、图片草稿、部分输入选择和提示词由本机浏览器保存，数据库备份不包含这些草稿。云端加工会上传实际输入并使用对应服务额度；不使用云端功能时，本地媒体索引与编辑不上传文件。
