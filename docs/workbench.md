# 工作台：素材、图片制作与 AI 创作

## 工作区与素材

按作品或任务创建工作区，填写名称和可选目标。工作区可搁置、恢复或删除。顶部可在“工作区”“图片制作”“AI 创作”“音视频工具”间切换；图片制作和 AI 创作共用当前工作区的素材。

“素材”按来源区分：**媒体库引用**保留原文件的位置，不复制文件；**工作区创建**收纳图片制作保存的图片及 AI 加工结果，不参与媒体库扫描。素材卡片显示媒体类型和来源，点击预览，右键可查看相关操作。可从媒体库加入图片、视频或音频；选素材时可用文字搜索、筛选、画面搜索和以图搜图。工作区创建的素材可按需同步到媒体库中已加入的目录；同步会复制文件，工作区内的素材仍保留。“成果”用于从媒体库记录已确定的文件，支持图片、视频和音频，不会复制原文件。

删除单项工作区创建的素材会删除对应文件。删除整个工作区前会提示：其记录、笔记、图片草稿和工作区创建的素材一并删除；媒体库引用、成果引用及已经同步到媒体库的文件不会被删除。工作区素材适合保存试验和中间版本，需要在媒体库长期归档时再主动同步。

## 图片制作

图片制作支持多个草稿。画布可添加图片、文字、分组、提示框、涂抹标注和遮罩；属性面板编辑所选对象。画布内滚轮缩放，移入画布时边框会提示当前滚轮作用区域。撤销与重做按钮在画布缩放按钮左侧。草稿保存在本机浏览器；可以重命名或删除草稿。

“保存为素材”会将当前合成图写入工作区创建的素材，支持 PNG 或 JPG。保存时也可选择同步到媒体库，并指定一个已加入媒体库的目录。直接“下载图片”只下载到浏览器指定的位置，不会自动加入工作区。原始媒体文件不因编辑而改变。

选中图层、分组或整张画布后可打开“合成 / AI 加工”，核对作品预览与实际输入。输入可按可见内容边界裁切，也可使用完整画布。遮罩图中白色表示允许修改、黑色表示保留；提示框、箭头与涂抹的说明会加入提示词，标注色不会成为最终颜色。Router 不接收独立像素遮罩；需要遮罩通道时使用已配置相应连接的工作流。加工成功后结果可预览和下载，也会自动保存到当前工作区素材；如果保存失败，页面会提示先下载。

## AI 创作与工作流

“AI 创作”按图片生成、图片编辑、音频创作、视频创作及工作流管理排列。目前图片编辑已接入工作区图片和 AI 加工；其余创作页是功能占位。图片编辑可选 **Comfy Router 图像模型**或 **Comfy Cloud 工作流**。使用前在“设置 → AI 接入”保存 Comfy API Key。直接模型提供其支持的输出比例与分辨率；Cloud 使用工作流自己的节点和参数。

在“工作流管理”导入 ComfyUI **API 格式** JSON。工作流属于全局库，按名称排序，并标记用途；在对应的创作页只显示相应用途。图形视图用于核对节点和连接，再明确配置主图、参考图输入位、可选遮罩、正向与负向提示词以及图片结果节点。自动识别只是初始建议，保存前应按实际工作流检查映射。遮罩可取自主图加载节点的 MASK 输出，也可由独立遮罩节点提供。参考图位可以只使用一部分；未提供的输入位会在提交时断开。多余参考图或未连接遮罩通道只会提示本次忽略，不阻止加工。

尺寸、采样算法、步数等不靠固定节点名推断。在“可调参数”中为每个工作流自定义名称、控件和目标字段；支持数值、文本、开关与选项，选项可同时写入多个字段。未暴露的字段保留 JSON 内的默认值。工作流的节点与模型必须存在于所使用的 Comfy 云端环境，导入前应移除 JSON 中的凭证或敏感内容。

工作区记录、媒体库引用、成果引用、全局工作流及工作区创建素材的元数据保存在本地应用数据库；创建素材的文件单独存放在数据库旁的 `iib-workspace-artifacts` 目录。当前工作区、图片草稿和部分输入选择由本机浏览器记忆。AI 云端请求会使用所选服务的额度；不使用云端功能时，本地媒体索引与编辑不上传文件。
