# 代码规范

[文档导航](../README.md) · [开发指南](01-development.md) · [设计系统](03-design-system.md)

## 模块与类型

- App 负责组合，页面管流程，组件管展示和局部交互，hooks 管会话，model 管纯计算。
- `frontend/src` 的领域模型不导入界面，shared 不反向依赖业务。按具体职责复用，避免循环及综合 helpers。
- 生成信息、渲染、筛选、仓储各归所属领域；纯函数与组件分开导入，保持懒加载。
- 编辑器通过宿主和仓储保存；HTTP 共用 `react/shared/apiClient.ts`。
- 桌面媒体地址复用认证 URL 工具，不能手工拼接遗漏令牌的图片、音视频或快照地址。
- 后端路由处理 HTTP、权限及状态码，流程、SQL、校验归适当模块，不机械增加层级。
- TypeScript 保持 strict，外部 JSON 用 unknown 校验；不全局关闭类型和依赖边界检查。

| 对象                | 命名                                                                 |
| ------------------- | -------------------------------------------------------------------- |
| 产品／标识          | 星空馆／OmniGallery；`omnigallery`、`OMNIGALLERY_*`、`omnigallery:*` |

media 包括图片、音视频；artifact 是产物，成果是作品选中的产物。界面称“制作文件”，draft 键保留数据契约；编辑文档与快照是持久数据。

## 状态与资源

- 请求捕获目标身份，切换／卸载后旧响应不能覆盖新会话。缓存明确范围、失效和刷新。
- 输入留在局部草稿，失败不清空；loading 必须释放，重复提交保护仍允许重试。
- 工作区写入走版本事务，成功后发布缓存；冲突不自动重放，旧会话不复活已删除对象。
- 图片会话复用持久仓储，重读索引不能重置观察版本；原图覆盖提交文件摘要，不能用编辑记录 ID 代替来源版本。
- AI 结果的会话去重与持久回执分离：文档保存成功后才确认回填，失败保留恢复能力；显式采用也不能让未落盘的像素结果无处找回。
- 多项标签保存目标集合，单个收藏可切换；嵌套弹窗按键不穿透外层。
- 错误只由一层展示，调用方处理标记 `handledLocally`，区分失败、空、取消与未保存。
- 高频播放／滚动只发布需要的变化，帧动画不逐帧重绘整个列表。
- 导入模块时不连接数据库、下载或请求。同步磁盘工作保留线程边界，SQLite 连接显式关闭。
- 新增受管数据只能从应用根派生，先明确持久数据或可重建缓存；不能引入独立目录设置或让清理覆盖作品、模板与安装环境。启动与迁移边界见[应用存储实现](09-storage.md)。
- 监听、观察器、计时器、对象 URL 与子进程成对释放。付费任务恢复只查询原任务；只有服务协议保证幂等且未超出保留时限时，才允许复用同一键补取提交响应，不能自动改成新任务。

## 格式与检查

前端 Prettier，单引号、无分号、2 空格、100 列；Python Ruff。CSS 限定范围并使用语义变量，不保留注释掉的实现，不靠无职责拆分减少行数。

包管理器更新锁文件，不手改 dist。缓存、数据库、日志、安装包、模型及原媒体不提交。

统一检查 `python tools/check.py`，验证切换、取消、失败、幂等、冲突、路径、保存与版本等真正行为。使用隔离资源，不碰开发数据库或付费服务；跳过与目标设备验证分别记录。

测试跟随当前页面、服务和工具的调用链；停止使用的实现不继续保留独立测试。旧数据迁移、权限、事务和已修复缺陷仍需回归，不能仅因名称包含 legacy 或用例数量多而删除。相同场景优先共用数据和参数化，测试类不继承含用例的另一个测试类，避免重复执行；Node 24 测试直接导入 TypeScript 模型，无需逐文件手工转译。基准应调用当前实现，不保留旧实现的性能比较。

文档以当前实现为依据：操作放使用指南，布局放设计系统，协议与持久化放实现文档；参数和限制保留一个主要出处，其他页面链接引用。更新记录只写可见变化，测试数量和本机性能数据留在验证输出。

受控删除和重置先预览目标，不扩大到原媒体、凭据、源码或 Git。提交前核对动态入口、静态资源、CLI 与 sidecar。
