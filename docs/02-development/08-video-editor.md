# 视频编辑实现

[文档导航](../README.md) · [工作台实现](07-workbench.md) · [用户操作与容量限制](../01-user-guide/02-workbench.md#视频剪辑)

视频制作沿用 React 编辑器和 Python／FFmpeg 后端。设计参考[本地音视频播放器与时间线剪辑工具草案：Tauri + Vue + Python](https://chatgpt.com/space/page_2e82acecbdd08191aa000bb7fe179689)的按需读取、代理预览和原片导出原则；没有改用 Vue，也没有接入 WebAV 或原生播放器。10 GB 以上 4K 是实机验收目标，不能由接口支持大偏移推断播放和导出性能。

## 文档与素材

`VideoStudio` 接收 `EditorHub` 的工作区、作品和制作文件上下文。`omnigallery:video-timeline-v1:<workspaceId>:<draftId>` 保存在工作区状态，包含画布、帧率、画面、声音、字幕和标记。文档只保存原媒体路径／所属产物引用以及剪辑指令，不嵌入视频或代理字节。编辑约 900 ms 自动保存，也可按钮或 Ctrl/Cmd+S，写入遵循工作区版本事务。

图片进入画面轨，音频进入声音轨；视频可加入两轨或单轨，音画片段可用 `linkId` 关联编辑。轨道记录顺序、隐藏、静音、独奏、锁定和音量；锁定约束编辑操作，隐藏的画面不参与合成，声音轨的静音／独奏控制混音。画面按轨道顺序从下到上叠加，同轨按开始时间及保存顺序叠加。删除片段不删除原媒体。

文档仍为 `version: 1`，新增字段有默认值；没有显式轨道的旧制作文件使用默认画面轨和声音轨。提交验证会规范化旧文档再比较内容，避免新增默认字段导致旧制作文件无法导出。

| 编辑指令       | 当前实现                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------- |
| 时间线         | 移动、裁边、拆分、源起点、变速、吸附、标记；框选和音画关联由前端编辑文档                     |
| 画面           | 源区域裁剪、完整／填充／拉伸、位置、缩放、旋转、水平／垂直翻转、透明度                       |
| 画布操作       | 按可见内容命中、对象框、拖动、等比缩放、旋转、裁剪、居中／边缘对齐和辅助线；播放隐藏编辑手柄 |
| 动画与过渡     | 位置、缩放、旋转、透明度关键帧，四种缓动；局部曲线时间轴、多选、复制；调整实际重叠区间的叠化 |
| 颜色与局部效果 | 亮度／对比度／饱和度、曝光／色温／色调／伽马；矩形／椭圆遮罩、模糊、马赛克、反选和柔边       |
| 特殊播放       | 定格指定源时间；受时长和缓冲限制的倒放，声音有独立倒放预览                                   |
| 声音           | 多轨叠加、片段／轨道音量、淡入／淡出、静音／独奏；变速保持音调                               |
| 字幕           | 样式、自动换行／最大宽度、5% 安全区；独立工作台搜索、多选替换、时间偏移和批量样式            |
| 导出区间       | 请求中可选 `range: { start, end }`，截取时间线区间，保留区间内的动画和声音时序               |

`workspaces/video_media.py` 用 ffprobe 探测媒体，返回时长、尺寸、旋转、帧率、编码、音轨、时间起点和 HDR／可变帧率提示；图片使用图片元数据。探测结果按路径、大小、mtime 缓存，读取前后重新检查 stat。添加素材不再依赖浏览器成功读取媒体时长；源音视频时长上限 24 小时，成片限制另见用户表。

原片由现有 Range 接口按需读取，分块上限 1 MiB。FFmpeg 接收文件路径，编码结果写磁盘；Python 不读取完整源视频，不承担实时逐帧播放传输。浏览器媒体元素解码，Canvas 合成可见画面；画面视频静音，声音轨独立播放。小尺寸时间线抽帧接口只提供按需预览，不替代视频播放。

素材选段、单源／目录重新链接、属性预设与制作版本复用[工作台共享契约](07-workbench.md#音视频素材属性与版本)。`videoSources.ts` 汇总同一源的画面／声音片段，重链验证流类型、所选声音流和所有源区间，保持时间、关联和属性；不能用过短素材替换并静默裁掉内容。`videoProperties.ts` 只复制画面变换、调色、局部效果、关键帧及淡化，或字幕样式，不覆盖媒体路径、时间位置、转场关系和关联声音。版本预览独立只读，支持连续音画播放及定位查看；损坏制作文件可从独立恢复入口保留坏副本后恢复正常版本。

`videoLinks.ts` 支持选定画面与声音重新关联，合并时保留已有组的全部成员及源／时间偏移。同步起点明确指定移动画面还是声音；相对偏移受关联轨锁定、源范围和时间线边界约束，不能在裁边或变速时强行把两侧 start 写成相同值。

## 画布与属性交互

`VideoStage` 在不超过 1280 × 720 的预览画布合成当前帧。`videoStageInteraction.ts` 统一源裁剪、contain／cover／stretch、翻转、缩放、旋转及平移的正逆几何，按当前像素透明度命中最上层可见对象；完整模式的留白及局部透明遮罩可以穿透到下层。透明度检查只读取当前帧的命中点，不读取整段视频。

选中画面时绘制对象框，支持拖动、以对角为锚点的等比缩放和旋转。Shift 旋转以 15° 为步进，Alt 暂时绕过对齐辅助线；位置可按方向键微调。可视裁剪从左侧画面工具发起，画布仅保留应用／取消；命令层高于裁剪 SVG，整面拖动命中不能遮住按钮。裁剪有独立草稿，确认才写入源区域；字幕用实际文字行矩形命中并移动位置。播放时隐藏编辑辅助层。

只读或锁定轨道禁止变更，手势容器在开始时取得焦点，Escape／指针取消回滚到捕获对象。主组件 `stageGesture` 合并拖动期间的文档回调，结束后写一次撤销记录；浮层开关、安全区、查看缩放和画布尺寸均不改变制作文档。`onEditingFrame` 只在选中、源或静止播放头变化时提供 crop＋fit 后的有界基帧，播放期间不逐帧更新 React 状态。

右侧统一为“属性／混音”，当前选择决定可用参数。预览画质和代理控制放在播放栏“预览设置”，输出尺寸和帧率放在属性页的成片设置。画面、精剪与画面／字幕预设从左侧浮层打开；画面工具内部切换动画、转场、裁切、调色与局部处理，`VideoClipProperties` 基础参数保留在右侧。关联／解除与片段复制、剪切、粘贴、创建副本、删除进入对象右键，顶部不再保留片段操作行；手动同步起点仍保留参照、移动侧与偏移参数。

视频左侧 9 个入口按“添加轨道、字幕｜在播放头分割、声音编辑、时间线标记｜画面、精剪、画面与字幕预设｜修复素材”分组，媒体库入口集中在底部素材条。添加轨道、标记、精剪与预设等浮层互斥；标记列表选择与剪辑点导航共用定位方法，同步播放头和时间线滚动位置。`SourceRepairButton` 在进入编辑器、引用路径变化、使用中的产物删除、修复关闭及窗口重新获得焦点时检查源素材，检查请求由 `inspectProjectSources` 按 8 项顺序批量发送，仅读取媒体头。片段时间变化复用元数据重新验证，代理失败不影响源素材健康状态；检测到问题时修复按钮显红。

右键已选对象保留多选与主对象，并扩展音画关联组；右键未选对象才切换选择，空白处可粘贴。复制写入剪贴板，粘贴落在播放头；创建副本立即追加到选中组最大结束时间并保留组内偏移，使用新的片段与关联 ID。右键与快捷键复用相同事务和锁定校验，轨道头的显隐、静音／独奏／锁定不在属性中重复。

次要关键帧列表、手动同步起点和恢复副本共用 `EditorDisclosure` 的显式“展开／收起”；独立工具使用左侧浮层，呈现约定见[设计系统](03-design-system.md#音视频制作)。

左侧精剪浮层使用 `VideoPrecisionTrim`，`videoPrecisionEditing.ts` 区分滑移源区间与滚动紧邻交界：滑移保持位置与时长，滚动保持两侧外边界，均检查关联声音、锁定和源范围。修改前／后以有限接缝区间预览，应用前不写当前文档。保留原包络锚点后复制属性，只提取可见淡化；原 fade 为零时仍保持零，延长片段或负偏移不能新增淡化。

## 动画与转场

`VideoKeyframe` 支持稀疏 `x/y/scale/rotation/opacity`，时间是片段局部时间。`videoAnimationEditing.ts` 统一记录、移动、多选复制到播放头及删除；`VideoKeyframesEditor` 显示曲线和可拖的关键帧，并提供按帧微调、精确时间与批量值输入。动画录制使用裸变换，不把片段淡化或转场透明度录进关键帧。

缓动为 `linear`、`easeIn`、`easeOut`、`easeInOut`，分别使用线性、二次缓入、二次缓出及 smoothstep。目标关键帧控制进入该帧的曲线；可选 `curves` 保留各字段原曲线的局部参数区间。`rebaseVideoAnimation` 供拆分、裁边和滚动交界使用，采样边界并限制保留曲线；延长到旧片段之外保持最近边界值，不能重建此前已裁掉的源动画。Canvas 与 FFmpeg 按相同局部时间和缓动表达式求值。

叠化记录在入场片段的 `transitionIn`，包含前一片段 ID、时长、缓动和裁边后的进度偏移。`setVideoTransition` 将入场开始位置设为“前一片段结束－重叠时长”，关联声音一起移动；删除转场恢复到前一片段结束。它控制真实叠放范围，单片段 `fadeIn/fadeOut` 仍独立。前一画面保留在重叠区间，入场透明度按曲线递增，并与片段自身透明度、淡化相乘。

`VideoTransitionEditor` 用两个片段条和范围手柄编辑重叠边界，数值按帧对齐，可跳到范围查看。操作检查两画面与关联声音的锁定、源范围及时间线界限；拒绝同时包含前后画面的同一关联组及重叠区内第三个同轨片段。分割／裁边保留原转场进度，不重新开始整段淡化。当前只实现叠化，不含复杂转场库。

## 字幕与局部处理

字幕样式新增 `maxWidth`（画布宽比例 0.1–1，默认 0.9）及 `wrap`（默认 true）。`videoCaptionLayout.ts` 用同一行布局供 Canvas 绘制和命中，支持显式换行、词边界、中日韩文字及长词拆分。后端 `video_caption_layout.py` 估算字体宽度后写显式 ASS 换行，`WrapStyle: 2` 禁止 libass 再次自动换行；字体测量与栅格化不承诺逐像素一致。5% 安全区仅为查看辅助线，不参与输出。

左侧字幕入口集中添加、导入／下载和 `VideoSubtitleWorkspace`；工作台提供搜索、分页、多选替换、整体时间偏移与批量套用当前样式，所有修改沿用主文档历史。右侧保留当前字幕时间与样式参数。输入、批量替换、前端文档读取与后端导出统一每条最多 5000 字符；超长旧文档进入保留原文的恢复入口，不能静默截断后覆盖。SRT／VTT 的文字时间与样式导出边界按现有字幕接口处理，样式烧录仍使用 UTF-8 ASS。

`clip.localEffects` 由 `videoLocalEffects.ts` 与后端 `video_local_effects.py` 校验：曝光 −2–2、色温／色调 −1–1、伽马 0.25–4，每片段最多 8 个矩形／椭圆区域。区域坐标属于源裁剪＋填充后的画布平面，随后才翻转、旋转、缩放和平移；遮罩产生透明度并露出下层，模糊／马赛克保留原透明度。区域可反选，柔边按画布短边比例 0–0.25，强度 0–1；没有自动跟踪。

`VideoLocalEffectsPanel` 在有界基帧上绘制、移动或缩放区域，拖动本地预览，松手单次提交。Stage 的效果平面限制在 640 × 360 内，模块硬性拒绝超过 1920 × 1080 的前端处理；导出按原输出画布计算。处理顺序为 crop＋fit、曝光／色温／色调／伽马、依次局部区域、原亮度／对比度／饱和度、翻转与仿射变换。模糊使用镜像边界与整数分离运算；小预览的采样精度与最终 4K 输出不同。

## 代理预览

前端 `useVideoMedia` 提供自动／流畅／原画模式。自动模式按源尺寸和编码决定是否准备代理；流畅模式请求代理，原画模式直接使用原片。准备完成前仍使用原片，任务失败可重试。只读会话可使用已有缓存，不创建、取消或清理代理。

代理为 H.264／AAC MP4，不放大原图，横屏限制在 1280 × 720 内、竖屏限制在 720 × 1280 内，宽高取偶数。保留音轨并处理旋转和时间起点；HDR 仅提供 8 位预览提示，不能视为已实现正确色调映射。代理不成为工作区素材、产物或成果，时间线始终保存原路径。

缓存位置为 `cache/video-proxies/<workspace>/<源路径摘要>/<源版本摘要>.mp4`。源版本摘要只计算路径、大小、mtime 和代理规格，不遍历大文件内容。读取入口重新验证当前源版本和路径权限，缓存通过受鉴权接口返回。

| 代理资源 | 当前约束                                                                |
| -------- | ----------------------------------------------------------------------- |
| 后台处理 | 单并发，最多 16 个排队／运行任务                                        |
| 任务记录 | 内存中最多约 256 条；重启不恢复未完成任务，已完成缓存可复用             |
| 磁盘余量 | 生成前及进度更新时检查，至少保留 512 MiB                                |
| 缓存回收 | 完成后按最近使用时间回收，目标为 20 GiB；正在播放的文件可能暂时无法删除 |
| 单个代理 | 生成期间检查 20 GiB 大小阈值，超限失败并清理临时文件                    |

同一工作区、同一源版本的活动请求合并为一个任务。取消会停止 FFmpeg；编辑器内手动清理先取消对应任务，退出播放后可删除该源的代理。全局清缓存当前不覆盖 `video-proxies`，可用编辑器内清理及容量回收。源文件变化时丢弃本次代理。所有缓存路径经过边界和符号链接检查。

## 时间线抽帧与声音预览

`videoTimelineInteraction.ts` 分开数值提交和拖动吸附：数值在确认时按帧对齐并回显实际接受值，拖动使用 8 px 容差且排除一起移动的关联片段。锁定关联轨道时禁用受限制的时间属性并显示原因。片段主体按真实时长绘制，超短片段可通过“适应选中”放大裁边；“适应”按内容范围计算，继续编辑所需的空白滚动范围单独保留。内容缩短会同步约束已有播放头、选区与滚动，主动定位到空白区域的能力仍保留。

`videoPreviewPosition.ts` 在播放头恰好到达整条时间线末尾时保留最后一帧，避免播放结束立即变成黑屏。仅保留同样结束于该位置的画面和字幕，视频采样最后一个输出帧；内部空隙、已经提前结束的内容以及末尾之后的空白不延长显示。声音、播放头数值和导出区间不受影响。

`workspaces/video_previews.py` 按可见源时间窗口返回抽帧地址，前端随时间线滚动、缩放调整请求。每批最多 24 张，每张最长边 64–320 px；FFmpeg 先 seek 再解码单帧，不遍历或读取整个媒体。地址带源指纹，源版本变化返回 409，不能继续使用旧帧。波形复用 `/api/audio_studio/source?peaks=true` 的 `start`、`duration`、`samples` 窗口参数。前端帧图片加载与窗口请求共用两个并发名额，并对临时失败有限重试；滚动离开的排队请求取消。

兼容的 `GET /preview-audio` 单源接口生成至多 30 秒的 48 kHz 双声道 WAV，仅取首声音流；其缓存不成为素材或产物。新编辑器使用下一节的文档混音链路，按所选声音流处理倒放、变速与多轨声音，不调用该旧接口。

时间线抽帧与上述单源声音预览共用 2 个 FFmpeg 槽位，繁忙时返回 429 和 `Retry-After: 1`。单次处理超时 45 秒，启动前至少保留 256 MiB 空间。缓存为 `cache/video-timeline-previews/<workspace>/<源版本摘要>/<参数摘要>`，目标容量 2 GiB，最多每 30 秒按最近使用时间淘汰；正在使用的文件可能暂时保留。指纹使用路径和 stat，不扫描源文件内容。全局清缓存当前也不覆盖该目录。

## 视频声音链路

`video_audio.py` 将片段声像、音量点、直线／柔和／等功率淡化、声道／反相、变速和保持音调加入视频声音渲染，定格声音保持静音。音轨和总混音复用 `audio_processing.py` 的均衡、压缩、降噪、减轻齿音、响度统一、限幅及旁路。视频当前没有对白角色侧链压低音乐的轨道设置，也没有整段响度报告。

声音编辑复用 `TimelineSoundEditor` 独立面板，音量点的时间／音量数值和片头／片尾接缝试听集中在面板内；右侧保留声像与淡化时长／曲线。左侧或片段右键打开面板，播放菜单不再重复提供接缝试听与循环选区命令。

`POST /video_studio/preview-mix` 接受工作区、完整视频文档、开始时间和最多 12 秒的试听时长，返回 48 kHz 双声道浮点 WAV 与 `X-Audio-Level-Peaks` 的 20 Hz 左右声道峰值。有状态的轨道／总处理，以及保持音调且 `rate != 1` 的可听片段，需要先准备完整混音；试听 seek 与取块直接读取最终 PCM，保持 `atempo` 产生的采样结果。前端改走完整缓存的 chunk，短窗接口在需要完整混音时返回 409。无需完整处理的片段仍支持有界窗口，限制两个并发试听；断开请求终止并回收实际 FFmpeg 进程。源元数据按路径、源 stat 和声音流缓存，不遍历大媒体。

声音片段保存 `audioStream` 顺序编号，旧文档默认 0。元数据、声音切换、选段、窗口波形、缓存、重链及导出均核对这一流；迟起流按容器时间补静音，不能用重设时间戳消除原同步偏移。画面和所选声音流的有效末端分别记录；多语言标题、声道和采样率供用户识别。

完整混音和导出共用 `audio_mix_render.py` 的逐窗解码与连续轨道／总线处理，RF64 支持超过 4 GiB 的临时 WAV。试听从整工程最终 PCM 按采样位置读取，导出可借用相同修订的 ready 文件；轨道／总线 DSP 不会在每个 10 秒交界重启。源变速仍按有界窗口解码与预热，其与单个不中断 `atempo` 进程的逐采样一致性尚未验证。管理器、路径安全、容量、取消和工作区清理见[完整声音缓存](07-workbench.md#完整声音缓存)。当前小样本真实 FFmpeg 回归验证浮点试听分块与同一混音导出采样一致；这不代替六小时或 10 GB 以上真实工程的压力验收。

## 导出任务

新编辑器使用 `workspaces/video_exports.py` 的持久化队列。提交携带 UUID `task_id`、工作区、制作文件、已保存内容 SHA-256 修订、时间线和名称，返回 HTTP 202；视频渲染不再依赖长 HTTP 请求。

1. 提交时校验已保存修订，保存独立的剪辑指令快照及原片路径／大小／mtime，不复制原片。相同 `task_id` 和内容返回已有任务，即使队列已满；相同编号配不同内容返回 409。
2. 单个工作线程取队列，检查制作文件仍存在、源文件没有变化、磁盘预算足够。ffprobe 校验流、时长和片段范围，FFmpeg 始终读取原片；后端明确拒绝代理缓存作为导出输入。
3. `Popen -progress` 持续报告 0–99% 进度，stdout 只保留最新进度，stderr 使用有界缓冲。取消、工作区删除、停滞或空间不足时终止进程并清理临时文件。
4. 成功后再次检查源版本，按提交快照发布。用户可以继续编辑当前制作文件，产物仍关联提交时的修订；制作文件已删除则不发布。
5. 在目标卷临时目录渲染，成功后原子移动文件，产物登记和任务完成写入同一数据库事务；完成进度为 100%。取消与发布并发时，已完成发布的任务返回完成结果。

`video_export_task` 保存请求、源指纹、状态、阶段、进度和最终产物。公开响应不返回内部请求与路径指纹。状态为 `queued`、`running`、`completed`、`failed`、`cancelled`、`interrupted`，阶段细分 `preparing`、`rendering`、`saving`。列表按工作区和可选制作文件过滤，最多返回最近 100 条。

| 导出资源         | 当前约束                                                                                                    |
| ---------------- | ----------------------------------------------------------------------------------------------------------- |
| 并发与队列       | 单并发，最多 4 个排队／运行任务                                                                             |
| 成片             | 最长 6 小时；选区必须位于时间线范围内                                                                       |
| 尺寸与帧率       | 单边 240–3840 px、偶数，面积不超过 3840 × 2160；整数帧率 1–60 fps                                           |
| 文档数量         | 画面／声音各最多 256 个片段，32 条轨道，4096 条字幕，256 个标记                                             |
| 关键帧与变换     | 每片段最多 128 个关键帧，时间不能重复或越过片段；缩放 0.05–4 倍、位置 ±2 个画布尺寸、旋转 ±360°、透明度 0–1 |
| 局部处理         | 每片段最多 8 个区域；预览为有界小画面，输出按成片尺寸处理                                                   |
| 倒放／淡化／转场 | 倒放片段最长 30 秒；新设淡化／叠化最长 30 秒且不超过片段，已有包络随慢放缩放后按原锚点保留                  |
| 磁盘预检         | 按时长、尺寸和帧率估算编码空间并加余量；这是工作预算，不保证 CRF 文件大小                                   |
| 运行余量         | 至少保留 256 MiB，空间不足即停止                                                                            |
| 执行期限         | 最长 24 小时；连续 10 分钟无编码时间进展则中断                                                              |

关闭页面后，已提交任务仍在后端执行。正常关闭服务会终止当前渲染；服务启动将原 `running` 标记为 `interrupted`，不会自动重跑，原 `queued` 可继续处理。中断／失败任务可重新导出。前端保存未确认提交的编号，响应丢失时先查任务或用相同编号重试，避免重复排队。

只有查重确认不存在任务后、创建前的明确拒绝，才返回 `detail: { type: 'video_export_not_created', message }`。鉴权失败、请求校验失败、同编号内容冲突以及提交后的服务错误都不带此标记；前端保留原编号和快照，不能仅凭 4xx／5xx 创建新编号。已有任务的重试优先返回原任务，不受队列已满或当前制作文件修订变化影响。

删除工作区状态会清理其视频任务记录；删除工作区产物先停止相关写入、等待进程退出，再删除目录，不能发布回已删除工作区。应用生命周期负责队列 `start()`／`close()`；重复启动同一个管理器不会重置活动任务。迁移应用数据根后，排队任务若仍保存工作区产物的旧解析路径，会在源指纹检查时安全失败，需要重新导出。

旧 `POST /api/video_studio/export` 暂时保留兼容：它仍同步返回产物、要求发布时修订未变化，且有旧渲染超时。新 UI 不调用此接口，长视频应使用任务队列。

## 分段渲染与资源控制

`workspaces/video_render.py` 将画面按最多 10 秒的窗口处理，并在片段边界分段。每个窗口从黑底开始，按层顺序逐个合成：FFmpeg 每次最多打开中间成片和一个源片段，不同时为整个时间线的所有素材开解码器。解码／编码线程受限，变换在固定画布尺寸内采样，放大 4 倍也不分配 16 倍像素的临时画布。

倒放窗口进一步按画布和帧率缩小，使 `reverse` 缓存的 RGBA 帧预算不超过 128 MiB；这是倒放帧缓存预算，不是整个 FFmpeg 进程的峰值内存上限。倒放前先限制帧尺寸，禁止对完整长源文件一次性 `reverse`。

声音使用上述连续轨道 DSP 链路，源解码不跟随倒放画面的极短窗口。最后合并画面片段并仅编码一次 AAC，避免每个小片段的 AAC 起始延迟累积。全程写磁盘、有进度与取消检查，失败清理临时产物；成功后删除分段文件。选区导出仍按原时间线求关键帧、淡入淡出和源位置。

中间画面使用 H.264 CRF 18，有损压缩且多层会有多次编码；该实现优先限制同时解码数量和倒放缓冲，复杂 4K 多层导出仍可能较慢。画布变换与字幕位置使用相同坐标口径，但 Canvas 与 FFmpeg 的缩放采样、字体栅格化及编码量化不承诺逐像素一致。

## HTTP 接口

以下路径均以 `/api/video_studio` 为前缀；读取需鉴权，创建、取消、清理另需写权限。

| 方法与路径                      | 输入／返回                                                                                                |
| ------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `GET /media`                    | `workspace_id`、`path`、可选 `kind`；返回元数据、源指纹及可用代理地址                                     |
| `POST /proxies`                 | JSON：`workspace_id`、`path`；返回代理任务                                                                |
| `GET /proxies`                  | `workspace_id`；返回 `{ jobs: [...] }`                                                                    |
| `GET /proxies/{job_id}`         | `workspace_id`；返回代理任务                                                                              |
| `POST /proxies/{job_id}/cancel` | `workspace_id`；返回取消后的任务                                                                          |
| `GET /proxy`                    | `workspace_id`、`path`；读取当前源版本的代理文件                                                          |
| `DELETE /proxy`                 | `workspace_id`、`path`；取消并清理该源的代理                                                              |
| `GET /thumbnails`               | `workspace_id`、`path`、`start`、`end`、`count`、`width`；返回 `{ frames: [{ time, url }], fingerprint }` |
| `GET /thumbnail`                | `workspace_id`、`path`、`time`、`width`、`revision`；返回单张 JPEG                                        |
| `GET /preview-audio`            | 兼容首声音流：`workspace_id`、`path`、可选 `kind`、`start`、输出 `duration`、`rate`、`reverse`；返回 WAV  |
| `POST /preview-mix`             | `workspace_id`、`document`、`start`、`duration`（≤12 秒）；返回浮点 WAV 及左右声道峰值头                  |
| `POST /tasks`                   | `task_id` 和导出快照；返回导出任务，HTTP 202                                                              |
| `GET /tasks`                    | `workspace_id`、可选 `document_id`；返回任务数组                                                          |
| `POST /tasks/{task_id}/cancel`  | `workspace_id`；返回任务最终或取消状态                                                                    |

代理进度范围是 0–1，完成状态为 `succeeded`；导出进度范围是 0–100，完成状态为 `completed`，并返回完整 `artifact`。两类任务不能混用状态或进度字段。

输出为 H.264／AAC MP4，画布底色为黑色；片段按各自的填充和变换指令合成，图片和动图只取首帧。FFmpeg 需要 libx264、AAC、相关滤镜，烧录字幕还需 subtitles／libass。字幕样式写入 UTF-8 ASS 文件，用户文字不拼入命令或滤镜，保留背景与描边两层绘制；标记不延长成片。没有画面也可导出黑底声音／字幕视频。产物、代理和应用管理的 FFmpeg 随应用数据根组织，存储边界见[应用存储实现](09-storage.md)。

## 验证与后续边界

集成测试包含真实 UHD 3840 × 2160 短片：带音轨、源起点裁切、变速与倒放、保持 UHD 输出、进度和源文件不变。真实 FFmpeg 用例覆盖多轨层序、裁剪／翻转／旋转、旋转缓动及裁边保留曲线、叠化真实重叠与选区、RGB 和局部调色、遮罩变换、模糊／马赛克、定格、字幕换行、音轨独奏／混音、抽帧和倒放声音预览。前端几何及模型回归覆盖锁定、取消、变换命中、精剪、动画复制与重定位、局部效果和属性复制。资源测试检查同时输入数量与倒放窗口预算；队列测试覆盖取消、重启、重复提交、边编辑边导出、源变化、工作区删除和发布回滚。

组合回归覆盖滚动精剪／源滑移后复制属性、跨重载预设、批量应用、保存及真实 MP4 导出；零淡化片段不因延展而变暗。独立工作区的真实接口验收覆盖损坏文档备份恢复、UTF-8 原文下载、多声音流试听和 WAV／MP4 导出、目录冲突与短候选拒绝、原子重链与撤销。声音回归比较有状态处理、变速保持音调的试听采样与最终混音，并覆盖多窗口、暂停、声音修改和取消。接口和短片回归只证明相应链路，不代替完整 UI 与实片性能验收。

`test_video_combination.py` 另外将真实视频源裁切／完整填充、局部模糊／马赛克与调色、翻转、旋转／位置／缩放／透明度关键帧、实际重叠转场组合在同一短片。整段和选区输出的四个相同时间点平均色阶差小于 2，叠化按原始重叠曲线推进；局部处理不会改变区域外的变换与调色。该回归同时确认源文件不变、单次渲染最多两个输入，测试尺寸为 320 × 240、12 fps、3 秒，不是 4K 性能测试。

尚未完成真实大于 10 GB／20 GB 4K 素材的性能验收。实机需记录：导入与随机 seek 延迟、预览掉帧和音画同步、WebView／Python／FFmpeg 峰值内存、代理和导出耗时、磁盘占用、取消响应；覆盖 HEVC、HDR、可变帧率及长 GOP 素材。

当前不含动态图播放、HDR 输出、专业色彩管理、自动跟踪或复杂转场库。浏览器不支持原生负速播放，倒放画面以 seek 预览，流畅度仍需实机验证。复杂多层画面会重复有损编码，源编码兼容性也取决于浏览器／WebView；WebAV／原生播放器仍是后续候选，本轮未更换 React 架构。
