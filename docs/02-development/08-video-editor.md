# 视频编辑实现

[文档导航](../README.md) · [工作台实现](07-workbench.md)

VideoStudio 接收 EditorHub 的工作区、作品与制作文件上下文。模型管理画布、帧率、画面、声音、字幕及标记，后端 `workspaces/video_studio.py` 用 FFmpeg 渲染 MP4。

## 文档与预览

`omnigallery:video-timeline-v1:<workspaceId>:<draftId>` 存入工作区状态，仅引用原媒体或所属产物。载入校验结构与数值，编辑约 900ms 自动保存，也可按钮／Ctrl/Cmd+S，写入版本事务。

图片进入画面轨，音频进入声音轨，视频默认两轨，可单独添加。支持移动、裁边、拆分、源起点、速度、音量、吸附和字幕／标记。

浏览器播放头驱动媒体元素，画面视频静音，声音轨独立播放。重叠时较晚开始画面优先，同起点按保存顺序；删除片段不删除源文件。

## 导出契约

`POST /api/video_studio/export` 提交工作区、制作文件、已保存内容 SHA-256 修订、时间线和名称。渲染前与产物提交时校验文件和修订，原媒体检查路径信任，产物仅限同工作区且类型匹配。

ffprobe 校验流和时长，源越界／不可解码直接报错。同卷临时文件成功后原子发布，失败清理，不登记半成品。

输出 H.264／AAC MP4，画面等比放入黑底，图片与动图只用首帧。独立声音轨混音，atempo 保持音调。字幕使用 UTF-8 SRT 烧录，不拼入命令或滤镜；标记不延长成片。

| 项目   | 限制                           |
| ------ | ------------------------------ |
| 时长   | 60 分钟                        |
| 画布   | 3840 × 2160，宽高偶数          |
| 帧率   | 60 fps                         |
| 片段   | 画面、声音各 64                |
| 字幕   | 256 条                         |
| FFmpeg | libx264、AAC；字幕需 subtitles |

没有转场、关键帧和动态图播放；无画面也能输出黑底声音／字幕视频。结果沿用产物与成果流程。

集成测试使用真实媒体，验证合成、速度、混音、字幕、缩略图、路径、修订与源范围；浏览器和 FFmpeg 的编码／颜色差异需实际视觉核对。
