## 品牌与主题

“星空馆／OmniGallery”，副标题“收藏所爱，创作所想”。星轨源图 `frontend/public/favicon.svg`，桌面图标从同一 SVG 生成。主题来自 `react/design/theme.ts` 和 `global.css`，使用 Mantine、Tabler 与 `--omni-*` 语义变量。

| 用途       | 浅色          | 深色            |
| ---------- | ------------- | --------------- |
| 工作区域   | #f7f7f7       | #202123         |
| 侧栏／顶部 | #eeeeee       | #171819         |
| 面板       | 白色          | #252628         |
| 主要操作   | #356cb6，白字 | #8cb8ed，深色字 |
| 导航       | 银灰          | 石墨银灰        |
| 产物       | 柔黄表面      | 深暖黄表面      |

蓝为主要操作、选择与焦点，绿为成功，琥珀为警告，红为错误／危险／收藏，来源用中性标签。媒体内容不随主题改变。正文和状态文字对比至少 4.5:1，必要边界至少 3:1，由 `colorContrast.test.mjs` 验证。

保留键盘焦点、悬停和禁用反馈，尊重 `prefers-reduced-motion`。

## 页面与反馈

侧栏和顶部连续，正文左上圆角 10px。工作台、设置、挑一挑使用 PageFrame，顶栏固定、正文独立滚动；宽屏铺开，窄屏按容器调整，设置控件限制长度。

图库与挑一挑工具栏高 40px，与列表同底色，无底部分隔线，保留吸附模糊。搜索聚焦蓝边，深色内部 #34373b，浅色 #f1f4f8；AI 光晕独立绘制避免裁切。

PageState 保留顶栏，编辑器状态避开操作区。空状态和错误留在所属区域，useNotice 在工作区域底部居中、避开控制条，重复反馈合并。

预览顶部集中操作与文件名，底部规格／位置／缩放；信息区为描述、生成信息、元信息，窄屏移到画面下方。菜单开启弹窗前关闭所属菜单。

## 目录与工作台

目录返回／路径在左，递归开关、进度与操作在右。子文件夹是轻量横向入口，复用目录图标，文字与图标居中对齐。

首页星空铺到正文顶部和两侧，底部仅 10px 渐隐。工作区与作品共用铺边标题和正文左边距，返回统一距正文顶 10px；作品先标题，再素材。

| 层级     | 呈现                                         |
| -------- | -------------------------------------------- |
| 工作区卡 | 纵向封面，柔和投影和高光，悬停上移 2px       |
| 作品卡   | 横向紧凑，独立画布预览与日期                 |
| 制作卡   | 文件标题／类型图标，内缩预览，素材／产物入口 |

卡片圆角均 8px，装饰不拦截点击。音频用玫瑰、图片与 AI 用蓝、视频用青绿，产物标记另用黄色。

制作／成果是 42px 主切换与数量标记；制作类型为 12px、最小高 28px 的文字标签及短下划线。工作区素材用多列条目，44px 缩略图、两行名称，列表高 344px 后独立滚动，提供继续加载。

工作台及所有编辑器共用素材条：黑底、灰边和高光，高 82px，卡片 64px，悬停／聚焦放大 6%；右侧为网格、添加入口及全部／已使用切换，无左右箭头。单击预览，添加／替换等对象操作集中在右键；浏览面板用类型／来源两组标签，窄屏换行。

横向滚轮跟随，两端最多拉伸 24px 后回弹，空列表保留底座。轨道两端 18px 渐隐只在内容被裁切时开启，跟随位移，到边界恢复首尾清晰；工具区不加遮罩或竖直分隔线。动画按需运行，减少动态效果时关闭，资源释放见[工作台实现](07-workbench.md#交互与加载)。

## 编辑器

全屏编辑器共用深色变量：顶部命令、中央画布／时间线、右属性、底素材，字幕／标记用琥珀。左上命令条依次放返回、文件名、保存／导出、撤销／重做、帮助与保存状态圆点，省略工具前缀；图片另有保存范围。保存成功后圆点才显示已保存，说明放悬停提示中。工作区编辑器右上依次为制作笔记、制作版本、任务列表；属性栏常驻，笔记和任务在独立浮层呈现，不挤压工作区。媒体库图片只提供任务列表；未接入的 AI 音视频保留笔记和任务入口，不显示保存操作、制作版本或伪造保存状态。

| 图片编辑区域   | 约定                                                                                          |
| -------------- | --------------------------------------------------------------------------------------------- |
| 视口           | 平移和浮层不改变文档；选框八点缩放、顶部环形箭头旋转，裁剪含九宫格、尺寸与框外遮罩            |
| 左工具栏       | 选择、调整、文字、素材、形状、版式、AI 工具用图标入口；面板统一对齐工具条顶部，悬浮且内部滚动 |
| 右面板         | 图层和属性常驻，滚动条贴外沿；细线及短把手分隔两区，可拖动或用方向键调节高度                  |
| 文字属性       | 紧凑标签行和图标按钮，区分排字与几何；图标具备操作名称、选中及禁用状态                        |
| 文字效果       | 常用值、颜色、开关同行；更多参数向图层组件左侧弹出，纵向贴近触发位置，避免撑长属性面板        |
| 画布内文字编辑 | 使用高对比文字与光标，按实际拟合字号显示；不改图层颜色                                        |
| 分组排序       | 显示上／下插入线和入组高亮，空分组也有明确位置                                                |

AI 图片沿用同一左侧工具栏、悬浮调整面板、裁剪框和缩放条。主图与参考图同屏，添加入口在素材条和配置面板，不为参考图预留空卡。右上媒体类型切换与通用编辑器功能分组，右侧只放生成／编辑参数。生成完成后中央直接展示当前制作文件的生成结果，支持多图切换、缩放与拖动；不混入其他制作文件或编辑用途的结果。各编辑器素材条统一单击预览、右键操作及全部／已使用筛选，视图缩放条和素材条左侧对齐。尺寸页内容参数直接展开，提示标注只在标注工具内出现。

AI 音视频使用相同左上命令条和右上类型图标，中央为视频预览／音频试听占位，右侧列出规划能力，底部提交禁用。通用任务列表汇总 AI、导出、图层处理及本次会话代理，使用紧凑卡片和可点击小缩略图；仅已确认结束的任务可删除记录，保留产物与媒体。筛选下拉浮在面板外，避免短列表裁切；Escape 先关闭预览或下拉，再关闭任务浮层。视频代理的预览设置仍提供准备入口。

完整声音准备在播放区显示阶段、进度与显式取消，结果仍为可回收的试听缓存；暂停只停止本地播放等待，继续观察准备。声音变化或离开时释放本窗口兴趣，其他窗口仍在观察则继续计算；即使暂停后编辑也应清除旧状态。未就绪、失败或过期的混音不能显示为可播放，读取状态失败须给出错误与重新试听入口。

手势、保存与导出操作见[图片制作](../01-user-guide/05-image-editor.md)，预览订阅、渲染和版本保护见[图片编辑实现](06-image-editor.md)。

### 音视频制作

音视频时间线共用播放头与入出点输入组件，接受秒数与时码，支持 I／O、选区边缘微调。Enter 或失焦提交，Escape 恢复真实值；非法或受锁定限制的输入回显实际接受值并提示。未设置选区保留空值，占位不能伪装成播放头。视频数值按帧对齐，拖动吸附按屏幕距离计算，避免缩放改变操作手感。

播放栏、时间输入和刻度固定在时间线外框内，轨道内容单独滚动，高度根据真实轨道计算，播放头装饰不能撑大滚动范围。视频抽帧、音频波形和刻度随当前可见范围及缩放更新；视频预览与时间线间可拖动调整高度。音频波形的振幅、左右声道显示和轨道高度属于查看设置，不改变音频内容。

片段主体使用抓取光标，移动中显示抓取中，裁剪边缘及淡化手柄使用水平调整光标，音量曲线空白区使用加点光标；锁定或只读不显示可拖动反馈。时间尺、片段、曲线与框选的高频输入按显示帧合并，松手使用最终坐标，取消丢弃待处理输入；无变化不能增加历史或保存。

| 区域           | 呈现与操作                                                                                                                                                                                                                                                |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 视频画布       | 暂停且选中时显示对象框、缩放／旋转手柄和少量工具；播放时隐藏。透明处按实际内容命中，居中／边缘辅助线只在相关手势中出现                                                                                                                                    |
| 动画与转场     | 使用片段局部时间轴显示可拖关键帧、数值及曲线；转场显示两个片段的实际重叠范围，不用淡化按钮代替范围控制                                                                                                                                                    |
| 局部处理       | 在有界小预览绘制矩形／椭圆，效果与源裁剪、填充后的画面对应；拖动结束一次提交，不把每次指针移动写入历史                                                                                                                                                    |
| 音频包络       | 名称条与波形分开；选中片段仅显示被动淡化范围。`TimelineSoundEditor` 在时间线滚动区下方显示独立的 144px 面板，标题指明音轨与片段归属，轨道列表保持连续；共用横向时间窗口与播放头。音量点的时间／音量数值与接缝试听集中在面板内，淡化时长／曲线留在右侧属性 |
| 素材添加／重链 | 添加弹窗集中源选段，视频可选择添加内容与叠加／插入／覆盖；图片默认显示 5 秒并选择视频时间线的添加方式。重链弹窗显示素材、源时间与确认结果；预检可取消，开始提交后禁用关闭，失败后恢复重试                                                                 |
| 制作版本       | 列表与独立只读预览并排，音频可试听、视频可连续播放音画或定位查看；查看版本不能隐式恢复当前制作文件                                                                                                                                                        |

音视频右侧统一为“属性／混音”，当前选中对象决定参数；静音／独奏／锁定与文字显示留在轨道头，避免在属性栏重复。`AudioProcessingControls inline` 在混音页直接展示，声道与淡化数值／曲线保留在片段属性。视频预览控制进入播放栏“预览设置”，成片尺寸和帧率放在属性页。删除顶部片段操作行，复制、剪切、粘贴、创建副本、关联及删除等对象命令由右键和快捷键提供。

左侧用分隔线形成四组，音频 8 个入口为“添加音轨、文字｜分割、声音编辑、标记｜声音预设、响度检查｜修复素材”；视频 9 个入口为“添加轨道、字幕｜在播放头分割、声音编辑、时间线标记｜画面、精剪、画面与字幕预设｜修复素材”。文字／字幕统一管理创建、导入与下载，字幕另提供搜索和批量操作；视频画面浮层用小页签切换动画、转场、裁切、调色和局部处理，精剪单独打开。素材修复自动检查并只列问题项，异常时入口显红。

关键帧列表、手动同步起点和恢复副本使用 `EditorDisclosure`：原生 button 支持 Enter／Space，plus／minus 与“展开／收起”表示状态，`aria-expanded` 与 `aria-controls` 关联内容。内容保持挂载但收起时隐藏，不能遗失子控件编辑状态。左侧工具沿用图片编辑的浮层样式、顶部锚点、标题与关闭按钮，内部滚动；标记、预设等浮层与同组工具互斥。下拉通过编辑器内独立 portal 显示，避免滚动容器裁切。声音预设、画面与字幕预设明确显示作用对象，关闭保留复制内容和名称草稿，只应用到同类对象；响度浮层关闭不终止分析。

对象右键保留已选集合与主对象，关联组按整体处理；仅右键未选对象时切换选择。复制写入剪贴板，由粘贴决定目标时间；创建副本立即追加到选中组末尾并保留组内偏移。空白处提供粘贴，所有对象命令复用快捷键的事务与锁定规则。常驻文案只保留单位、作用对象和异常原因，操作说明集中在帮助或悬停提示。

视频裁剪由左侧画面工具发起，画布保留“应用／取消”，命令层高于选择／裁剪 SVG，裁剪区域的整面拖动命中不能挡住按钮。画布自身裁切溢出，手柄与工具都留在可操作范围；这些辅助层不参与导出。

拖动起点把焦点交给手势容器；Escape、指针取消、对象切换、控件卸载或中途进入只读／锁定，都恢复开始时状态并结束预览事务。一笔完成操作只产生一次撤销，取消不会提交临时值。画布命令浮层位于 SVG 命中层之上，并避让缩放／旋转手柄。只读和锁定既影响控件，也影响提交校验，不能仅靠按钮禁用。安全区、工具浮层、预览设置和保存反馈不参与导出画面。

实现细节见[音频时间线](07-workbench.md#音频时间线)和[视频编辑实现](08-video-editor.md)；容量与验收限制见[工作台使用指南](../01-user-guide/02-workbench.md#音视频共用操作)。

## 设置

SettingsCard／SettingsRow 按名称、说明、状态及控件组织，路径换行。辅助说明收入帮助，错误、路径和未保存状态直接显示，AI 分类切换保留草稿。

存储只提供一个应用数据目录，清楚区分当前与待迁移位置；占用按固定子目录统计，数值右对齐。迁移与缓存清理分别确认，完成后显示实际状态或释放大小，不能将“已安排”显示为“已迁移”。
