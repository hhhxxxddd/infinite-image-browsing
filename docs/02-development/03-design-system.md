# 03 · 设计系统

[文档首页](../README.md) · [React 界面](06-react-mantine-preview.md#视觉规则)

## 1. 品牌与主题

品牌为“星空馆／OmniGallery”，副标题“收藏所爱，创作所想”。星轨图标使用石墨底板、银白星光与弧形轨迹，源文件是 `frontend/public/favicon.svg`；在 frontend 下用 `npm exec tauri icon -- public/favicon.svg` 同步桌面图标。字标使用现代黑体、字重 500、字距 1px；包名、应用标识和已有存储键保持兼容。

唯一主题来自 `frontend/react/design/theme.ts` 与 `global.css`，使用 Mantine 和 `--omni-*` 语义变量。页面与编辑器沿用共用颜色和控件样式。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 工作区域 | `#f7f7f7` | `#171819` |
| 侧栏／顶部 | `#eeeeee` | `#202123` |
| 面板 | 白色 | `#252628` |
| 导航选中 | 银灰底 `#e3e4e7`／文字 `#454852` | 石墨底 `#393b42`／文字 `#c6c8cf` |
| 主要操作 | 蓝色第 6 档 `#356cb6` | 蓝色第 3 档 `#8cb8ed` |
| 工作区产物 | 柔黄底 `#fff4d1`／文字 `#6e5610` | 暖黄底 `#463c20`／文字 `#e6ca77` |
| 语义状态 | 绿色成功、琥珀警告、红色错误／危险／收藏 | 同用途，按主题调整深浅 |

导航使用石墨银灰；蓝色用于主要按钮、业务选择和焦点。普通控件及图库卡片圆角 7px，容器 10px、弹层和编辑器属性面板 14px。常规字级为 12／13／14／16／20px；编辑器在 `.react-editor-shell` 内保留紧凑密度。填充控件按实际背景解析前景色，避免浅底白字。标签使用预设配色，内置“喜欢”为红色。

## 2. 页面、控件与反馈

应用外壳由 `react/App.tsx` 组合；顶部与侧栏连续，内容区从顶部下方以 18px 左上圆角衔接。设置、工作台和挑一挑使用共用页框和独立正文滚动区；标题不参与正文滚动。媒体库使用吸附搜索与结果工具栏。宽屏正文铺开，设置控件最大宽度 440px；按容器可用宽度切换表单布局。

Tabler 图标统一线条，导航使用 19px、线宽 1.8，填充心形表示已收藏。品牌图标共用 SVG。保留键盘焦点、输入光标、禁用及悬停反馈；尊重系统减少动态效果。应用内确认用 Mantine 弹窗，菜单触发弹窗前先关闭受控菜单。

整页加载和渲染失败使用 `shared/PageState.tsx`，保留 `PageFrame` 的顶部区域，将提示限制在 460px 内并放在正文可用区域中央。编辑器使用独立全屏状态；读取制作文件时的加载、失败和未选择状态在编辑器内居中，避开浮动工具栏。编辑器渲染失败提供返回上一页和刷新入口。列表内部的空状态与操作错误保留在对应内容区。

`useNotice` 将反馈放在当前工作区域底部居中，避开多选条、素材条和播放控制。成功 2.5 秒、普通信息 4 秒、警告 6 秒、错误 8 秒；悬停或聚焦暂停关闭，重复操作替换同一调用方提示，最多三条。失败指定 error 类型。

## 3. 媒体库、目录与挑一挑

媒体库和挑一挑共用 `MediaArtwork`、`MasonryGallery` 和图库卡片样式。图片保留比例，音视频混排，收藏及播放入口统一；悬停只放大图片，不改变卡片和按钮尺寸。标签与文件名置于底部遮罩内，信息开关和卡片尺寸使用同一偏好。

挑一挑顶栏左侧是类型切换，右侧是上一批／换一批；下排展示批次数量和视图控件。点击卡片进入可切换项目的共用预览，不重复标题、说明或逐项查看按钮。

`MediaFilterPanel` 是右侧轻量浮层，无整页遮罩和焦点锁定。标题与底部操作固定，表单独立滚动。`MediaFilterForm` 管本地草稿，应用后才更新媒体查询；尺寸和比例字段各占两列中的一列，标签按组展示。标签编辑复用 `MediaTagPicker`，快捷菜单复用 `MediaTagMenu`，保留搜索、分组和选择状态。

目录总览复用图库搜索、添加按钮和结果工具栏。`FolderGraphCanvas`／`FolderGraphNode` 使用低对比点阵与清晰边界；根节点默认展开，用户展开／折叠选择持久保存，折叠父节点保留下级选择。总览纵向和各根图横向滚动位置在异步目录加载后恢复。

## 4. 预览与编辑器

`MediaPreview` 参考桌面图片查看器：顶部集中操作，文件名居中；底部展示规格、列表位置、缩放及信息栏开关。图标 20px、点击区域 34px，常态透明，悬停／选中时显示中性反馈，收藏为红色。`MediaDetailsPanel` 保留描述、生成信息、元信息页签，标签只在描述中显示；不足 700px 时信息移到画布下方独立滚动。

`EditorHub` 提供全屏编辑器入口。图片、音频、视频和 AI 界面采用顶部保存／导航、中央画布或时间线、右侧属性和底部素材条。使用 `--omni-editor-*` 中性表面与蓝色强调；普通媒体片段用蓝灰，字幕和标记用琥珀，电平表保留绿／琥珀／红阈值。输出图像和棋盘格不随界面配色改变。

图片裁剪／缩放、笔记和局部工具以浮动面板打开，不改变画布尺寸；窄屏限制宽高并独立滚动。视图缩放、输入尺寸和 AI 输出尺寸分别管理。保存状态等待持久写入确认后才显示已保存。

## 5. 设置与工作台

设置使用 `react/features/settings/components.tsx` 的 `SettingsCard`、`SettingsRow` 和共用帮助表现。名称、说明、状态及控件按行组织；路径允许换行，窄容器中上下排列。非必要说明收入圆圈问号，错误、当前路径和未保存状态直接显示。环境详情使用信息图标及加减展开按钮。

AI 接入分为本地模型、服务连接、使用设置，切换保留草稿。本地模型和量化由应用管理；在线服务连接只配置实际支持的来源。Studio 工作流在工作台配置入口管理。

`WorkbenchPage` 组合作品、制作文件、成果与素材。`ProductionDraftCard` 统一制作卡片，`WorkbenchMediaPicker` 和 `MaterialBar` 沿用共用媒体选择、筛选与预览。工作流参数、结果映射和 `WorkflowGraph` 沿用同一控件主题。AI 音频／视频当前为不可提交的占位界面。

工作区与作品使用雾蓝、青绿、陶土橙、灰玫瑰，以及深空黑、银、星光、午夜、天蓝九种柔和点缀色。新金属色借鉴 MacBook 外壳，界面色值自行适配浅深主题，不作为 Apple 官方色值。标题保留中性文字，颜色用于封面底色、小标签和细边框，文件预览保留原色。蓝色和青绿沿用 accent／success 变量，其余使用 `--omni-creative-*-soft`／`--omni-creative-*-ink`。卡片右上角的“更多”按钮使用中性文字和表面颜色，只随深浅主题变化。

`workbenchColors.ts` 为卡片、详情及弹窗预览提供统一颜色变量。缺少手动颜色时按稳定 ID 分配预设色；手动颜色保存为规范化的不透明六位十六进制值。自定义颜色生成浅深主题的低饱和背景及可读前景，不直接将任意颜色用作文字。`WorkbenchEditDialog` 在自身维护名称、目标和选色草稿，输入及拖动色盘不重绘背景卡片；只有保存时提交。“自动”清除手动颜色，取消丢弃草稿。

产物标记、数量入口、列表和缩略图占位统一使用 `--omni-product-soft`／`--omni-product-ink`，Mantine 控件使用 `color="product"`，覆盖作品页及编辑器共用素材条。黄色表示产物身份，大面板仅带轻微暖色；绿色“已同步”仍表示同步状态，琥珀警告使用独立的 warning 变量。

工作台顶栏使用“工作台／工作区／作品”的可点击层级路径，当前项标记 `aria-current`，长名称截断并保留完整标题。工具配置通过顶栏右侧的 `IconTools` 按钮进入，使用 `aria-expanded` 表示当前状态，不与应用设置的齿轮图标混用；取消正文上方的页面分栏。配置页面单独显示“工作台／工具配置”，再次点击工具按钮返回之前的工作区或作品；返回入口集中在顶栏。制作卡片中，音频使用 `--omni-audio-soft`／`--omni-audio-ink` 的柔和玫瑰色，图片与 AI 使用蓝色，视频使用青绿色；类型颜色与黄色产物标记分开。
