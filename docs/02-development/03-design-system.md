## 品牌与主题

“星空馆／OmniGallery”，副标题“收藏所爱，创作所想”。星轨源图 `frontend/public/favicon.svg`，桌面图标从同一 SVG 生成。主题来自 `react/design/theme.ts` 和 `global.css`，使用 Mantine、Tabler 与 `--omni-*` 语义变量。

| 用途       | 浅色          | 深色            |
| ---------- | ------------- | --------------- |
| 工作区域   | #f7f7f7       | #202123         |
| 侧栏／顶部 | #eeeeee       | #171819         |
| 面板       | 白色          | #252628         |
| 主要操作   | #356cb6，白字 | #8cb8ed，深色字 |
| 导航       | 银灰          | 石墨银灰        |
| 产物       | 柔黄表面      | 深暖黄表面      |

蓝为主要操作、选择与焦点，绿为成功，琥珀为警告，红为错误／危险／收藏，来源用中性标签。媒体内容不随主题改变。正文和状态文字对比至少 4.5:1，必要边界至少 3:1，由 `colorContrast.test.mjs` 验证。

保留键盘焦点、悬停和禁用反馈，尊重 `prefers-reduced-motion`。

## 页面与反馈

侧栏和顶部连续，正文左上圆角 10px。工作台、设置、挑一挑使用 PageFrame，顶栏固定、正文独立滚动；宽屏铺开，窄屏按容器调整，设置控件限制长度。

图库与挑一挑工具栏高 40px，与列表同底色，无底部分隔线，保留吸附模糊。搜索聚焦蓝边，深色内部 #34373b，浅色 #f1f4f8；AI 光晕独立绘制避免裁切。

PageState 保留顶栏，编辑器状态避开操作区。空状态和错误留在所属区域，useNotice 在工作区域底部居中、避开控制条，重复反馈合并。

预览顶部集中操作与文件名，底部规格／位置／缩放；信息区为描述、生成信息、元信息，窄屏移到画面下方。菜单开启弹窗前关闭所属菜单。

## 目录与工作台

目录返回／路径在左，递归开关、进度与操作在右。子文件夹是轻量横向入口，复用目录图标，文字与图标居中对齐。

首页星空铺到正文顶部和两侧，底部仅 10px 渐隐。工作区与作品共用铺边标题和正文左边距，返回统一距正文顶 10px；作品先标题，再素材。

| 层级     | 呈现                                         |
| -------- | -------------------------------------------- |
| 工作区卡 | 纵向封面，柔和投影和高光，悬停上移 2px       |
| 作品卡   | 横向紧凑，独立画布预览与日期                 |
| 制作卡   | 文件标题／类型图标，内缩预览，素材／产物入口 |

卡片圆角均 8px，装饰不拦截点击。音频用玫瑰、图片与 AI 用蓝、视频用青绿，产物标记另用黄色。

制作／成果是 42px 主切换与数量标记；制作类型为 12px、最小高 28px 的文字标签及短下划线。工作区素材用多列条目，44px 缩略图、两行名称，列表高 344px 后独立滚动，提供继续加载。

内嵌素材条纯黑底、灰边、高光，高 82px，卡片 64px，悬停／聚焦放大 6%。无左右箭头，右侧网格及添加。滚轮横向跟随，两端最多拉伸 24px 后回弹；少量与空列表保留同交互，减少动态效果时关闭动画。

素材浏览用类型／来源两组文字标签，保留搜索和键盘切换，窄屏换行。动画按需运行，不逐帧更新 React；拖拽、键盘、尺寸变化结束残余运动。

## 编辑器与设置

编辑器全屏：顶部命令、中央画布／时间线、右属性、底素材，共用深色变量，字幕／标记用琥珀。裁剪、缩放和笔记以浮层显示，不改画布尺寸，保存状态等待提交成功。

设置使用 SettingsCard／SettingsRow，按名称、说明、状态及控件组织，路径换行。辅助说明收入帮助，错误、路径和未保存状态直接显示，AI 分类切换保留草稿。
