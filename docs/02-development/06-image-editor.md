# 图片编辑实现

[文档导航](../README.md) · [图片制作](../01-user-guide/05-image-editor.md) · [工作台实现](07-workbench.md)

ImageStudio 共用工作区和媒体库编辑界面，保存目标由 EditorHub 上下文决定。领域模型位于 `frontend/src/features/image-editor/model`，交互组件位于 `frontend/react/features/editors`。

## 文档与交互

`StudioDocument` v2 保存图层、分组、画布和文字样式。载入校验结构、唯一 ID 和数值，保留全部有效图层与分组。分组保持连续层块，空组用 `stackIndex` 保存位置；整组变换包含隐藏成员并检查成员锁定。

`ImageGroupAssignment` 统一各类图层的归属标签与右键入口，支持多选批量移入／移出和新建分组。`moveStudioLayersToGroup` 原子检查源／目标锁定，保留成员顺序与几何、连续组块及空组位置；无变化时返回原文档，不产生撤销记录。组自身属性保留在常驻面板。

`EditorParameterSlider` 共用图片编辑与 AI 图片加工的单行参数布局，显式传入默认值和单位格式。重置沿用滑条变更回调，已为默认值或只读时禁用；视图缩放与笔刷重置不修改文档。

图片和文字属性按名称、类型设置、公共几何、不透明度排列。`ImagePropertyControls` 共用行与按钮布局，`ImageLayerGeometry` 单独订阅实时变换，统一比例锁定、尺寸、位置、画布对齐、旋转与翻转；`ImageTextProperties` 组合文字内容、排版和效果。只读、图层锁定及所属分组锁定均禁止修改属性。

`ImageTextEffects` 提供填充、描边、投影、外发光和背景的紧凑设置，更多参数用左侧浮窗。`imageStudioTextEffects.ts` 校验与补全旧文档默认值；`imageStudioTextRender.ts` 共用排版、字形绘制及效果边界，预览和导出不维护两套实现。

`ImageContextMenu` 负责画布与图层列表的共享菜单、视口边界定位和键盘导航；`ImageStudio` 根据打开时的选择快照生成动作。图片提供替换／铺满，文字提供模板，分组提供解散，画框提供内部内容选择；多选提供编组和合成，空白处提供添加／粘贴／画布设置。重命名、显隐及参数编辑不在菜单中重复铺开。

`imageStudioContext.ts` 复用渲染顺序与旋转／矢量裁切命中，生成重叠对象候选；右键选中内容保留混选，Alt 右键进入成员。继承锁定向上检查分组／画框，解锁仅作用于当前选择涉及的锁。`duplicateStudioItems` 同时映射图层、分组及画框成员 ID，独立复制数据；`orderStudioItems` 在分组／画框的兄弟节点之间进行四向排序，整组选中作为整体移动，保留成员归属和内部顺序。分组与画框删除复用确认框，`deleteStudioSelection` 原子检查锁定并清理受影响的空组。每次文档修改进入同一撤销栈。

`imageStudioGeometry.ts` 统一旋转命中、变换、对齐和裁剪边界。裁剪用原素材归一化坐标累计，按实际选框保留小尺寸裁剪；翻转时反向映射源区域，画框仍使用显示坐标。图片和文字的 `flipX`／`flipY` 随文档保存，旧图片文档默认不翻转；预览和导出共用渲染。源快照保留真实宽高，文字预设、排版与拟合由 `imageStudioText.ts` 提供。

变换和裁剪分别使用 `imageTransformPreviewStore`、`imageCropPreviewStore`。手势按动画帧合并，画布、选框和几何属性订阅同一预览，避免重绘整个编辑器；开始文档保持不变，结束一次提交、一次撤销，取消清除预览。中键／空格平移只更新视口 CSS 位移。

## 工具栏与校正

EditorHub 的使用说明按“工具与操作／快捷键”分 Tab。图片操作说明用六组短句概括选择、内容与模板、调整与视图、AI 工具、合成及保存；保存说明区分媒体库与工作区。快捷键分为保存与历史、选择与图层、移动与视图、文字与退出四组，提醒输入框及已聚焦控件优先处理按键。帮助使用 `shared/lib/shortcut.ts` 的 `imageStudioShortcutGroups`，设置页使用由其展开的 `imageStudioShortcuts`，共用一份描述；Ctrl / Cmd + G 打开编组确认，复制／粘贴支持图层和分组混选。

左侧工具弹窗共用工具条顶部锚点（`useEditorToolAnchor`，同时用于 AI 图片编辑），由 ResizeObserver 同步至编辑器容器的 CSS 变量；Portal 弹窗固定在该位置，超出视口的内容内部滚动。

`ImageTransformTools` 在一个左侧入口中提供裁剪／尺寸／校正 Tab；尺寸输入、比例预设和校正即时更新文档。尺寸值订阅实际几何，比例锁定与重置基线仅在打开面板或切换对象时初始化，避免每次实时更新覆盖用户选择。重置仅恢复本次会话的宽高，沿用图层中心缩放或画布中心扩边，进入撤销栈；切换 Tab 不重建基线。`ImageAITools` 已接通单图层 Qwen2.1 消除、SAM3 抠图和 SeedVR2 高清化。撤销重做移至顶部，对比入口并入底部视图操作。

图片层可选 `correction` 保存水平、垂直透视及中心径向畸变（-100～100）和内容旋转（-180～180°）；缺省为中性值，旧文档缺少 `center` 时补 0，读取时清洗非有限数。`imageCorrectionMapping` 预计算保持像素纵横比的逆旋转、透视及径向映射，按四角约束与径向安全范围计算覆盖缩放，使原图不透明时校正不会产生新的空角。图层边框与文档尺寸不变。

`imageStudioCorrectionRender.ts` 在原图坐标内使用上述映射，再沿用 crop／fit／flip／亮度／对比度流程，使裁剪后的可见像素与保存重开保持一致。预览和导出共用 WebGL 双线性采样及缓存；GPU 不可用或超过纹理上限时回退 CPU 采样，不降低原图输出分辨率。CPU 每帧只计算一次变换参数，透明像素按预乘 Alpha 插值。辅助网格仅用于编辑，不参与导出。

选择状态分别记录图层 ID 与分组 ID，画布及列表 Ctrl 点击增减选择。`studioSelectionIds` 展开分组和画框成员并去重；`regroupStudioSelection` 合并成员、保留内部 frameId、移除受影响的空组，不创建父子分组。分组删除复用确认框并通过 `deleteStudioSelection` 原子检查成员锁定；多选平移每个成员仅移动一次。编组、删除和拖动均进入原有撤销栈。

## 图层合成

`imageStudioMerge.ts` 展开多选、分组和画框，计算包含旋转描边／文字效果的内容边界；保留画布外内容。选中部分画框成员时，边界与父框相交，渲染仍使用完整父框的矢量路径和不透明度。`renderStudioDocument` 的 `selection` 范围只绘制选中成员，祖先画框仅提供裁切上下文，不引入未选中的底色和边框。

`ImageMergeModal` 默认透明底，可选纯白底和保留原图层；用原始像素 PNG 合成，单边上限 16384、总量一亿像素。源文档不变时才将结果作为根图片层追加至整个栈顶；替换与组清理一次提交，撤销／重做无需重新渲染。渲染或上传失败不修改图层。源图层锁定、空可见内容、只读或正在裁剪／编辑文字时不允许合成。

`POST /api/image-editor-assets` 验证静态 PNG、解码像素及 64 MiB 上限，按 SHA-256 去重、原子保存至 `project-data/image-editor-assets/<hash>.png`，返回 `editor-asset:<hash>`。GET 同名资源接口受认证保护，POST 另检查写权限。`managedImageAssets.ts` 为预览、导出、缩略图及模板提供统一资源解析；媒体库保存时将该资源复制进编辑历史快照。合成资源不属于缓存，目前不自动回收，确保撤销及其他文档引用可用。

## 单图层 SAM3 抠图

`useImageAITasks` 管理选点／选框、参数、后台轮询与结果应用；`ImageCutoutOverlay` 使用青色虚线与角标标识输入范围，将画布坐标逆旋转到图层局部坐标，保存归一化提示。`imageCutoutInput` 使用完整源图分辨率渲染局部图片平面，烘焙裁剪、填充、内容放大、翻转、校正、亮度／对比度和圆角；不烘焙位置、旋转、图层不透明度与所属画框。上限为 8192 单边及 1600 万像素，默认返回同尺寸透明 PNG。

`trim_transparent` 为严格布尔值，默认 false，UI 命名「按边缘裁剪」，编辑器本次参数及内置工具全局默认值均可设置。后端对原图 alpha 与遮罩相乘后的非零 alpha 求包围矩形，实际裁剪 PNG，并返回相对完整输入的 `result_bounds`；透明孔洞与半透明边缘保留，空主体报错。前端按该矩形调整图层几何，通过旋转后的中心偏移保持主体世界坐标不变。再次抠图保留完整原输入及提示，并用 `cutoutInputLayer` 逆算其画布范围；提交时 `source_bounds` 记录当前图层在完整输入中的范围，避免重复裁剪累积缩小，也允许关闭裁边后恢复完整输入范围。旧任务缺少范围字段时按完整矩形兼容。结果直接应用到图层，面板不提供额外查看结果链接。

结果按文档、图层和工具保留一个成功槽位。`list_jobs` 返回每个槽位的最近任务及最近成功结果，旧历史在读取时折叠；`currentCutoutJobs` 在前端作相同归并，面板只显示当前图层的最近任务状态。新成功结果将完成状态与去重的 `recovery_steps`（旧来源版本、输入／输出裁边和结果资源）一次原子写入，再通过 `_retire_results` 清除旧回执的输入、输出和提示引用；旧回执保留请求摘要与已处理标记以保证幂等。恢复链用于找回连续未保存的加工结果，不作为历史列表展示；失败或取消不清除上一组成功结果。共享 PNG 不在这里删除，避免破坏撤销、重复图层或其他文档的引用。

`useImageAITasks` 的 `selection / before / after` 视图绑定图层及最近成功任务 ID，成功后默认显示处理后。UI 顶层仅保留 AI 功能 Tab；选区用三个工具按钮统一切换保留点、排除点、框选，工具提示承担操作说明。结果预览用独立对比区和「显示处理前」开关，「调整选区／查看对比」按钮切换编辑与预览。`cutoutBeforeDocument` 仅为渲染构造当前图层的完整输入替身，保留移动位置、旋转、分组、画框和其他图层；不写入文档或撤销栈。`ImageTransformPreview` 统一渲染该对比文档，`ImageCutoutOverlay` 在对比时只读并保留青色边框；它订阅同一 `imageTransformPreviewStore`，先取实时图层再按 `inputBounds` 恢复完整输入范围，使拖动中的图片、外框和提示坐标保持同步。撤销到更早结果不会重新激活旧任务的对比槽位。

`image_editing/cutout.py` 固定调用 `ai/builtin_tools.py` 的 `image-cutout-sam3` v1 流程（SAM3.1 checkpoint），不再自动选用兼容的用户预设。任务持久记录工具 ID 和版本。执行副本移除文本条件分支和非当前模式的提示，保持 `individual_masks=false`；点坐标转换为像素坐标 JSON 字符串，单框转换为像素矩形。`refine_iterations` 为严格整数 0–5，UI 命名「边缘精修」，出厂默认 3，全局默认值通过 `/api/image-cutout/config` 提供，界面可覆盖本次参数。跨标签配置变更通过 BroadcastChannel 刷新默认值，不覆盖已有选区或正在执行的任务。`threshold` 不向用户开放，因为节点的点选／框选路径不使用它。

接口为 `GET /api/image-cutout/config`、`GET /api/image-cutout/tasks?document_key=...`、`POST /api/image-cutout/tasks` 和 `POST /api/image-cutout/tasks/{id}/{cancel|handled}`。所有接口要求认证，写接口检查写权限。`imageToolSubmission` 按工具与完整请求摘要在发送前持久保存 UUID，响应未确认时（包括刷新后）重试复用该编号，成功响应后才清除；存储失败不发送。后台按请求 UUID 与内容摘要去重、每图层只允许一个待处理任务；最多 2 个执行、8 个含排队任务。后台复用 Comfy Cloud v2 上传／提交／等待／下载链路，不经过会自动创建工作区产物的 StudioTasks。

任务原子持久化至 `project-data/image-editor-tasks/<document-key>/<uuid>.json`，输入与透明结果通过 `image-editor-assets` 去重保存。白遮罩保留，最终 alpha = 输入 alpha × 遮罩；拒绝非灰度、全空和尺寸不匹配的遮罩。任务不保存 Key；取消立即阻止结果应用，无法保证云端停止计费。后端重启将遗留待处理任务标记失败，保留已知云端编号，不自动重提付费请求。

应用结果前再次比较图层 ID、像素内容摘要、宽高比和锁定状态；结果保留最新位置，删除目标不会复活。处理中由 `imageStudioProcessing.ts` 对文档变更、撤销／重做和手势预览统一验证，仅放行目标及所属画框的平移，保护所属分组属性；属性控件、右键、列表和快捷键同步禁用相关操作。`ImageProcessingOverlay` 订阅变换预览，显示仅用于编辑视图的遮罩与状态，不参与导出。任务进入完成态但尚未应用时仍保留限制，失败或确认取消后解除。拖动和文字／裁剪编辑期间延后应用，结果写入最新文档并进入一次撤销事务。处理回执分为会话去重和持久确认：`ImageToolReceipts` 在开始保存时捕获已处理编号，工作区 flush 或媒体库覆盖成功后才确认这批编号；保存失败、后到结果、保存副本均不提前确认原文档。浏览器只持久保存已确认回执和取消决定。`recoverImageToolResult` 为已 handled／accepted 或连续未保存的结果提供显式恢复：按严格来源版本遍历恢复链和同层其他工具的成功结果，保留锁定、删除与是否已应用校验；中间状态只在内存计算，最终结果一次写入撤销栈，不自动重放用户的撤销。旧版本已清除的恢复链无法重建。重新抠图复用任务保存的原始输入；媒体保存的 `snapshot:<hash>` 与相同 `editor-asset:<hash>` 视为同一图片内容。结果沿用媒体库明确保存／工作区自动保存的原契约。

## 单图层 SeedVR2 高清化

`image-upscale` v2 保留用户提供的 12 节点 SeedVR2 图、UNet、VAE、种子、采样器、分块及透明后处理。`target_resolution` 为 `original|2K|4K|8K`，默认 `4K`；提交注入 LoadImage `1`，将 ResizeImageMaskNode `4:12` 设为 `scale shorter dimension`，`resize_type.shorter_size` 为 2048／4096／8192；原尺寸使用 `scale by multiplier` 和 1，仍经过采样器。长边采用节点相同的四舍六入五成双取整，再按 SeedVR2 输出向下对齐偶数，前后端预览与校验保持一致。输出读取 SaveImage `2`。旧请求仍兼容整数倍率 1／2／4，但不得与目标分辨率同传；旧默认 1 迁为原尺寸，旧 2／4 迁为 4K（缺少输入尺寸，无法等价映射）。旧任务回执保留倍率；新默认值只保存 `target_resolution`。

`ImageUpscaleTools` 显示短边档位、尺寸预览、开始按钮和最近结果对比。`imageToolDimensions` 与输入渲染共用像素尺寸计算，原尺寸模式不静默降低输入分辨率；采用前再次运行且内容匹配时复用原始输入；采用后重新读取当前结果的原生尺寸。`upscale.py` 在提交前校验结果单边不超过 16384、像素总数不超过 1 亿、最短边至少 2 像素；下载上限 64 MiB、云端等待上限 30 分钟。结果只校验 PNG、单帧及尺寸，原样入库，不在本地重建或覆盖 Alpha。工作流的 JoinImageWithAlpha → ResizeImageMaskNode → SeedVR2PostProcessing 已恢复透明通道；该后处理会向下对齐偶数边长，前端预览及后端校验同时兼容。其他尺寸不匹配直接失败，保留当前图层。

高清化接口为 `GET /api/image-upscale/config`、`POST /api/image-upscale/tasks`；共享轮询和回执使用 `/api/image-ai-tools/tasks`、`/api/image-ai-tools/tasks/{id}/{cancel|handled}`，保留旧抠图 URL 兼容。`cutout.py` 承担共享持久化、队列、取消和幂等，SAM3 与 SeedVR2 各用独立适配器，跨工具同一图层互斥。`useImageAITasks` 用一个轮询／结果应用循环处理所有工具，避免并行回传覆盖其他图层的更新。结果槽位以图层 ID + 工具 ID 隔离；透明素材、处理锁、撤销、实时移动和媒体库／工作区保存约定均复用。高清化不写 `source_bounds/result_bounds`，仅替换图片像素，保持画布几何。

## AI 结果采用与连续编辑

三个工具共用 `POST /api/image-ai-tools/tasks/{job_id}/accept`。采用只接受未被替代的成功结果；同图层存在进行中的任务或其他未回填结果时返回 409，保持写权限校验和幂等性。服务端为该图层已有的成功槽位写入 `accepted_at` 与 `handled`，不删除像素资源，因此文档及撤销引用仍有效；重复采用旧任务不会采用后来产生的新结果。

`previousCutout` 将已采用结果排除出重试／对比输入，后续请求直接渲染当前图层。前端按采用时间保护已确认状态，避免旧轮询响应恢复对比；选区草稿的键包含输入版本和采用时间，清除旧点位、笔迹、框选及裁剪偏移。采用结束本轮对比，下一轮成功后形成新的一组处理前／后；文档回填产生的撤销记录继续有效。

## 单图层 Qwen2.1 消除

`image-erase` v1 使用随代码发布的 `ai/erase_workflow.py`，基于提供的 Qwen2.1 API 图保留模型、采样器、局部编码／重绘／贴回路径；8 号 `InpaintCropImproved` 关闭预缩放、填洞、额外遮罩扩展、反转、阈值过滤和扩图，上下文系数设为 1，输出缩放开启并按 32 对齐。明确使用 CPU 裁切逻辑以固定几何规则。增加 16／17 号 `LoadImageMask(channel=red)` 分别加载涂抹遮罩与矩形上下文，不借用原图 alpha。`blend_pixels` 为严格整数 0–256，出厂默认 16；`prompt` 可编辑，处理宽高为 64–4096 的 32 倍数。内置默认值全局共享，自定义副本移除独立上下文输入，恢复自动参考范围。

`ImageEraseOverlay` 使用图层局部归一化笔迹，逆旋转映射指针，拖动过程局部刷新，提交时从原生分辨率黑白 PNG 扫描真实非零包围框。显示透明度与遮罩强度分离；橡皮擦删除遮罩，支持图标单笔回退。涂抹与擦除共用随图层缩放的 DOM 笔刷轮廓，用颜色、实虚线及加减号区分；指针移动直接更新位置，离开图层、拖框或平移时隐藏。范围入口统一为局部／整图，局部保留 auto/manual 两种内部状态，直接拖边线／标签移动、拖控制点缩放，区域内部不拦截涂抹。整图禁用框调整，手动局部可重置为自动。`imageStudioErase.ts` 与后端 `erase.processing_box` 对齐遮罩融合支持范围、上下文并集、目标比例及贴边移动／补边，画布显示最终处理范围；手动画框不能排除融合后的消除区，移动时按该支持范围限制位移而不拉伸矩形。服务端从实际上传遮罩重新计算并校验 `processing_box`，不一致时在云端提交前拒绝。空遮罩、尺寸错误、彩色遮罩、非法参数或过大的补边范围同样提前拒绝。

`GET /api/image-erase/config` 返回配置；`POST /api/image-erase/tasks` 接受原图、独立遮罩、笔迹、矩形、处理尺寸、融合值与提示词。输入与输出均为完整图层像素平面，不静默缩小高分辨率输入。原图／遮罩／上下文各上传一次，读取 2 号输出，验证结果为单帧同尺寸 PNG；提供的流程使用 RGB 贴回，本地仅在输入含透明通道时恢复原 alpha。共享任务队列负责图层互斥、幂等、取消、刷新恢复与结果槽位；PNG 仅进入编辑器资源，不生成媒体库素材或工作区产物。成功后只更新图片像素，保持图层移动、旋转、尺寸及归属，失败／取消保留上次成功结果。

## 共享文字模板

`imageTextTemplates.ts` 从完整分组或单个文字图层生成局部坐标快照，使用不受原画布裁切的旋转／特效完整边界，保留画布外内容和隐藏成员的数据。模板组恢复为可见、解锁状态，成员自身显隐／锁定状态保留。套用创建新组和新图层 ID，保持层级与相对位置，过大时等比缩至画布 85% 以内；字号、字距、特效及图片圆角一同缩放，作为一次文档更新进入撤销和自动保存。

文字侧栏内嵌 `ImageTextTemplates` 的紧凑列表，复用搜索、分页、预览和管理逻辑；两列卡片使用 72px 高预览，列表独立滚动，搜索框与文字预设保持可见。重命名和删除确认也在该面板内完成；版式／整页模板仍使用独立模板库。无画框时禁用“保存当前版式”，与 `capturePageTemplate` 的空版式检查一致。

后端 `templates` 模块服务整个应用：`GET/POST /api/templates` 列表／创建，`GET/PATCH/DELETE /api/templates/{id}` 读取／改名／删除，`POST /api/templates/{id}/instantiate` 生成独立套用载荷。列表按名称搜索及分页，每页默认 12 项；自定义模板的 PNG 预览单独读取，没有持久预览的预置在前端生成卡片预览，避免列表载入整幅配图。写操作受只读权限保护。

保存时客户端通过现有认证资源 URL 读取原始素材、历史快照或工作区产物，提交完整字节；后端验证文档版本、分组关系、500 层上限、图片内容及 64 MB 总量，持久化完整资源包，不读取客户端任意本地路径。`type` 区分 `text`、`layout`、`image`，分别使用 `image-group-v1`、`image-layout-v1`、`image-document-v1` 载荷。列表通过 `type` 过滤，缺省 `text`，兼容既有调用；音视频类型尚未开放。

模板浏览使用 `template-library:<id>:<sha256>`，套用后使用 `template-asset:<sha256>`。`templateAssets.ts` 验证引用格式并生成认证 URL；渲染可直接从引用恢复文件信息，重新打开工作区不依赖上次会话缓存。媒体库保存时 `history.prepare` 将套用图片收入自身快照，模板删除不会影响既有作品。底层目录与回收边界见[共享模板存储](09-storage.md#共享模板)。

6 套默认文字组合由 `templates/defaults.py` 定义；`comic_defaults.py` 另提供 4 套矢量气泡和 2 套整页漫画。初始化分别使用 `seeded-v1.json`、`seeded-comic-v1.json`，旧安装会补齐新版预置，已删除预置不会恢复。预置记录也允许改名／删除，初始化标记防止下次启动重新出现。

## 矢量、画框和页面模板

文档 v2 增加 `shape`／`frame` 图层及可选 `frameId`。形状使用归一化四边形顶点、气泡尾点、填充、描边和圆角；不接受任意 SVG/XML。`imageStudioVectors.ts` 产生 Canvas Path2D 与 SVG 选框共用的路径，普通形状参与导出，与仅作 AI 批注的 guide 分开。frameId 只指向一个根画框，读取时清除失效引用并阻止画框嵌套。

图层继续保存世界坐标。`changeStudioLayer` 平移／旋转画框时更新子层；改变外框宽高时保持内容几何，供独立构图。隐藏／锁定父画框影响子层。`studioFrameOrder` 将画框作为原子绘制块，先填背景，子层按自身顺序裁切，最后画边框；边框索引与父引用按帧预建，避免每个子层重复扫描层栈。图片解码和文字绘制缓存仍复用。点击命中先检查真实画框轮廓，双击／Alt 点击进入子层。顶点和尾巴拖动沿用原有实时预览、取消和单次撤销机制。

复制画框重新映射子层的 frameId 和内部组 ID；删除一起移除子层。模板插入、剪贴板和工作区持久化保留这套关系。`imageStudioLayouts.ts` 生成 6 个基础拼图、5 个漫画分镜的可编辑画框，应用时不删除原有素材。空版式快照仅保留画框；整页快照保留图片、文字、形状、画框、分组，排除 AI 批注。整页应用先确认，再作为单次文档替换，保留当前制作文件身份并重新分配层／组／容器 ID。

后端文字模板要求单组且至少一层文字，可含图片、形状和画框，捕获画框时包含其子层并重新映射容器引用；版式仅含画框；整页允许多组及画框关系。矢量字段、控制点范围、分组唯一性和容器引用均校验。模板配图仍独立持久化，清理缓存或删除模板不会删除已套用素材。

## 预览与导出

`studioPreviewScale` 根据显示尺寸、缩放和设备像素密度绘制文字，缓冲区上限为单边 4096 像素、8 Mi 像素。图片解码与绘图缓冲区复用，过期帧取消；透明区域完整替换。预览缩放不改变文档坐标或导出分辨率。

导出按文档及保存范围计算尺寸，内容区排除隐藏层和编辑批注，并考虑旋转与文字描边、阴影、发光、背景扩展边界。媒体保存的格式和尺寸上限见[使用指南](../01-user-guide/05-image-editor.md#保存与导出)，素材及快照必须走[带认证的资源 URL](05-architecture-performance.md#访问与文件完整性)。

## 两种保存目标

| 目标       | 保存契约                                                                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 工作区制作 | 一次编辑会话复用 `createPersistentImageDraftRepository`，初次载入记录观察版本；`EditorSaveQueue` 串行保存，失败保持 dirty，切换前等待 flush |
| 媒体库文件 | `/api/image_edit_history` 返回文档及当前文件摘要，`/api/edit_image` 提交合成图片、文档和 `parent_revision`                                  |

工作区每次写入读取新索引，但不能重建会话仓储或刷新已观察的文档版本。事务拒绝其他窗口修改及已删除制作文件，成功后才更新观察值和缓存。

媒体的 `parent_revision` 是打开时文件的 SHA-256，成功覆盖后更新为返回记录的 `output_hash`；它与稳定的记录 `id` 用途不同。准备快照和发布前检查源版本，过期请求拒绝保存。覆盖更新一个记录，副本另建记录，不切换当前原图编辑目标。`mergeSavedMediaAssets` 仅在覆盖时更新当前文档的快照映射，保存副本只登记输出文件，保留原图快照的归属和修订。

应用数据目录中的 `project-data/omnigallery-edit-history` 保存记录、输出摘要映射和去重素材快照，随统一根迁移且不参与缓存清理。各次编码加入独立修订标识，BMP 使用私有尾部及更新后的文件长度，避免相同像素串用记录；摘要映射支持文件改名。媒体文档最多 500 图层、JSON 序列化字符数不超过 800 万，超限明确拒绝，保存范围为 `content` 或 `canvas`。

## 高级 AI 加工入口

图片编辑顶部及分组属性中的旧 AI 分支入口统一迁至 `AI 工具 → 高级`。仅工作区开放创建：要求单个可见、未锁定、未处于内置 AI 加工中的图片图层；多层内容先合成。`prepareAdvancedAIInput` 按图片旋转后的边界取得透明快照，保留父画框的裁切及不透明度，但排除画框填充、描边、其他图层与标注。输入长边上限沿用 2048 像素。

`installAIBranch` 分开验证来源制作文件与目标作品：可加入同工作区的已有作品，或在同一次工作区状态事务中新建作品并保存 AI 制作文件。AI 会话键使用目标作品 ID，来源仍记录原图片制作文件、修订、图层和路径。创建前等待来源保存；快照建立失败或安装失败时清理临时输入，安装结果不确定时保留输入并核对服务端状态。

高级面板订阅作品状态，展示目标作品拥有的 AI 图片产物及制作文件。产物按 `document_id` 归属过滤，排除其他作品、其他工作区及私有输入；打开面板时每 5 秒刷新，关闭后停止，支持手动刷新及预览。

媒体库免建作品的高级加工仅记录后续方向，尚未实施：任务与临时输入应独立于作品存在，返回结果作为产物管理；明确保存到媒体库后才成为成果。不应为每次加工隐式创建作品，也不应把 AI 返回值直接写入媒体库。
