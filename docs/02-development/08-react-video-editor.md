# 08 · React 视频剪辑编辑器

`frontend/react/features/editors/VideoStudio.tsx` 是 React + Mantine 视频剪辑编辑器。它接收 `EditorHub` 解析后的工作区、作品与制作文件上下文，在同一个界面展示工作区素材、画面预览、时间线和片段属性。旧版视频页仅提供布局预览；新编辑器的制作数据采用独立版本格式，由 `backend/src/omnigallery/workspaces/video_studio.py` 使用本机 FFmpeg 渲染成 MP4 工作区产物。

## 制作文件

每个视频制作文件在版本化工作区状态中保存一个 `omnigallery:video-timeline-v1:<workspaceId>:<draftId>` 条目。内容包括画布宽高、帧率、画面片段、声音片段、字幕和标记。片段只引用已有工作区素材或工作区产物；原媒体不复制。载入时验证结构与关键数值，无法读取的数据保持原状并提示错误。编辑后约 900 毫秒自动保存，也可点击“保存”或按 Ctrl/Cmd+S；写入走 `mutateWorkspaceState`，避免覆盖并行修改的其他工作区字段。

## 当前操作

| 操作       | 行为                                                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 加入素材   | 图片进入画面轨；音频进入声音轨；视频默认同时进入画面轨和声音轨，也可以只加入其中一轨。位置采用当前播放头。                             |
| 拖动与裁切 | 拖动片段主体移动，拖动两端裁切；靠近播放头、标记及其他片段边缘时可吸附。属性面板可精确设置开始时间、时长、源文件起点、速度与声音音量。 |
| 拆分       | 选中片段后在播放头处分成前后两段，后一段的源文件起点随之调整。                                                                         |
| 字幕与标记 | 在播放头添加字幕或标记，并在属性面板编辑内容、起点与时长。字幕叠加在画面预览上。                                                       |
| 预览       | 播放头驱动图片、视频及独立声音片段；视频画面静音，声音由声音轨播放，避免重复播放原声。                                                 |
| 删除       | 仅删除选中的片段、字幕或标记，不删除源文件。                                                                                           |
| 导出       | 先保存当前制作文件，再将 H.264 视频与 AAC 声音封装为 MP4 产物；用户可从作品成果中选用它。原媒体保持原状。                              |

## 渲染契约

导出调用 `POST /video_studio/export`，提交工作区、制作文件 ID、已保存内容的 SHA-256 修订、时间线文档和产物名称。后端在渲染前及提交产物事务时核对制作文件仍存在且内容与修订一致。原始文件路径经过媒体库路径信任检查，工作区产物引用只允许本工作区且类型一致。FFprobe 检查实际画面／声音流及时长；无法解码或片段超出源范围会直接报告错误。渲染的临时文件位于工作区产物目录，同卷原子发布；失败时删除临时文件，不登记半成品。

画面底色是黑色。每个画面片段按比例完整放入画布，留空处以黑色填充；重叠时较晚开始的片段位于上层，同起点按保存顺序叠放，结束后露出下层。图片（包括动图）作为静态首帧使用，其时长由片段长度决定；视频按源文件起点和速度播放。声音轨独立混音，视频的原声只有加入声音轨才进入成片；速度使用 FFmpeg 的 `atempo` 保持音调，音量对应片段增益。字幕作为 UTF-8 SRT 在画面合成后烧录，文字不拼入 FFmpeg 命令或滤镜表达式。标记点不影响成片时长。没有画面时仍可输出黑底声音／字幕视频。当前没有转场、关键帧动画或动态图片播放。

当前输出限制为最长 60 分钟、最多 3840 × 2160 像素、60 fps、画面轨与声音轨各 64 个片段及 256 条字幕。画布宽高需为偶数，以保持 H.264 常见播放器兼容性。FFmpeg 需要 `libx264`、AAC 和相应滤镜；含字幕的成片还需要 `subtitles` 滤镜。用户可在“设置 → 运行环境”检查 FFmpeg。导出的 MP4 通过既有工作区产物与成果流程管理，可下载或在选为成果后同步到媒体库。

针对性集成测试生成真实图片、视频和声音，检查画面顺序、速度、混音、字幕烧录、产物缩略图、路径信任、陈旧修订与源文件越界。浏览器预览仍由 HTML 媒体元素完成；复杂编码、颜色空间和浏览器／FFmpeg 解码差异需用实际素材继续视觉验收。
