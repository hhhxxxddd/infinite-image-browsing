# 09 · React 功能对照与验收

迁移以可操作的 Vue 页面、实际后端接口及现有制作文档为依据，不从按钮名称推测功能。Vue `/` 与 `/legacy.html` 保留作对照，React 位于 `/react.html`。两套界面共享媒体索引和版本化工作区状态；原媒体、现有画布和测试数据均保留。

## 编辑器对照

编辑器采用全屏工作区：浮动保存/导航、左工具、中央画布或时间线、右侧可滚动检查器、底部共用素材条。素材条有箭头、横向滚轮、网格、引用/产物分隔、类型/来源筛选及用途操作；悬浮仅轻微放大组件本身。各编辑器有工具介绍与快捷键表，未接入的 AI 服务明确说明边界。

| 编辑器            | 保留或新增行为                                                                                                                                                               | 数据与接口                                                                                                                                                   |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |

## 真实操作验收

2026-09-30 使用原 Vue、React 和同一后端核对真实本机媒体。新增 `React功能回归验证` 作品及产物保留供复查。

- 媒体库：顶部搜索、混排、选择交互；长列表滚动时搜索、筛选及多选工具栏固定，目录页搜索栏也保持可用；原生拖动排序落库后恢复原有手动顺序；目录图标修改后恢复；图片缩放/旋转和视频解码通过。
- 收藏：卡片右上角直接收藏不触发预览或选择；取消最后一个标签后清除缓存和喜欢标记。真实 MP3 完成收藏/取消往返并恢复原状态，空标签及批量混合路径有回归测试。
- 目录：右键递归查看及重载保持 `mode=walk`；真实磁盘分批加载、预览跨页接续和分享链接通过。普通目录开启 2 秒轮询后，新加入的回归 JPG 自动出现，随后停止轮询并恢复原间隔；回归文件保留。
- 图片对比：候选菜单曾被画布遮挡，修复浮层后实际换图成功；滑动/并排、逐词高亮、字段差异、九宫格和全屏通过。
- 工作台：现有用户 4 层画布保持；素材条滚轮/箭头、方形网格和 1.025 倍悬浮反馈通过；高级素材选择器过滤后取消，未更改用户引用。
- 图片：原图保存副本后重开，文字和两层文档恢复；测试图层/分组创建、分组 AI 来源“画面与文字”通过，原件不变。
- AI：主/参考图保存重开、标注与提示词提取、参考图预览缩放/旋转、图片→音频占位→视频占位→图片往返通过，主图与参考图保留。
- AI 生成：独立新建空画布制作文件，不设主图或参考图；文字描述保存重开正确，满足条件后可提交。未触发外部生成服务。
- 音频：视频声音、1.25 倍速度/保音调、字幕片段内编辑、字幕导出/重导入/重开、标记跳转、吸附/撤销、峰值和真实 WAV 导出通过；同一文档可从 Vue 打开。成果 WAV 已实际同步测试目录。
- 视频：4 秒画面/声音/中文字幕、1280×720/30fps MP4 导出及播放通过；元信息读取 h264、4 秒和 30fps，描述更新有隔离集成测试。
- 歌曲：用户 MP3 原件只读核对；测试副本修改标题/歌手/专辑及替换封面，保存后预览正确。Windows 替换前释放读取句柄，避免缓存或播放占用文件。
- 设置：所有分类真实打开，Qwen 102/102 与 Comfy 配置沿用；标签跨组移动落库后恢复，文本表单及工作流参数名称/范围/选项可输入，临时参数未保存到现有工作流。
- 布局与帮助：图片、音频、视频、AI 编辑在 1225×595 窗口核对命令栏、检查器和素材条；AI 画布曾被素材条遮挡，修复后按中央区域实际高度适应，放大/滚动后可复位。AI 生成/编辑的配置与任务独立滚动，提交按钮固定底部；配置控件不受滚动区域压缩，顶部和末端均实际核对。各实际编辑器帮助弹窗有工具说明和快捷键表，AI 音频/视频占位帮助明确说明未接入。

浏览器操作与自动化检查互补，类型/API 测试不能单独证明拖动、浮层、滚动和媒体解码有效。前端完整 `npm run check`（格式、ESLint、两套类型检查、276 项测试、三入口构建）通过；后端全量运行 305 项测试，跳过 2 项，无失败，Ruff 检查通过。

## 2026-10-01 代码审查与性能回归

- 修复预览播放时反复更新整棵组件树、音频详情重复读取、图片 EXIF 提前读盘及开发模式重复挂载的请求。真实音频播放约 69 秒的 CPU 采样未出现 `MediaPreview`／`MediaDetailsPanel` 渲染帧；歌曲元数据仅一次读取，图片 EXIF 在元信息页签打开后读取。该采样为本机开发环境结果，不代表所有设备或大型图库容量。
- 标签编辑改为目标集合的事务保存；隔离测试覆盖重复请求、空集合、非法标签以及写入失败回滚，保留生成标签。真实页面以原选择重复保存并核对分组搜索，不改动媒体内容。旧文件的读取结果不再覆盖新编辑会话，全屏描述弹窗内的方向键和旋转键不作用于外层预览。
- 修复挑一挑翻译变化触发重新取全部媒体；快速换批后仍补齐保留批次的标签，旧类型请求不会污染新批次或覆盖已编辑标签。最近排除路径限制为 256，标签缓存跟随最近 20 批。元数据与标签同步操作放到工作线程；隔离测试确认慢文件读取期间其他请求仍可响应。批量生成信息 100 个已缓存路径使用一次 SELECT，并保留原请求键。
- 前端完整检查、三入口构建与后端 Ruff 通过；后端 315 项测试中跳过 2 项（可选 HNSW、未配置的 TwelveLabs 服务），工具测试跳过宿主不支持的符号链接场景。源码、界面契约和使用指南分别标明 Vue 对照与 React 现行口径，移除临时配置状态及旧预览布局的混用。

## 能力边界与入口

AI 音频/视频、自动转写、任务取消尚无现成后端协议；录音不在用户要求中。云端计费 AI 提交、模型下载/更新、本机系统应用选择器未在此次回归中实际执行。触控上下滑动的方向与阈值有模型测试，当前内嵌浏览器不支持模拟触摸，未作真实触屏验收。只读权限和路径边界仍由后端校验。四种语言保留，但高级编辑器/工作台文案尚未全量翻译。

旧 App 挂载智能整理和提示词编辑组件，但 `openSmartOrganizeConfig`、`openEditPromptModal` 无调用入口，整理任务列表是非持久空状态。组件或路由存在不等于原页面有可达功能，不据此新增重复入口。

默认入口仍是 Vue，React 保留独立页面供迁移对照；切换默认入口及删除 Vue 依赖应单独执行，不在核对时删除基线。前端运行 `npm run check`；后端运行 `PYTHONPATH=backend/src python -m unittest discover -s backend/tests` 与 Ruff。详细数据边界见 [06](06-react-mantine-preview.md)、[07](07-react-workbench.md)、[08](08-react-video-editor.md)。
