# 架构与性能

## 入口与边界

`frontend/index.html` 加载 `react/main.tsx`，网页与桌面共用界面。启动先初始化 API 客户端，App 组合导航、认证、主题与错误边界，页面与编辑器懒加载，HTTP 共用 `react/shared/apiClient.ts`。

路由用 page、section、path、editor、draft 查询参数，支持浏览器前进／后退；编辑器保留来源页。资源 ID 不从名称推断。

| 位置                          | 职责                                      |
| ----------------------------- | ----------------------------------------- |
| frontend/react/features       | 页面与编辑器界面                          |
| frontend/src/features/*/model | 规则、仓储、图层、时间线、筛选与布局      |
| frontend/src/shared           | 类型、字典与纯工具                        |
| backend/src/omnigallery       | 路由、索引、元数据、工作区、AI 与基础设施 |

领域不依赖界面，编辑器通过宿主保存，lint 与类型检查维护依赖边界。

## 持久化与任务

SQLite 保存索引、设置与工作区状态，项目目录保存产物和快照。`/api/workspace_state/{workspace_id}` 隔离数据与版本。修改在暂存副本完成，服务器一次提交文档、索引及关联，成功后发布缓存。

冲突拒绝覆盖，删除标记阻止旧窗口复活。浏览器已有制作数据首次读取时幂等导入，界面偏好与当前标签页选择独立。媒体改名同时更新图层和 AI 引用，不改文字与提示词。

批量标签使用目标集合与事务，重试幂等。元数据检查文件版本，同卷临时文件完成后原子替换；路径、认证和权限统一校验，同步磁盘／SQLite 工作使用线程边界。

云任务固定提交时归属、用途和输入。每张结果立即记录，后续失败保留成功部分。并发 1–15，等待队列有界，调度属于单进程；重启不重放付费请求。

## 性能策略

| 范围       | 策略                                               |
| ---------- | -------------------------------------------------- |
| 列表／筛选 | 缓存卡片、稳定回调、本地草稿，分页集合合并保留对象 |
| 布局       | 复用未受影响位置，尺寸／顺序／列数改变时局部重算   |
| 查询       | 排序位置游标、文字索引，减少常规深分页 OFFSET      |
| 预览       | 当前请求去重，切换后旧响应失效，EXIF 按页签读取    |
| 音频       | 共用元数据、歌词二分定位，只发布歌词行变化         |
| 原媒体     | 视频 Range 单次至多 1 MiB，不预载相邻音视频        |
| 时间线     | 可见波形／片段绘制，短窗口试听和共用导出规则       |
| 素材       | 渐进展示、浏览网格虚拟化，滚轮动画仅活动时运行     |
| 轮询       | 完成后排下一次，空闲降频，任务历史缓存有界         |

本地模型串行推理，切换／空闲释放。GGUF 模型、视觉文件与协议共同定义索引版本，安装采用哈希、自检及原子切换；PyTorch 与原生引擎共用推理锁。

目录展开记录按子树迁移，成功读取才清理失效节点，异步完成后恢复视口，用户滚动可接管。渐进列表已显示节点仍会累计。

## 基准与容量

```powershell
node frontend/scripts/benchmark-generation-metadata.mjs
node frontend/scripts/benchmark-media-library.mjs
python tools/benchmark_library.py
```

合成基准不修改开发媒体，分别测纯解析、布局与 SQLite，不代表 HTTP、DOM、GPU 或磁盘。在同环境比较参数与结果，不用历史本机数值承诺吞吐。

语义搜索仍精确扫描候选并检查新鲜度；HNSW 可选加速主题聚类候选，不是全部向量查询的加速器。宽目录、网络盘、大工作区、编码和大图并发需真实容量验证。

自动检查覆盖模型、路径、事务、冲突、删除、渲染和任务；视觉、手势、推理、云服务与 Windows 安装包分别验证。
